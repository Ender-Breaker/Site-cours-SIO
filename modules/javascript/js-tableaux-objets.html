1. Les tableaux

const notes = [12, 15, 9];
notes[0]          // 12 (les indices commencent à 0)
notes.length      // 3
notes.push(18);   // ajoute à la fin
notes.pop();      // retire le dernier
notes.includes(9) // true
notes.indexOf(15) // 1

2. Les méthodes qui transforment

const doubles = notes.map(n => n * 2);           // [24, 30, 18]
const admis   = notes.filter(n => n >= 10);       // [12, 15]
const total   = notes.reduce((acc, n) => acc + n, 0);   // 36
const trie    = [...notes].sort((a, b) => a - b);       // copie triée
notes.forEach((n, i) => console.log(i, n));
sort() trie du texte par défaut

[10, 9, 1].sort() donne [1, 10, 9]. Pour des nombres, donne une fonction de comparaison : sort((a, b) => a - b).

3. Les objets

const eleve = { nom: "Léa", age: 19, option: "SLAM" };
eleve.nom            // "Léa"
eleve["age"]         // 19
eleve.ville = "Rennes";   // ajoute une propriété
for (const cle in eleve) console.log(cle, eleve[cle]);
Object.keys(eleve)   // ["nom", "age", "option", "ville"]

4. Déstructuration et décomposition

const { nom, age } = eleve;      // extrait des propriétés
const [premier, second] = notes; // extrait des éléments
const copie = { ...eleve, age: 20 };   // copie modifiée
const tout = [...notes, 20, 14];

5. Les classes

class Compte {
  constructor(solde) { this.solde = solde; }
  deposer(m) { this.solde += m; }
}
const c = new Compte(100);
c.deposer(50);

6. JSON

Le format JSON (JavaScript Object Notation) sert à échanger des données entre un serveur et une page :

const texte = JSON.stringify(eleve);   // objet → texte
const objet = JSON.parse(texte);       // texte → objet
