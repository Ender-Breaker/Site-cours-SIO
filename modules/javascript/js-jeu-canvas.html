Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Un jeu vidéo, c'est une boucle qui tourne environ 60 fois par seconde : lire les entrées (clavier, souris), mettre à jour l'état du jeu (positions, score), puis dessiner l'image. Dans le navigateur, on dessine dans une balise <canvas>.

1. Le canvas

<canvas id="jeu" width="480" height="320"></canvas>
<script>
  const ctx = document.getElementById("jeu").getContext("2d");
  ctx.fillStyle = "red";
  ctx.fillRect(40, 40, 100, 60);           // rectangle plein
  ctx.beginPath();
  ctx.arc(300, 160, 40, 0, Math.PI * 2);   // cercle
  ctx.fill();
  ctx.font = "24px sans-serif";
  ctx.fillText("Mon jeu", 20, 280);
</script>

L'origine (0, 0) est en haut à gauche ; x augmente vers la droite, y vers le bas.

2. La boucle de jeu

let x = 0, dernier = 0;
const touches = {};
document.addEventListener("keydown", e => touches[e.key] = true);
document.addEventListener("keyup",   e => touches[e.key] = false);

function boucle(t) {
  const dt = (t - dernier) / 1000;   // secondes écoulées depuis l'image précédente
  dernier = t;
  if (touches["ArrowRight"]) x += 200 * dt;   // 200 pixels par seconde
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 480, 320);               // effacer
  ctx.fillStyle = "blue";
  ctx.fillRect(x, 140, 40, 40);               // dessiner
  requestAnimationFrame(boucle);              // image suivante
}
requestAnimationFrame(boucle);
update puis draw

Sépare toujours la mise à jour (logique, déplacements, collisions) du dessin. Le labo fait exactement ça : il appelle ta fonction update(dt) puis draw() à chaque image, et fournit des fonctions simples (rect, cercle, texte, touche…) qui utilisent le canvas pour toi.

3. Mouvement et rebonds

let x = 100, y = 80, vx = 4, vy = 3;     // position et vitesse
function update(dt) {
  x += vx;  y += vy;
  if (x < 12 || x > LARGEUR - 12) vx = -vx;   // rebond horizontal
  if (y < 12 || y > HAUTEUR - 12) vy = -vy;   // rebond vertical
}

La gravité est une accélération : à chaque image on ajoute une petite valeur à la vitesse verticale (vy += 0.6), puis la vitesse à la position.

5. Organiser un jeu

  • Un objet par entité : { x, y, vx, vy } ; un tableau pour les ennemis ou les projectiles.
  • Des états : "menu", "jeu", "perdu" ; update et draw font un switch dessus.
  • Math.random() pour l'aléatoire (le labo propose hasard(a, b)).
