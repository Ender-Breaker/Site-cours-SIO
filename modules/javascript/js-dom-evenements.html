Le DOM (*Document Object Model*) est la représentation de la page HTML sous forme d'un arbre d'objets. Avec lui, JavaScript lit et modifie la page pendant qu'elle est affichée.

Où tester ?

Ces exemples ont besoin d'une page HTML : essaie-les dans le labo HTML / CSS ou dans la console de ton navigateur (touche F12).

1. Sélectionner des éléments

const titre = document.querySelector("h1");               // le premier qui correspond
const bouton = document.querySelector("#valider");        // par id
const cartes = document.querySelectorAll(".carte");       // tous (une liste)
const champ = document.getElementById("email");           // ancienne méthode, toujours valable

cartes.forEach(c => console.log(c.textContent));

querySelector accepte n'importe quel sélecteur CSS : "nav a", "ul > li.actif", "input[type=email]". Il renvoie null si rien ne correspond.

2. Modifier le contenu, les classes, les attributs

titre.textContent = "Nouveau titre";            // texte seul : sûr
zone.innerHTML = "<b>gras</b>";                 // HTML : jamais avec une saisie d'utilisateur
bouton.classList.add("actif");                  // classes CSS
bouton.classList.remove("cache");
bouton.classList.toggle("ouvert");              // ajoute si absente, retire sinon
lien.setAttribute("href", "https://exemple.fr");
image.src = "photo.jpg";
bouton.disabled = true;
titre.style.color = "crimson";                  // style direct (préfère une classe)
innerHTML et la faille XSS

Insérer avec innerHTML un texte venant d'un utilisateur lui permet d'injecter du HTML et du JavaScript dans ta page (faille XSS). Pour afficher une saisie, utilise toujours textContent.

3. Créer et supprimer des éléments

const li = document.createElement("li");
li.textContent = "Nouvelle tâche";
li.classList.add("tache");
document.querySelector("#liste").append(li);    // ajoute à la fin

li.remove();                                    // supprime

4. Les événements

bouton.addEventListener("click", () => {
  compteur++;
  affichage.textContent = compteur;
});

champ.addEventListener("input", (e) => {        // à chaque frappe
  apercu.textContent = e.target.value;          // e.target : l'élément concerné
});

formulaire.addEventListener("submit", (e) => {
  e.preventDefault();                           // empêche le rechargement de la page
  const email = champ.value.trim();
  if (!email.includes("@")) erreur.textContent = "Adresse invalide";
});

document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") fenetre.classList.add("cache");
});
ÉvénementSe produit quand
clickon clique
inputla valeur d'un champ change
submitun formulaire est envoyé
keydown / keyupune touche est enfoncée / relâchée
mouseoverla souris survole
DOMContentLoadedla page est prête

5. La délégation d'événements

Plutôt qu'un écouteur par ligne d'une liste, un seul sur le parent suffit : l'événement remonte dans l'arbre.

liste.addEventListener("click", (e) => {
  const bouton = e.target.closest("button.supprimer");
  if (bouton) bouton.closest("li").remove();    // marche aussi pour les lignes ajoutées plus tard
});

6. Garder des données : localStorage

localStorage.setItem("theme", "sombre");
const theme = localStorage.getItem("theme");                 // null si absent
localStorage.setItem("taches", JSON.stringify(taches));      // un objet : passer par JSON
const taches = JSON.parse(localStorage.getItem("taches") || "[]");

TutorielUne liste de tâches complète

Le HTML

<form id="form"><input id="champ" required><button>Ajouter</button></form>
<ul id="liste"></ul>

Ajouter une tâche

const form = document.querySelector("#form");
const champ = document.querySelector("#champ");
const liste = document.querySelector("#liste");

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const li = document.createElement("li");
  li.textContent = champ.value.trim();          // textContent : pas de faille XSS
  liste.append(li);
  champ.value = "";
});

Cocher et supprimer

Un seul écouteur sur la liste, grâce à la délégation.

liste.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") e.target.classList.toggle("fait");
});
liste.addEventListener("dblclick", (e) => {
  if (e.target.tagName === "LI") e.target.remove();
});
À retenir

document.querySelector(sélecteur CSS) et querySelectorAll.

textContent pour le texte, classList.add/remove/toggle pour les classes.

createElement + append pour ajouter, remove() pour supprimer.

element.addEventListener("click", fonction) ; e.preventDefault() sur un formulaire.

Jamais innerHTML avec une saisie d'utilisateur.
