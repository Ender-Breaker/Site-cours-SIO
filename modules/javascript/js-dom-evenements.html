Le DOM (Document Object Model) est la représentation de la page HTML sous forme d'objets que JavaScript peut lire et modifier : changer un texte, ajouter un élément, réagir à un clic.

1. Trouver des éléments

const titre = document.querySelector("h1");          // le premier qui correspond
const btn   = document.querySelector("#valider");     // par id
const items = document.querySelectorAll(".item");     // tous (liste)
const champ = document.getElementById("nom");

Les sélecteurs sont les mêmes qu'en CSS.

2. Modifier la page

titre.textContent = "Nouveau titre";       // texte (sûr)
titre.classList.add("actif");              // ajoute une classe CSS
titre.classList.toggle("cache");
titre.style.color = "red";
champ.value                                // contenu d'un champ de formulaire
const li = document.createElement("li");   // créer un élément
li.textContent = "Nouvel item";
document.querySelector("ul").append(li);
li.remove();
textContent plutôt qu'innerHTML

innerHTML interprète le HTML : si on y met une saisie utilisateur, un visiteur peut injecter du code (faille XSS). Pour du texte, utilise textContent.

3. Les événements

btn.addEventListener("click", () => {
  console.log("Bouton cliqué");
});

champ.addEventListener("input", (e) => {
  console.log("Saisie :", e.target.value);
});

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowRight") avancer();
});

4. Valider un formulaire

form.addEventListener("submit", (e) => {
  if (champ.value.trim() === "") {
    e.preventDefault();          // bloque l'envoi
    erreur.textContent = "Le nom est obligatoire";
  }
});

La vérification en JavaScript améliore le confort, mais le serveur (PHP) doit toujours revérifier : n'importe qui peut désactiver JavaScript.

5. Récupérer des données : fetch

async function charger() {
  const rep = await fetch("api/produits.json");
  const produits = await rep.json();
  console.log(produits.length + " produits");
}

async/await permettent d'attendre une réponse réseau sans bloquer la page.
