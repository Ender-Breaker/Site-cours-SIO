Charger des données depuis un serveur prend du temps. JavaScript ne bloque pas la page en attendant : il lance l'opération, continue, et reprend quand la réponse arrive. C'est la programmation asynchrone.

Où tester ?

Ces exemples font des requêtes réseau : essaie-les dans la console de ton navigateur (F12), sur n'importe quelle page.

1. Le principe

console.log("1 : avant");
setTimeout(() => console.log("3 : une seconde plus tard"), 1000);   // n'attend pas
console.log("2 : après");

L'ordre d'affichage est 1, 2, 3 : setTimeout programme la fonction et rend la main tout de suite.

2. Les promesses

Une promesse (Promise) représente un résultat qui arrivera plus tard. Elle est *en attente*, puis *tenue* (avec une valeur) ou *rompue* (avec une erreur).

fetch("https://api.exemple.fr/produits")           // renvoie une promesse
  .then(reponse => reponse.json())                  // quand la réponse arrive
  .then(produits => console.log(produits.length))   // quand le JSON est lu
  .catch(erreur => console.log("Échec :", erreur.message));

3. async / await : la forme à utiliser

await met la fonction en pause jusqu'à ce que la promesse soit tenue, sans bloquer la page. Le code se lit de haut en bas, comme du code ordinaire.

async function chargerProduits() {
  try {
    const reponse = await fetch("https://api.exemple.fr/produits");
    if (!reponse.ok) throw new Error("HTTP " + reponse.status);   // 404, 500…
    const produits = await reponse.json();
    return produits;
  } catch (e) {
    console.log("Impossible de charger :", e.message);
    return [];
  }
}

const produits = await chargerProduits();     // await : seulement dans une fonction async ou un module
fetch ne rejette pas sur une erreur 404

fetch n'échoue que si le réseau est coupé. Une réponse 404 ou 500 est une réponse « réussie » : il faut tester reponse.ok (ou reponse.status) soi-même.

5. Plusieurs requêtes en parallèle

const [clients, produits] = await Promise.all([
  fetch("/api/clients").then(r => r.json()),
  fetch("/api/produits").then(r => r.json()),
]);

Promise.all lance tout en même temps et attend que toutes les promesses soient tenues.

Charger

async function charger() {
  const reponse = await fetch("https://jsonplaceholder.typicode.com/users");
  if (!reponse.ok) throw new Error("HTTP " + reponse.status);
  return reponse.json();
}

Afficher

textContent et createElement : aucune faille XSS possible, même si l'API renvoie du HTML.

function afficher(utilisateurs) {
  const liste = document.querySelector("#liste");
  liste.replaceChildren();                       // vide la liste
  for (const u of utilisateurs) {
    const li = document.createElement("li");
    li.textContent = `${u.name} — ${u.email}`;
    liste.append(li);
  }
}

Relier, avec un état de chargement et les erreurs

const etat = document.querySelector("#etat");
etat.textContent = "Chargement…";
try {
  afficher(await charger());
  etat.textContent = "";
} catch (e) {
  etat.textContent = "Impossible de charger les données : " + e.message;
}
À retenir

Asynchrone : l'opération est lancée, le code continue, le résultat arrive plus tard.
