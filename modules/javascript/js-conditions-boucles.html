Les valeurs « fausses »

Dans une condition, false, 0, "", null, undefined et NaN sont considérés comme faux. Tout le reste est vrai, y compris "0", [] et {}.

4. Les boucles

let n = 1;
while (n < 100) n *= 2;                  // tant que
console.log(n);

for (let i = 1; i <= 5; i++) console.log("tour", i);     // nombre de tours connu

const fruits = ["pomme", "kiwi", "poire"];
for (const f of fruits) console.log(f);                  // for…of : chaque VALEUR
for (const c of "abc") console.log(c);                   // marche aussi sur une chaîne

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;             // tour suivant
  if (i > 7) break;                      // sortie
  console.log(i);
}
for…of, pas for…in

for…in parcourt les clés (les indices, sous forme de texte) et réserve des surprises sur les tableaux. Pour un tableau, c'est toujours for…of.

TutorielLe jeu du « plus ou moins »

Une seule comparaison

const SECRET = 42;
const essai = Number(lire());
if (essai < SECRET) console.log("Trop petit");
else if (essai > SECRET) console.log("Trop grand");
else console.log("Gagné !");

Répéter et compter

do … while exécute le bloc au moins une fois.

const SECRET = 42;
let essai, essais = 0;
do {
  essai = Number(lire());
  essais++;
  if (essai < SECRET) console.log("Trop petit");
  else if (essai > SECRET) console.log("Trop grand");
} while (essai !== SECRET);
console.log(`Gagné ! Essais : ${essais}`);
