Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Comparaisons

5 === 5       // true  : égalité stricte (même valeur ET même type)
5 === "5"     // false
5 == "5"      // true  : égalité large (convertit) → à éviter
5 !== 3       // true  : différent
a > b, a <= b
&& (et)   || (ou)   ! (non)
Toujours === et !==

L'égalité large == fait des conversions surprenantes (0 == "" est vrai). Utilise ===.

2. if, else if, else

if (note >= 16) {
  console.log("Très bien");
} else if (note >= 10) {
  console.log("Admis");
} else {
  console.log("Recalé");
}

const statut = age >= 18 ? "majeur" : "mineur";   // opérateur ternaire

Valeurs « fausses » (falsy) : false, 0, "", null, undefined, NaN. Tout le reste est vrai dans un if.

3. switch

switch (jour) {
  case "samedi":
  case "dimanche":
    console.log("Week-end");
    break;
  default:
    console.log("Semaine");
}

4. Les boucles

for (let i = 1; i <= 5; i++) {      // compteur
  console.log(i);
}

let n = 100;
while (n > 1) {                      // tant que
  n = n / 2;
}

const fruits = ["pomme", "kiwi"];
for (const f of fruits) {            // chaque élément d'un tableau
  console.log(f);
}

break sort de la boucle, continue passe au tour suivant. Une boucle dont la condition ne devient jamais fausse bloque la page : le labo l'arrête au bout de quelques secondes.
