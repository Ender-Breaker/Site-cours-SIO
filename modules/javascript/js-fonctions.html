Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Déclarer une fonction

function carre(x) {
  return x * x;
}
carre(5);   // 25

function saluer(nom = "inconnu") {   // paramètre par défaut
  console.log("Salut " + nom);
}

Une fonction sans return renvoie undefined. Les paramètres sont des variables locales.

2. Fonctions fléchées

const carre = (x) => x * x;            // return implicite
const somme = (a, b) => {
  const s = a + b;
  return s;
};
const direBonjour = () => console.log("Bonjour");

3. La portée

let total = 0;              // globale
function ajouter(n) {
  const double = n * 2;     // locale : n'existe que dans la fonction
  total += double;
}
if (true) {
  let a = 1;                // n'existe que dans ce bloc { }
}

4. Les fonctions sont des valeurs

On peut ranger une fonction dans une variable, la passer en paramètre à une autre (un callback) ou la renvoyer :

function repeter(n, action) {
  for (let i = 0; i < n; i++) action(i);
}
repeter(3, (i) => console.log("Tour " + i));

setTimeout(() => console.log("1 seconde plus tard"), 1000);
bouton.addEventListener("click", () => alert("Clic !"));
Pourquoi des fonctions ?

Ne pas répéter le même code, lui donner un nom qui explique ce qu'il fait, et pouvoir le tester séparément. Une bonne fonction fait une seule chose.

5. La récursivité

function factorielle(n) {
  if (n <= 1) return 1;          // cas de base : indispensable
  return n * factorielle(n - 1);
}
