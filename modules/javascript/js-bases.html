2. Les variables : let et const

let score = 0;          // modifiable
score = score + 10;
const PRENOM = "Léa";    // constante : ne peut pas être réaffectée
let x;                   // déclarée sans valeur : undefined

On utilise const par défaut, et let seulement quand la valeur doit changer. Le vieux mot-clé var est à éviter (sa portée est piégeuse).

4. Opérateurs et conversions

10 / 4        // 2.5
10 % 4        // 2 (reste)
2 ** 3        // 8 (puissance)
"5" + 3       // "53"  ← le + colle les textes !
"5" * 3       // 15    ← les autres opérateurs convertissent en nombre
Number("42")  // 42
String(42)    // "42"
parseInt("12px")  // 12
Le piège du +

Une valeur lue dans un formulaire ou au clavier est toujours du texte. "17" + 10 donne "1710" : convertis avec Number() avant de calculer.

5. Les chaînes et les gabarits

const nom = "Léa", age = 19;
console.log("Bonjour " + nom + ", tu as " + age + " ans");
console.log(`Bonjour ${nom}, tu as ${age} ans`);   // gabarit (backticks)
nom.length          // 3
nom.toUpperCase()   // "LÉA"
"a-b-c".split("-")  // ["a", "b", "c"]
