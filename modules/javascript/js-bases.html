JavaScript est le langage du web : c'est le seul que tous les navigateurs exécutent. Il anime les pages (menus, formulaires, jeux), et avec Node.js il tourne aussi côté serveur. Pour l'option SLAM, c'est un passage obligé.

2. Variables : const et let

const prenom = "Léa";      // const : ne sera jamais réaffectée
let score = 0;             // let : peut changer
score = score + 10;
score += 5;                // raccourci
score++;                   // + 1
console.log(prenom, score);
let inconnue;              // déclarée sans valeur
console.log(inconnue);     // undefined
Jamais var

var est l'ancienne façon de déclarer : sa portée est la fonction entière et non le bloc, ce qui cause des bugs. Écris const par défaut, let quand la valeur doit changer.

4. Les chaînes et les gabarits

const nom = "Léa", age = 17;
console.log("Bonjour " + nom + ", tu as " + age + " ans");      // concaténation
console.log(`Bonjour ${nom}, dans 10 ans tu auras ${age + 10} ans`);   // gabarit : accents graves
console.log(nom.length, nom.toUpperCase(), nom[0], nom.includes("é"));

5. Convertir, et les pièges de +

console.log("5" + 3);            // "53" : + avec une chaîne = concaténation
console.log("5" - 3);            // 2    : - convertit en nombre
console.log(Number("42") + 1, parseInt("42px"), Number("abc"));   // 43  42  NaN
console.log(String(42).length, (42).toString(2));
console.log(5 == "5", 5 === "5");    // true  false
Toujours ===

== convertit les types avant de comparer (0 == "" est vrai !). === compare la valeur et le type : utilise toujours === et !==.

6. Lire une entrée

Dans le labo, lire() renvoie la ligne suivante des entrées, sous forme de texte. Dans une page web, on lit plutôt la valeur d'un champ de formulaire (chapitre DOM).

const nom = lire();
const age = Number(lire());        // conversion indispensable pour calculer
console.log(`Bonjour ${nom}, dans 10 ans tu auras ${age + 10} ans.`);
