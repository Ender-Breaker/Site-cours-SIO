Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

La plupart des grands jeux sont écrits en C++ (Unreal Engine, la plupart des moteurs maison) : il est rapide et contrôle précisément la mémoire. Dans le navigateur, le C++ peut être compilé en WebAssembly, un format binaire que le navigateur exécute presque aussi vite que du code natif (c'est ce que fait Emscripten pour porter des jeux sur le web, et ce que fait le labo).

1. Le principe : la boucle de jeu

Le programme n'a pas de main qui se termine : c'est le moteur qui appelle tes fonctions à chaque image.

#include "jeu.h"            // l'API du labo

double x = 200;             // l'état du jeu : variables globales (ou dans une classe)

void setup() {              // une fois, au démarrage
}

void update(double dt) {    // 60 fois par seconde : logique
    if (touche("droite")) x += 5;
}

void draw() {               // 60 fois par seconde : dessin
    effacer("black");
    rect(x, 140, 40, 40, "blue");
}
Fonction du laboRôle
effacer(c)remplit l'écran (480 × 320)
rect(x, y, l, h, c), cercle(x, y, r, c), ligne(x1, y1, x2, y2, c)formes pleines
texte(t, x, y, taille, c)texte (utilise std::to_string pour les nombres)
touche("gauche"), toucheAppuyee("espace")touche maintenue / appuyée à cette image
sourisX(), sourisY(), clic()souris
hasard(a, b)entier au hasard entre a et b

2. Des entités avec des struct

struct Balle {
    double x, y, vx, vy;
    void avancer() {
        x += vx; y += vy;
        if (x < 10 || x > LARGEUR - 10) vx = -vx;
        if (y < 10 || y > HAUTEUR - 10) vy = -vy;
    }
};

vector<Balle> balles;

void setup() {
    for (int i = 0; i < 5; i++)
        balles.push_back({ (double)hasard(20, 460), (double)hasard(20, 300), 3, 2 });
}
void update(double dt) { for (auto& b : balles) b.avancer(); }
void draw() {
    effacer("black");
    for (const auto& b : balles) cercle(b.x, b.y, 10, "orange");
}
auto& dans la boucle

for (auto b : balles) travaille sur des copies : les balles ne bougeraient pas. Il faut auto& pour modifier les éléments du vector.

3. Collisions

bool collision(double ax, double ay, double al, double ah,
               double bx, double by, double bl, double bh) {
    return ax < bx + bl && ax + al > bx && ay < by + bh && ay + ah > by;
}
// cercle contre cercle
bool touche2(const Balle& a, const Balle& b) {
    return hypot(a.x - b.x, a.y - b.y) < 20;
}

4. Supprimer des éléments

#include <algorithm>
balles.erase(remove_if(balles.begin(), balles.end(),
             [](const Balle& b) { return b.y > HAUTEUR; }), balles.end());

L'idiome erase(remove_if(…)) retire d'un coup tous les éléments qui vérifient une condition (ici une lambda, une petite fonction anonyme).
