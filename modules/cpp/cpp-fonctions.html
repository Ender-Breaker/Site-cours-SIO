Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Définir une fonction

int carre(int x) {          // type de retour, nom, paramètres typés
    return x * x;
}

void afficherLigne(int n) { // void : ne renvoie rien
    for (int i = 0; i < n; i++) cout << '-';
    cout << endl;
}

Une fonction doit être déclarée avant d'être utilisée. Si elle est écrite après main, on place son prototype en haut : int carre(int x);

2. Passage par valeur ou par référence

void plusUnCopie(int n) { n++; }     // reçoit une COPIE
void plusUn(int& n) { n++; }         // reçoit une RÉFÉRENCE : modifie l'original

int a = 5;
plusUnCopie(a);   // a vaut toujours 5
plusUn(a);        // a vaut 6

void afficher(const string& s) {     // référence constante : pas de copie, pas de modification
    cout << s << endl;
}
Quand utiliser & ?

Pour modifier la variable de l'appelant, ou pour éviter de copier un gros objet (string, vector) : dans ce dernier cas, ajoute const.

3. Surcharge et valeurs par défaut

double aire(double r) { return 3.14159 * r * r; }        // cercle
double aire(double l, double h) { return l * h; }         // rectangle
void saluer(string nom = "inconnu") { cout << "Salut " << nom; }

Plusieurs fonctions peuvent porter le même nom si leurs paramètres diffèrent : c'est la surcharge.

4. Pointeurs (aperçu)

int a = 5;
int* p = &a;     // p contient l'ADRESSE de a
*p = 8;          // modifie ce qui est pointé : a vaut 8

Les pointeurs sont puissants mais dangereux (accès à une zone mémoire invalide = plantage). En C++ moderne, on les remplace souvent par des références, vector et des pointeurs intelligents (unique_ptr).

#include <cmath>
