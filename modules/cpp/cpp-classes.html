1. Classe et objet

class Compte {
private:                         // accessible seulement dans la classe
    string titulaire;
    double solde;
public:                          // accessible de partout
    Compte(string t, double s) : titulaire(t), solde(s) {}   // constructeur
    void deposer(double m) { if (m > 0) solde += m; }
    bool retirer(double m) {
        if (m > solde) return false;
        solde -= m;
        return true;
    }
    double getSolde() const { return solde; }   // const : ne modifie pas l'objet
};                               // ← point-virgule obligatoire

Compte c("Léa", 100);
c.deposer(50);
cout << c.getSolde();

Une classe regroupe des données (attributs) et les fonctions qui les manipulent (méthodes). Un objet est une instance de la classe.

2. L'encapsulation

Les attributs sont private : on ne peut les modifier que par les méthodes, qui garantissent que l'objet reste cohérent (pas de solde négatif, par exemple). Les accesseurs (getSolde()) et mutateurs (setX()) contrôlent l'accès.

struct est identique à class, mais tout y est public par défaut : on l'utilise pour de simples regroupements de données.

struct Point { double x, y; };
Point p = {3, 4};

3. L'héritage

class Personnage {
protected:                        // accessible aussi dans les classes filles
    int pv = 100;
public:
    virtual void attaquer() { cout << "Coup de poing" << endl; }
    virtual ~Personnage() {}
};

class Mage : public Personnage {  // Mage hérite de Personnage
public:
    void attaquer() override { cout << "Boule de feu" << endl; }
};

Avec virtual et override, un appel à attaquer() sur un Personnage& qui est en réalité un Mage exécute la version du Mage : c'est le polymorphisme.

4. Mémoire

Compte a("Léa", 100);                         // sur la pile : détruit automatiquement
auto b = make_unique<Compte>("Tom", 50);      // sur le tas, géré par un pointeur intelligent
b->deposer(10);
Pas de new sans delete

En C++ moderne, on évite new/delete à la main : les objets locaux, vector et unique_ptr libèrent la mémoire tout seuls. Il n'y a pas de ramasse-miettes comme en Java.
