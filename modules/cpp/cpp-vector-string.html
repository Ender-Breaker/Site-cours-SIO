1. std::vector : le tableau dynamique

#include <vector>
vector<int> notes = {12, 15, 9};
notes.push_back(18);      // ajoute à la fin
notes.size()              // 4
notes[0]                  // 12 (indice 0)
notes.back()              // 18 (dernier)
notes.pop_back();         // retire le dernier
vector<double> v(5, 0.0); // 5 cases à 0

Un vector grandit tout seul et connaît sa taille : c'est le choix par défaut en C++.

2. Parcourir

for (int i = 0; i < (int)notes.size(); i++) cout << notes[i] << " ";
for (int n : notes) cout << n << " ";        // boucle sur les éléments (copie)
for (int& n : notes) n += 1;                 // par référence : modifie le vector
Hors limites

notes[10] sur un vector de 4 éléments n'est pas vérifié : comportement indéfini (plantage ou valeur aléatoire). notes.at(10), lui, vérifie l'indice.

4. std::string

5. Les tableaux « à la C »

int t[5] = {1, 2, 3, 4, 5};   // taille fixe, ne connaît pas sa taille

On les rencontre dans du code ancien ou très optimisé ; préfère vector (ou array<int, 5> pour une taille fixe).
