Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Conditions

if (note >= 16) {
    cout << "Très bien" << endl;
} else if (note >= 10) {
    cout << "Admis" << endl;
} else {
    cout << "Recalé" << endl;
}
string statut = (age >= 18) ? "majeur" : "mineur";

Opérateurs : == != < > <= >=, et logiques && (et), || (ou), ! (non).

= ou == ?

if (x = 5) affecte 5 à x et vaut toujours vrai ! La comparaison s'écrit ==. L'option -Wall du compilateur signale ce genre d'erreur.

2. switch

switch (choix) {
    case 1: cout << "Jouer"; break;
    case 2: cout << "Options"; break;
    default: cout << "Quitter";
}

switch ne fonctionne qu'avec des entiers (ou des caractères, des énumérations), pas avec des string.

3. Boucles

for (int i = 1; i <= 10; i++) {
    cout << i << " ";
}

int n = 100;
while (n > 1) {
    n /= 2;
}

int x;
do {                        // au moins une fois
    cin >> x;
} while (x < 0);

i++ ajoute 1, n /= 2 divise n par 2 (aussi +=, -=, *=). break sort de la boucle, continue passe au tour suivant.

4. Portée

Une variable déclarée dans un bloc { } (par exemple le i d'un for) n'existe que dans ce bloc.
