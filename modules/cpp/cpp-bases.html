Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

C++ est un langage compilé créé par Bjarne Stroustrup dans les années 1980 comme une extension du C. Il est très rapide et donne un contrôle fin sur la mémoire : on le trouve dans les moteurs de jeux (Unreal Engine), les navigateurs, les logiciels de création, l'embarqué et la finance.

1. Compiler, puis exécuter

Le code source (main.cpp) n'est pas exécuté directement : un compilateur (g++, clang++, MSVC) le traduit en programme exécutable. Les erreurs de syntaxe ou de type sont détectées avant l'exécution.

g++ -std=c++20 -Wall main.cpp -o main     # compiler
./main                                    # exécuter

Le labo fait tout ça dans ton navigateur : ton code est compilé par clang en WebAssembly puis exécuté.

2. Le programme minimal

#include <iostream>     // bibliothèque d'entrées/sorties
using namespace std;    // évite d'écrire std:: partout

int main() {            // point d'entrée du programme
    cout << "Bonjour !" << endl;
    return 0;           // 0 = tout s'est bien passé
}

Chaque instruction se termine par un point-virgule. Les blocs sont entre accolades.

3. Variables et types

int age = 19;              // entier
double prix = 9.99;        // nombre à virgule
char lettre = 'A';         // un caractère (apostrophes)
bool majeur = true;        // vrai / faux
string nom = "Léa";        // texte (#include <string>)
const double TVA = 0.2;    // constante
auto x = 3.5;              // type déduit : double
Typage statique

Le type d'une variable est fixé à sa déclaration et ne change plus. int n = 7 / 2; vaut 3 : entre deux entiers, la division est entière. Écris 7.0 / 2 pour obtenir 3.5.

4. Afficher et lire

int a, b;
cout << "Deux nombres : ";
cin >> a >> b;                     // lit deux valeurs séparées par des espaces
cout << "Somme : " << a + b << endl;
string ligne;
getline(cin, ligne);               // lit toute une ligne

<< envoie vers la sortie, >> lit depuis l'entrée. endl passe à la ligne (comme "\n").
