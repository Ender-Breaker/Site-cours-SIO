Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Le C++ est né en 1985 comme une extension du langage C. C'est un langage compilé et typé : rapide, précis, exigeant. Il fait tourner les moteurs de jeu (Unreal Engine), les navigateurs web, les systèmes d'exploitation, les bases de données, les logiciels embarqués. Si tu comprends le C++, tu comprends ce que font réellement les autres langages derrière ton dos.

Comment suivre ce cours

Chaque bloc avec un bouton Exécuter est compilé par un vrai compilateur C++20 (clang) dans ton navigateur. La première compilation prend quelques secondes. Modifie le code, provoque des erreurs, lis les messages du compilateur : c'est lui ton meilleur professeur.

2. De la source au programme : la compilation

Un programme C++ ne s'exécute pas directement. Le compilateur traduit le fichier source .cpp en langage machine :

g++ main.cpp -o programme     # compile (g++ ou clang++)
./programme                   # exécute
g++ -Wall -Wextra -std=c++20 main.cpp -o programme   # avec tous les avertissements

Conséquence : beaucoup d'erreurs sont détectées avant l'exécution. Une *erreur de compilation* (faute de syntaxe, type incorrect) empêche de produire le programme ; une *erreur d'exécution* survient pendant qu'il tourne.

#include <iostream>
using namespace std;

int main() {
    cout << "Il manque quelque chose" << endl
}

Lis toujours la première erreur : elle indique la ligne et ce que le compilateur attendait. Les suivantes en sont souvent des conséquences.

3. Variables et types

En C++, chaque variable a un type fixé à sa création, qui ne changera jamais.

#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 17;                // entier
    double prix = 19.99;         // nombre à virgule
    char initiale = 'L';         // UN caractère, entre apostrophes
    bool majeur = false;         // true ou false
    string prenom = "Léa";       // texte, entre guillemets
    cout << prenom << " a " << age << " ans" << endl;
    cout << prix << " " << initiale << " " << majeur << endl;   // false s'affiche 0
    age = age + 1;
    cout << age << endl;
}

Une variable non initialisée contient n'importe quoi

int x; sans valeur ne vaut pas 0 : elle contient ce qui traînait en mémoire. Donne toujours une valeur de départ : int x = 0;.

const et auto

#include <iostream>
#include <string>
using namespace std;

int main() {
    const double TVA = 0.2;      // constante : toute modification est refusée à la compilation
    auto quantite = 3;           // auto : le compilateur déduit int
    auto total = quantite * 9.99;   // … et ici double
    auto nom = string("Sam");
    cout << total * (1 + TVA) << " " << nom << endl;
}

4. Les opérateurs et leurs pièges

#include <iostream>
using namespace std;

int main() {
    cout << 7 / 2 << endl;          // 3   : entier / entier = entier !
    cout << 7.0 / 2 << endl;        // 3.5 : dès qu'un des deux est double
    cout << 7 % 2 << endl;          // 1   : reste de la division
    int a = 7, b = 2;
    cout << static_cast<double>(a) / b << endl;   // 3.5 : conversion explicite
    int i = 5;
    i++;            // i = i + 1
    i += 10;        // i = i + 10
    i *= 2;
    cout << i << endl;
    cout << (5 > 3) << " " << (5 == 3) << " " << (5 != 3) << endl;
}
Division entière

7 / 2 vaut 3, pas 3.5. Pour une moyenne, écris somme / 3.0 ou convertis avec static_cast<double>(somme).

5. Lire au clavier

cin >> variable lit une valeur et la convertit dans le type de la variable. Les valeurs sont séparées par des espaces ou des retours à la ligne.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string prenom;
    int age;
    cin >> prenom >> age;
    cout << "Bonjour " << prenom << ", dans 10 ans tu auras " << age + 10 << " ans." << endl;
}

cin >> s'arrête au premier espace. Pour lire une ligne entière, on utilise getline :

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nomComplet;
    getline(cin, nomComplet);
    cout << "Bonjour " << nomComplet << " (" << nomComplet.size() << " caractères)" << endl;
}

6. Mettre en forme les nombres

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double prix = 12.5;
    cout << prix << endl;                              // 12.5
    cout << fixed << setprecision(2) << prix << endl;  // 12.50 : deux décimales
    cout << setw(8) << 42 << "|" << endl;              // sur 8 caractères, aligné à droite
}

Calculer

double * int donne un double : aucun problème de division entière ici.

#include <iostream>
using namespace std;

int main() {
    double prix;
    int quantite;
    cin >> prix >> quantite;
    double total = prix * quantite;
    cout << "Total : " << total << endl;
}

Ajouter la TVA et mettre en forme

Change les entrées et relance. Essaie aussi de modifier TVA après sa déclaration : le compilateur refuse.

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const double TVA = 0.2;
    double prix;
    int quantite;
    cin >> prix >> quantite;
    double ht = prix * quantite;
    cout << fixed << setprecision(2);
    cout << "HT : " << ht << " €" << endl;
    cout << "TVA : " << ht * TVA << " €" << endl;
    cout << "TTC : " << ht * (1 + TVA) << " €" << endl;
}

À retenir

Tout programme commence dans int main(). Chaque instruction finit par ;.

cout << valeur << endl; affiche, cin >> variable; lit, getline(cin, ligne) lit une ligne entière.

Types de base : int, double, char, bool, string.

int / int donne un entier.

const interdit la modification, auto laisse le compilateur déduire le type.
