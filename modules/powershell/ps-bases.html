Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

PowerShell est le shell et le langage de script de Windows (il existe aussi pour Linux et macOS). Il sert à administrer les postes, Windows Server, Active Directory, Microsoft 365. Sa grande différence avec Bash : les commandes n'échangent pas du texte, mais des objets.

1. Les cmdlets : Verbe-Nom

Toutes les commandes suivent la même forme, ce qui les rend devinables.

Get-Process                      # liste les processus
Get-Service                      # liste les services
Get-ChildItem C:\Users           # contenu d'un dossier (alias : dir, ls, gci)
Get-Content notes.txt            # contenu d'un fichier (alias : cat, type)
Set-Location C:\Scripts          # change de dossier (alias : cd)
New-Item -ItemType Directory -Name Projet
Remove-Item ancien.txt
Copy-Item a.txt b.txt
VerbeRôle
Getlire
Setmodifier
Newcréer
Removesupprimer
Start / Stop / Restartdémarrer / arrêter / redémarrer

2. Trouver de l'aide

Get-Command *service*            # quelles commandes parlent de services ?
Get-Help Get-Service -Examples   # des exemples d'utilisation
Get-Service | Get-Member         # quelles propriétés et méthodes ont ces objets ?

Ces trois commandes suffisent à tout découvrir sans quitter le terminal.

3. Le pipeline d'objets

Le tube | transmet des objets complets, avec leurs propriétés. Pas besoin de découper du texte avec cut ou awk.

Get-Service | Where-Object Status -eq "Running"                  # filtre
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, CPU
Get-ChildItem C:\Logs -Filter *.log | Measure-Object Length -Sum
Get-Process | Where-Object { $_.WorkingSet -gt 200MB } | Select-Object Name, Id
Get-Service | Group-Object Status
CmdletRôleÉquivalent Linux

Measure-Objectcompter, additionnerwc

Dans un bloc { }, $_ désigne l'objet en cours.

4. Les opérateurs de comparaison

OpérateurSens
-eq -neégal, différent
-gt -ge -lt -lesupérieur, supérieur ou égal, inférieur, inférieur ou égal
-likecorrespond à un motif avec * : -like "*.log"
-matchcorrespond à une expression régulière
-and -or -notet, ou, non

PowerShell ne tient pas compte de la casse par défaut : "ABC" -eq "abc" est vrai.

5. Exporter et mettre en forme

Get-Service | Export-Csv services.csv -NoTypeInformation -Encoding UTF8
Import-Csv utilisateurs.csv                      # chaque ligne devient un objet
Get-Process | ConvertTo-Json
Get-Service | Out-File services.txt
Get-Process | Format-Table Name, Id, CPU -AutoSize
Get-Process | Out-GridView                       # une fenêtre triable et filtrable

6. Variables et types

$nom = "Léa"                     # toutes les variables commencent par $
$age = 17
$liste = @("pc01", "pc02", "pc03")               # tableau
$compte = @{ Nom = "Léa"; Service = "SIO" }      # table de hachage (dictionnaire)
"Bonjour $nom, tu as $age ans"                   # guillemets doubles : variables remplacées
'Bonjour $nom'                                   # guillemets simples : texte littéral
"Il y a $($liste.Count) postes"                  # $( ) pour une expression
$liste[0]; $compte.Nom; $compte["Service"]

TutorielFaire l'état d'un poste

Les informations système

Get-ComputerInfo | Select-Object CsName, OsName, OsVersion

L'espace disque

Get-PSDrive -PSProvider FileSystem | Select-Object Name, @{ n = "LibreGo"; e = { [math]::Round($_.Free / 1GB, 1) } }

Les services arrêtés qui devraient tourner

Get-Service | Where-Object { $_.StartType -eq "Automatic" -and $_.Status -ne "Running" }

Un rapport dans un fichier

Get-Service | Where-Object Status -eq "Running" | Select-Object Name, DisplayName | Export-Csv rapport.csv -NoTypeInformation
À retenir

Cmdlets en Verbe-Nom : Get-, Set-, New-, Remove-.

Get-Command, Get-Help, Get-Member pour tout découvrir.

Le pipeline transmet des objets : Where-Object, Select-Object, Sort-Object.

$_ : l'objet en cours.

Comparaisons : -eq, -gt, -like, -and.
