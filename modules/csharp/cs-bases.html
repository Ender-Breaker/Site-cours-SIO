Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Le C# (« C sharp ») est le langage de la plateforme .NET de Microsoft. C'est l'un des langages les plus enseignés en option SLAM : applications de bureau (WinForms, WPF), sites et API (ASP.NET Core), jeux (Unity). Sa syntaxe est très proche de celle de Java : si tu as suivi le cours Java de ce site, tu connais déjà les trois quarts du C#.

Pour pratiquer

Installe le SDK .NET (gratuit) et Visual Studio Community ou VS Code. En ligne de commande : dotnet new console -n MonProjet, puis dotnet run.

5. Méthodes

static double Aire(double largeur, double hauteur)   // PascalCase pour les méthodes
{
    return largeur * hauteur;
}

static double Ttc(double ht, double taux = 0.2) => ht * (1 + taux);     // corps d'expression, valeur par défaut

static bool Diviser(int a, int b, out int resultat)                     // out : un second résultat
{
    resultat = b == 0 ? 0 : a / b;
    return b != 0;
}

TutorielUn inventaire en console

Lire des articles

var stock = new Dictionary<string, int>();
Console.Write("Nombre d'articles : ");
int n = int.Parse(Console.ReadLine());
for (int i = 0; i < n; i++)
{
    Console.Write("Nom : ");
    string nom = Console.ReadLine();
    Console.Write("Quantité : ");
    int qte = int.Parse(Console.ReadLine());
    stock[nom] = stock.GetValueOrDefault(nom) + qte;     // 0 si la clé est absente
}

Afficher trié

foreach (var (nom, qte) in stock.OrderBy(p => p.Key))    // OrderBy : LINQ, chapitre suivant
    Console.WriteLine($"{nom,-15}{qte,5}");              // alignement : 15 à gauche, 5 à droite
