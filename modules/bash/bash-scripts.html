Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Un script Bash est un fichier texte qui contient les commandes que tu taperais dans le terminal. L'administrateur système s'en sert pour automatiser tout ce qui se répète : sauvegardes, création de comptes, installation de serveurs, surveillance. Ce cours prolonge les chapitres Linux de la matière SISR.

1. Le premier script

#!/bin/bash
# sauvegarde.sh : mon premier script
echo "Bonjour $USER"
echo "Nous sommes le $(date +%d/%m/%Y)"
chmod +x sauvegarde.sh       # donne le droit d'exécution
./sauvegarde.sh              # lance le script
bash sauvegarde.sh           # autre façon, sans le droit x

La première ligne #!/bin/bash (le *shebang*) indique quel programme doit interpréter le fichier.

7. Le code de retour

Chaque commande renvoie un code de retour : 0 signifie succès, toute autre valeur une erreur. Il est disponible dans $? juste après la commande.

ls /etc/passwd
echo $?                      # 0 : succès
ls /dossier/inexistant
echo $?                      # 2 : erreur
exit 1                       # un script signale lui-même son échec
EnchaînementSignifie
cmd1 && cmd2cmd2 seulement si cmd1 a réussi
cmd1 || cmd2cmd2 seulement si cmd1 a échoué
cmd1 ; cmd2cmd2 dans tous les cas
mkdir /sauvegardes && echo "Dossier créé" || echo "Échec de la création"

Des mesures utiles

echo "Espace libre sur / : $(df -h / | tail -1 | awk '{print $4}')"
echo "Mémoire libre : $(free -h | awk '/Mem/ {print $7}')"
echo "Utilisateurs connectés : $(who | wc -l)"

Un argument pour choisir le dossier à mesurer

${1:-/home} : le premier argument, ou /home s'il est absent.

dossier="${1:-/home}"
echo "Taille de $dossier : $(du -sh "$dossier" 2>/dev/null | cut -f1)"
