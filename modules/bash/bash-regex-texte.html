Journaux, fichiers de configuration, exports CSV : l'administration système consiste beaucoup à chercher et transformer du texte. Les expressions régulières (*regex*) décrivent des motifs de texte ; on les retrouve à l'identique en PHP, JavaScript, Java, Python.

2. grep : chercher

grep "erreur" /var/log/syslog            # les lignes qui contiennent « erreur »
grep -i "erreur" fichier                 # sans tenir compte de la casse
grep -v "^#" /etc/ssh/sshd_config        # les lignes qui NE commencent PAS par #
grep -n "root" /etc/passwd               # avec les numéros de ligne
grep -c "Failed password" auth.log       # compte les lignes
grep -r "TODO" ~/projet                  # dans tout un dossier
grep -E "^[a-z]+:x:[0-9]{4}:" /etc/passwd    # -E : regex étendues (+, ?, {}, |)
grep -oE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+" auth.log   # -o : seulement ce qui correspond

3. sed : remplacer

sed 's/ancien/nouveau/' fichier          # remplace la 1re occurrence de chaque ligne
sed 's/ancien/nouveau/g' fichier         # g : toutes les occurrences
sed -i 's/Port 22/Port 2222/' sshd_config    # -i : modifie le fichier lui-même
sed -i.bak 's/a/b/g' fichier             # … en gardant une copie fichier.bak
sed '/^#/d' fichier                      # supprime les lignes de commentaire
sed -n '5,10p' fichier                   # affiche les lignes 5 à 10
sed -E 's/([0-9]+)-([0-9]+)/\2-\1/' f    # \1, \2 : les groupes capturés

4. awk : travailler en colonnes

awk découpe chaque ligne en champs : $1, $2… et $0 pour la ligne entière.

awk '{print $1}' fichier                 # la première colonne
awk -F: '{print $1, $7}' /etc/passwd     # -F: : le séparateur est « : »
awk -F: '$3 >= 1000 {print $1}' /etc/passwd      # condition : les comptes « humains »
df -h | awk 'NR > 1 {print $5, $6}'      # NR : numéro de ligne (on saute l'en-tête)
awk '{somme += $2} END {print somme}' ventes.txt # un total

5. Combiner avec les tubes

# Les 5 adresses IP qui échouent le plus à se connecter en SSH
grep "Failed password" /var/log/auth.log \
  | grep -oE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+" \
  | sort | uniq -c | sort -rn | head -5

# Les utilisateurs dont le shell est bash, triés
grep "bash$" /etc/passwd | cut -d: -f1 | sort

# Nombre de requêtes par code HTTP dans un journal nginx
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn

Le couple sort | uniq -c | sort -rn (trier, compter les doublons, classer) est le réflexe de base pour analyser un journal.

TutorielAnalyser les tentatives d'intrusion

Repérer les lignes

grep "Failed password" /var/log/auth.log | tail -3

Extraire l'adresse IP

grep "Failed password" /var/log/auth.log | grep -oE "[0-9]+(\.[0-9]+){3}"

Compter et classer

grep "Failed password" /var/log/auth.log \
  | grep -oE "[0-9]+(\.[0-9]+){3}" | sort | uniq -c | sort -rn | head -10
