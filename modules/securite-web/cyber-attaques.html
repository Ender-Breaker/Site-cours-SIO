Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Ce chapitre fait le tour des attaques que tu dois savoir reconnaître. Pour chacune : le principe, les signes qui la trahissent, et la parade. Les attaques propres aux sites web (injection SQL, XSS, CSRF) ont leur propre chapitre.

1. Les logiciels malveillants (*malwares*)

TypeCe qu'il faitComment il arrive
Viruss'attache à un fichier et se propage quand on l'ouvrepièce jointe, téléchargement
Ver (*worm*)se propage seul par le réseaufaille d'un service exposé
Cheval de Troiese fait passer pour un logiciel utilefaux logiciel, logiciel piraté
Rançongiciel (*ransomware*)chiffre les fichiers et exige une rançonhameçonnage, accès distant mal protégé
Logiciel espion (*spyware*), enregistreur de frappevole mots de passe et donnéescheval de Troie
Rootkitse cache au cœur du systèmeaprès une élévation de privilèges
Botnettransforme la machine en « zombie » pilotée à distancetoutes les voies ci-dessus
Porte dérobée (*backdoor*)laisse un accès secretinstallée par l'attaquant

Signes : machine lente, ventilateur qui s'emballe, fichiers renommés avec une extension inconnue, antivirus désactivé, connexions réseau vers des adresses inconnues.

Parades : mises à jour, antivirus ou EDR, pas de droits administrateur au quotidien, sauvegardes hors ligne, filtrage des pièces jointes.

Face à un rançongiciel

Débrancher la machine du réseau (câble et Wi-Fi) sans l'éteindre, prévenir le responsable, ne pas payer (aucune garantie, et cela finance les attaquants), restaurer depuis une sauvegarde saine, porter plainte.

2. Les attaques sur les mots de passe

AttaquePrincipeParade
Force bruteessayer toutes les combinaisonslongueur, blocage après N échecs
Dictionnaireessayer les mots de passe les plus courantspas de mot du dictionnaire, liste noire
*Credential stuffing*rejouer des couples identifiant / mot de passe volés ailleursun mot de passe différent par site, MFA
*Password spraying*un seul mot de passe courant essayé sur des milliers de comptesMFA, détection
Vol de la base d'empreintescasser les empreintes hors lignebcrypt / Argon2 avec sel
// Pourquoi la longueur compte plus que les symboles : le nombre de combinaisons
function combinaisons(alphabet, longueur) { return Math.pow(alphabet, longueur); }
const parSeconde = 1e10;       // dix milliards d'essais par seconde (matériel spécialisé, empreintes rapides)
const duree = n => {
  const s = n / parSeconde;
  if (s < 60) return s.toFixed(1) + " secondes";
  if (s < 86400) return (s / 3600).toFixed(1) + " heures";
  if (s < 3.15e7) return (s / 86400).toFixed(0) + " jours";
  return (s / 3.15e7).toExponential(1) + " années";
};
console.log("8 minuscules           :", duree(combinaisons(26, 8)));
console.log("8 caractères variés    :", duree(combinaisons(94, 8)));
console.log("12 caractères variés   :", duree(combinaisons(94, 12)));
console.log("phrase de 20 minuscules:", duree(combinaisons(26, 20)));

4. L'exploitation de vulnérabilités

NotionDéfinition
Faille non corrigéela vulnérabilité est connue et un correctif existe, mais n'a pas été installé : le cas le plus fréquent
Zero-dayvulnérabilité inconnue de l'éditeur : aucun correctif n'existe encore
Configuration par défautmot de passe d'usine, page d'administration exposée, service inutile actif
Élévation de privilègespasser d'un compte limité à administrateur
Attaque de la chaîne d'approvisionnementpiéger un logiciel ou une bibliothèque que la cible utilise

Parade principale : mettre à jour, vite et partout, et réduire la surface d'attaque (ce qui n'est pas installé ne peut pas être attaqué).

5. La menace interne et physique

Un employé mécontent, un prestataire trop curieux, un poste laissé déverrouillé, une clé USB trouvée sur le parking et branchée par curiosité, un visiteur qui se connecte à une prise réseau libre. Parades : moindre privilège, verrouillage automatique des sessions, journalisation, contrôle des ports réseau (802.1X), sensibilisation.

Dans un journal d'authentification

Des centaines d'échecs en quelques minutes depuis la même adresse, sur un seul compte : force brute.

Nov 13 03:12:01 srv sshd[411]: Failed password for root from 203.0.113.7 port 51122 ssh2
Nov 13 03:12:02 srv sshd[411]: Failed password for root from 203.0.113.7 port 51124 ssh2
Nov 13 03:12:03 srv sshd[411]: Failed password for root from 203.0.113.7 port 51130 ssh2

Dans un journal de serveur web

Des apostrophes, des mots-clés SQL ou des balises dans les paramètres : une tentative d'injection.

GET /produit.php?id=12'%20OR%20'1'='1 HTTP/1.1" 200
GET /recherche.php?q=<script>… HTTP/1.1" 200

Sur un poste

Des fichiers renommés rapport.docx.locked et un fichier LISEZ-MOI.txt dans chaque dossier : rançongiciel. Réflexe : isoler la machine du réseau.

À retenir
