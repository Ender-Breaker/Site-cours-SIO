Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Java est un langage orienté objet : un programme est un ensemble d'objets qui collaborent. C'est aussi le langage de référence pour apprendre les concepts objet au BTS (modélisation UML, design patterns).

1. Classe, attributs, constructeur, méthodes

class Compte {
    private String titulaire;          // attributs privés
    private double solde;

    public Compte(String titulaire, double solde) {   // constructeur
        this.titulaire = titulaire;    // this = l'objet en cours de création
        this.solde = solde;
    }

    public void deposer(double m) { if (m > 0) solde += m; }
    public double getSolde() { return solde; }        // accesseur
}

Compte c = new Compte("Léa", 100);     // new crée un objet (une instance)
c.deposer(50);

3. Héritage

class Personnage {
    protected int pv = 100;
    public void attaquer() { System.out.println("Coup de poing"); }
}

class Mage extends Personnage {           // Mage EST UN Personnage
    @Override
    public void attaquer() { System.out.println("Boule de feu"); }
}

Personnage p = new Mage();
p.attaquer();          // « Boule de feu » : polymorphisme

Toutes les classes héritent de Object, qui fournit toString(), equals(), hashCode(). Java n'autorise qu'un seul parent par classe.

4. Classes abstraites et interfaces

abstract class Forme {                    // ne peut pas être instanciée
    abstract double aire();               // à définir dans les classes filles
}
class Cercle extends Forme {
    double r;
    Cercle(double r) { this.r = r; }
    double aire() { return Math.PI * r * r; }
}

interface Affichable {                    // un contrat
    void afficher();
}
class Produit implements Affichable {
    public void afficher() { System.out.println("Produit"); }
}

5. static et la mémoire

Un attribut static est partagé par tous les objets de la classe (un compteur d'instances, une constante). La mémoire des objets est libérée automatiquement par le ramasse-miettes (garbage collector) quand plus rien ne les référence.
