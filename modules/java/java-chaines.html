1. String : un objet non modifiable

Un String est immuable : aucune méthode ne le modifie, toutes renvoient un nouveau String.

public class Main {
    public static void main(String[] args) {
        String s = "Bonjour Java";
        System.out.println(s.length());                 // 12 (avec des parenthèses, contrairement aux tableaux)
        System.out.println(s.charAt(0) + " " + s.charAt(s.length() - 1));
        System.out.println(s.toUpperCase() + " " + s.toLowerCase());
        System.out.println(s.substring(0, 7));          // de l'indice 0 inclus à 7 exclu : Bonjour
        System.out.println(s.substring(8));             // de 8 à la fin : Java
        System.out.println(s.indexOf("Java") + " " + s.indexOf("Python"));   // 8  -1
        System.out.println(s.contains("jour") + " " + s.startsWith("Bon") + " " + s.endsWith("va"));
        System.out.println(s.replace("Java", "le monde"));
        System.out.println(s);                          // inchangé !
        s = s.toUpperCase();                            // il faut réaffecter
        System.out.println(s);
    }
}

2. Comparer

public class Main {
    public static void main(String[] args) {
        String a = "java";
        String b = new String("java");
        System.out.println(a == b);                     // false : deux objets différents
        System.out.println(a.equals(b));                // true  : même contenu
        System.out.println("Java".equalsIgnoreCase("JAVA"));
        System.out.println("abc".compareTo("abd"));     // négatif : "abc" est avant "abd"
        System.out.println("".isEmpty() + " " + "   ".isBlank());
    }
}
equals, toujours

== compare les références. Il « marche » parfois par hasard (Java réutilise certains littéraux), ce qui rend le bug sournois. Pour éviter une erreur quand la variable peut être null, place la constante à gauche : "oui".equals(reponse).

3. Découper, assembler, nettoyer

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String csv = "Léa;17;SIO";
        String[] champs = csv.split(";");
        System.out.println(champs.length + " " + champs[0] + " " + Arrays.toString(champs));
        System.out.println(String.join(" | ", champs));
        System.out.println("  texte  ".trim() + "|" + "  texte  ".strip() + "|");
        System.out.println("ab".repeat(3));
        String[] mots = "un  deux   trois".trim().split("\\s+");     // \\s+ : un ou plusieurs espaces
        System.out.println(mots.length);
    }
}

4. Convertir

public class Main {
    public static void main(String[] args) {
        int n = Integer.parseInt("42") + 1;             // String → int
        double d = Double.parseDouble("3.5") * 2;       // String → double
        String s = String.valueOf(n);                   // nombre → String
        String t = "" + d;                              // raccourci courant
        System.out.println(n + " " + d + " " + s.length() + " " + t);
        System.out.println(Integer.toBinaryString(10) + " " + Integer.toHexString(255) + " " + Integer.parseInt("1010", 2));
    }
}

Integer.parseInt("abc") lève une NumberFormatException : on apprendra à l'attraper dans le chapitre sur les exceptions.

5. Les caractères

Un char est un petit entier : le code du caractère. On peut calculer avec.

public class Main {
    public static void main(String[] args) {
        char c = 'a';
        System.out.println((int) c + " " + (char) (c + 1) + " " + (char) 65);
        System.out.println(Character.isDigit('7') + " " + Character.isLetter('7') + " " + Character.toUpperCase('b'));
        String mot = "Bonjour";
        int voyelles = 0;
        for (char x : mot.toCharArray()) {
            if ("aeiouy".indexOf(x) >= 0) voyelles++;
        }
        System.out.println(voyelles);
    }
}

6. StringBuilder : construire un texte efficacement

Comme un String n'est pas modifiable, s = s + morceau dans une boucle recrée tout le texte à chaque tour. StringBuilder est une chaîne modifiable, faite pour cela.

public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) {
            sb.append(i).append(" ");           // append renvoie le StringBuilder : on enchaîne
        }
        System.out.println(sb.toString().trim());
        sb.insert(0, "Nombres : ");
        sb.setLength(sb.length() - 1);          // retire le dernier caractère
        System.out.println(sb);
        System.out.println(new StringBuilder("Java").reverse());
    }
}

TutorielAnalyser une ligne de journal (log)

Découper les champs

public class Main {
    public static void main(String[] args) {
        String ligne = "2026-11-13 14:02:55 ERREUR disque plein sur /dev/sda1";
        String[] p = ligne.split(" ", 4);        // au plus 4 morceaux : le message reste entier
        System.out.println(p[0]);
        System.out.println(p[1]);
        System.out.println(p[2]);
        System.out.println(p[3]);
    }
}

Tester le niveau et compter les mots

public class Main {
    public static void main(String[] args) {
        String ligne = "2026-11-13 14:02:55 ERREUR disque plein sur /dev/sda1";
        String[] p = ligne.split(" ", 4);
        if (p[2].equals("ERREUR")) {
            System.out.println("Alerte : " + p[3].toUpperCase());
        }
        System.out.println(p[3].split("\\s+").length + " mots");
    }
}

Masquer une information sensible

replaceAll accepte une expression régulière : ici, quatre groupes de chiffres séparés par des points.

public class Main {
    public static void main(String[] args) {
        String ligne = "connexion refusée depuis 192.168.1.42 puis 10.0.0.7";
        String propre = ligne.replaceAll("\\d+\\.\\d+\\.\\d+\\.\\d+", "[IP masquée]");
        System.out.println(propre);
        System.out.println("192.168.1.42".matches("\\d+\\.\\d+\\.\\d+\\.\\d+"));
    }
}
