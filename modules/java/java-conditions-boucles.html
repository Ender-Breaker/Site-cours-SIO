Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Conditions

if (note >= 16) {
    System.out.println("Très bien");
} else if (note >= 10) {
    System.out.println("Admis");
} else {
    System.out.println("Recalé");
}
String statut = age >= 18 ? "majeur" : "mineur";

Opérateurs : == != < > <= >=, &&, ||, !. La condition doit être un boolean : if (n) ne compile pas.

2. switch

switch (jour) {                     // fonctionne aussi avec des String
    case "samedi", "dimanche" -> System.out.println("Week-end");
    default -> System.out.println("Semaine");
}

String type = switch (note / 5) {   // switch-expression (Java 14+)
    case 4 -> "excellent";
    case 2, 3 -> "moyen";
    default -> "faible";
};

3. Boucles

for (int i = 1; i <= 10; i++) {
    System.out.print(i + " ");
}

int n = 100;
while (n > 1) n /= 2;

do {
    x = sc.nextInt();
} while (x < 0);

int[] notes = {12, 15, 9};
for (int note : notes) {            // boucle « pour chaque »
    System.out.println(note);
}

break sort de la boucle, continue passe au tour suivant.
