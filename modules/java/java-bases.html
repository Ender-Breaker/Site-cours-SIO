Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Java (1995) est un langage orienté objet très utilisé en entreprise (applications de gestion, serveurs avec Spring), pour Android et pour Minecraft (édition Java). Son principe : « écrire une fois, exécuter partout ». Le code est compilé en bytecode que la machine virtuelle Java (JVM) exécute sur n'importe quel système.

1. Le programme minimal

public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour !");
    }
}
  • Tout le code est dans une classe ; le fichier porte son nom (Main.java).
  • main est le point d'entrée. static : elle appartient à la classe, pas à un objet.
  • System.out.println affiche et passe à la ligne ; print n'y passe pas.
javac Main.java     # compile en Main.class (bytecode)
java Main           # exécute sur la JVM

Le labo compile ton code avec un vrai javac directement dans le navigateur.

2. Types primitifs et String

int age = 19;

char lettre = 'A';
long grand = 3_000_000_000L;
String nom = "Léa";            // String est une classe (majuscule !)
final double TVA = 0.2;        // constante
var total = 12.5;              // type déduit (Java 10+)
Division entière et comparaison de textes

7 / 2 vaut 3 entre deux int. Et deux String se comparent avec a.equals(b), jamais avec == (qui compare les références).

3. Lire au clavier avec Scanner

import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();          // un entier
double d = sc.nextDouble();    // un décimal
String mot = sc.next();        // un mot
String ligne = sc.nextLine();  // une ligne
