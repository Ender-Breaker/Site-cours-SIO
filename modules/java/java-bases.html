Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Java (1995) est l'un des langages les plus utilisés au monde : applications d'entreprise, serveurs web, applications Android, logiciels bancaires, Minecraft. Sa devise : *écrire une fois, exécuter partout*. Il est typé, orienté objet de bout en bout, et sa syntaxe ressemble beaucoup à celle du C# que l'on rencontre aussi en BTS SIO : apprendre l'un, c'est presque connaître l'autre.

Comment suivre ce cours

Chaque bloc avec un bouton Exécuter est compilé par le vrai compilateur javac dans ton navigateur. Modifie le code, provoque des erreurs, lis les messages : c'est la meilleure façon d'apprendre.

2. Compiler et exécuter : la JVM

javac Main.java     # compile : produit Main.class (du bytecode)
java Main           # la machine virtuelle Java (JVM) exécute le bytecode

Le compilateur ne produit pas un programme pour un processeur précis, mais du bytecode exécuté par la JVM. Le même fichier .class tourne sur Windows, Linux, macOS : il suffit d'avoir une JVM. Le JDK contient le compilateur et les outils ; le JRE seulement de quoi exécuter.

3. Variables et types primitifs

Chaque variable a un type fixé à sa déclaration.

public class Main {
    public static void main(String[] args) {
        int age = 17;                 // entier
        double prix = 19.99;          // nombre à virgule
        char initiale = 'L';          // UN caractère, entre apostrophes
        boolean majeur = false;       // true ou false
        String prenom = "Léa";        // texte, entre guillemets (String est une classe : majuscule)
        long population = 8_000_000_000L;   // très grand entier (suffixe L)
        System.out.println(prenom + " a " + age + " ans");     // + colle les textes
        System.out.println(prix + " " + initiale + " " + majeur + " " + population);
        age = age + 1;
        System.out.println(age);
    }
}
TypeContenuExemple
intentier (environ ±2 milliards)42
longtrès grand entier9000000000L
doublenombre à virgule3.14
booleanvrai ou fauxtrue
charun caractère'A'
Stringtexte (un objet, pas un type primitif)"Bonjour"

final et var

public class Main {
    public static void main(String[] args) {
        final double TVA = 0.2;       // constante : ne peut plus être modifiée
        var quantite = 3;             // var : le compilateur déduit int (Java 10+)
        var total = quantite * 9.99;  // … et ici double
        System.out.println(total * (1 + TVA));
    }
}

4. Les opérateurs et leurs pièges

public class Main {
    public static void main(String[] args) {
        System.out.println(7 / 2);            // 3   : entier / entier = entier !
        System.out.println(7 / 2.0);          // 3.5 : dès qu'un des deux est double
        System.out.println(7 % 2);            // 1   : reste de la division
        int a = 7, b = 2;
        System.out.println((double) a / b);   // 3.5 : conversion explicite (cast)
        System.out.println((int) 3.99);       // 3   : le cast vers int TRONQUE
        int i = 5;
        i++;            // i = i + 1
        i += 10;        // i = i + 10
        System.out.println(i);
        System.out.println("Total : " + 2 + 3);      // Total : 23  (concaténation de gauche à droite)
        System.out.println("Total : " + (2 + 3));    // Total : 5
        System.out.println(Math.pow(2, 10) + " " + Math.sqrt(49) + " " + Math.round(2.5) + " " + Math.max(3, 8));
    }
}
Division entière et concaténation

7 / 2 vaut 3. Et dès qu'un String apparaît dans une addition, tout ce qui suit est collé comme du texte : mets les calculs entre parenthèses.

5. Lire au clavier : Scanner

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String prenom = sc.nextLine();        // une ligne de texte
        int age = sc.nextInt();               // un entier
        System.out.println("Bonjour " + prenom + ", dans 10 ans tu auras " + (age + 10) + " ans.");
    }
}
MéthodeLit
nextInt()un entier
nextDouble()un nombre à virgule
next()un mot (jusqu'au prochain espace)
nextLine()toute la ligne
hasNext()vrai s'il reste quelque chose à lire
Le piège de nextInt suivi de nextLine

nextInt() laisse le retour à la ligne dans le tampon : le nextLine() suivant renvoie alors une chaîne vide. Ajoute un sc.nextLine(); « pour rien » après le nextInt().

6. Mettre en forme : printf et String.format

public class Main {
    public static void main(String[] args) {
        double prix = 12.5;
        System.out.printf("%.2f €%n", prix);                  // 12.50 €   (%n = retour à la ligne)
        System.out.printf("%s a %d ans%n", "Léa", 17);        // %s texte, %d entier
        System.out.printf("|%5d|%-5d|%05d|%n", 42, 42, 42);   // largeur, gauche, zéros
        String texte = String.format("%.1f %%", 45.678);      // même chose, mais renvoie un String
        System.out.println(texte);
    }
}

Ajouter la TVA et mettre en forme

Essaie de modifier TVA après sa déclaration : le compilateur refuse.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        final double TVA = 0.2;
        Scanner sc = new Scanner(System.in);
        double prix = sc.nextDouble();
        int quantite = sc.nextInt();
        double ht = prix * quantite;
        System.out.printf("HT : %.2f €%n", ht);
        System.out.printf("TVA : %.2f €%n", ht * TVA);
        System.out.printf("TTC : %.2f €%n", ht * (1 + TVA));
    }
}
