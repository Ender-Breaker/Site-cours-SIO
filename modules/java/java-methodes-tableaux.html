1. Écrire une méthode

En Java, une fonction s'appelle une méthode et appartient toujours à une classe. Pour l'instant, nos méthodes sont static : on les appelle directement, sans créer d'objet.

public class Main {
    static double aire(double largeur, double hauteur) {
        return largeur * hauteur;
    }

    static void saluer(String nom) {            // void : ne renvoie rien
        System.out.println("Bonjour " + nom + " !");
    }

    static boolean estPair(int n) {
        return n % 2 == 0;
    }

    public static void main(String[] args) {
        System.out.println(aire(3, 4.5));
        saluer("Léa");
        System.out.println(estPair(7) + " " + estPair(8));
    }
}

La signature annonce le type de retour, le nom, puis le type de chaque paramètre. L'ordre des méthodes dans la classe n'a pas d'importance.

2. Surcharge

Plusieurs méthodes peuvent porter le même nom si leurs paramètres diffèrent.

public class Main {
    static int maxi(int a, int b) { return a > b ? a : b; }
    static double maxi(double a, double b) { return a > b ? a : b; }
    static int maxi(int a, int b, int c) { return maxi(maxi(a, b), c); }

    public static void main(String[] args) {
        System.out.println(maxi(3, 8) + " " + maxi(2.5, 1.5) + " " + maxi(4, 9, 2));
    }
}

3. Passage des arguments

Java passe toujours par valeur. Pour un type primitif, la méthode reçoit une copie du nombre. Pour un objet ou un tableau, elle reçoit une copie de la référence : elle peut donc modifier le contenu de l'objet, mais pas remplacer l'objet de l'appelant.

public class Main {
    static void doubler(int n) { n = n * 2; }              // modifie une copie : sans effet
    static void doublerTout(int[] t) {                     // modifie le tableau d'origine
        for (int i = 0; i < t.length; i++) t[i] *= 2;
    }

    public static void main(String[] args) {
        int x = 5;
        doubler(x);
        System.out.println(x);                 // 5
        int[] notes = {1, 2, 3};
        doublerTout(notes);
        System.out.println(notes[0] + " " + notes[1] + " " + notes[2]);    // 2 4 6
    }
}

4. Récursivité

public class Main {
    static long factorielle(int n) {
        if (n <= 1) return 1;                  // cas d'arrêt
        return n * factorielle(n - 1);         // appel récursif
    }

    public static void main(String[] args) {
        System.out.println(factorielle(5) + " " + factorielle(20));
    }
}

5. Les tableaux

Un tableau contient un nombre fixe d'éléments du même type. Les indices vont de 0 à length - 1.

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notes = {12, 15, 9};              // tableau initialisé
        double[] prix = new double[4];          // 4 cases, toutes à 0.0
        String[] noms = new String[2];          // 2 cases, toutes à null
        notes[1] = 16;
        prix[0] = 9.99;
        System.out.println(notes[0] + " " + notes.length);     // length SANS parenthèses
        System.out.println(Arrays.toString(notes));            // affichage lisible
        System.out.println(Arrays.toString(prix) + " " + noms[0]);

        int somme = 0;
        for (int n : notes) somme += n;                        // parcours for-each
        System.out.println("Moyenne : " + (double) somme / notes.length);
        for (int i = notes.length - 1; i >= 0; i--) System.out.print(notes[i] + " ");   // à l'envers
        System.out.println();
    }
}
Sortir des bornes

notes[3] sur un tableau de 3 éléments lève l'exception ArrayIndexOutOfBoundsException et arrête le programme. Le dernier indice valide est toujours length - 1.

La boîte à outils Arrays

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] t = {5, 2, 8, 1};
        Arrays.sort(t);                                      // trie sur place
        System.out.println(Arrays.toString(t));
        int[] copie = Arrays.copyOf(t, t.length);            // vraie copie
        copie[0] = 99;
        System.out.println(t[0] + " " + copie[0]);
        int[] meme = t;                                      // PAS une copie : même tableau
        meme[0] = -1;
        System.out.println(t[0]);
        System.out.println(Arrays.equals(t, copie));
        Arrays.fill(copie, 7);
        System.out.println(Arrays.toString(copie));
    }
}

6. Tableaux à deux dimensions

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[][] grille = new int[3][4];            // 3 lignes, 4 colonnes, remplies de 0
        grille[1][2] = 7;
        for (int[] ligne : grille) {
            System.out.println(Arrays.toString(ligne));
        }
        int[][] triangle = {{1}, {1, 1}, {1, 2, 1}};       // lignes de longueurs différentes
        System.out.println(triangle[2][1] + " " + triangle.length + " " + triangle[2].length);
    }
}

Renvoyer deux résultats dans un tableau

Une méthode ne renvoie qu'une valeur ; cette valeur peut être un tableau.

import java.util.Arrays;

public class Main {
    static double[] minMax(double[] t) {
        double mini = t[0], maxi = t[0];
        for (double v : t) {
            if (v < mini) mini = v;
            if (v > maxi) maxi = v;
        }
        return new double[]{mini, maxi};
    }

    public static void main(String[] args) {
        double[] r = minMax(new double[]{12, 5, 19, 8});
        System.out.println(r[0] + " " + r[1]);
    }
}

Composer les méthodes

public class Main {
    static double moyenne(double[] t) {
        double s = 0;
        for (double v : t) s += v;
        return s / t.length;
    }
    static int auDessus(double[] t, double seuil) {
        int n = 0;
        for (double v : t) if (v > seuil) n++;
        return n;
    }

    public static void main(String[] args) {
        double[] notes = {12, 5, 19, 8, 10};
        System.out.println(auDessus(notes, moyenne(notes)) + " notes au-dessus de la moyenne");
    }
}
