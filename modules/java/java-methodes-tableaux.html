1. Les méthodes

public class Main {
    static int carre(int x) {            // type de retour, nom, paramètres typés
        return x * x;
    }
    static void afficherLigne(int n) {   // void : ne renvoie rien
        System.out.println("-".repeat(n));
    }
    public static void main(String[] args) {
        System.out.println(carre(5));
        afficherLigne(10);
    }
}

Les méthodes appelées depuis main sans objet doivent être static. Plusieurs méthodes peuvent avoir le même nom avec des paramètres différents (surcharge).

Java passe toujours les paramètres par valeur : pour un int, une copie ; pour un objet ou un tableau, une copie de la référence, donc la méthode peut modifier son contenu.

3. ArrayList : la liste qui grandit

import java.util.ArrayList;

ArrayList<String> noms = new ArrayList<>();
noms.add("Léa");
noms.add("Tom");
noms.get(0)          // "Léa"
noms.size()          // 2
noms.remove("Tom");
noms.contains("Léa") // true
for (String n : noms) System.out.println(n);

ArrayList<Integer> nombres = new ArrayList<>();   // Integer, pas int
Tableau ou ArrayList ?

Tableau : taille connue et fixe, types primitifs, rapide. ArrayList : taille variable, méthodes pratiques, mais seulement des objets (Integer, Double… les « enveloppes » des types primitifs).
