Java a servi à écrire Minecraft et de nombreux jeux Android. Sur ordinateur, on utilise des bibliothèques comme libGDX ou LWJGL ; dans le labo, ton code Java est compilé dans le navigateur (javac, puis TeaVM qui le traduit en WebAssembly) et dessine dans un canvas.

1. La structure d'un jeu

public class Main extends Jeu {
    double x = 200;                       // l'état du jeu : des attributs

    public void setup() {                 // une fois au démarrage
    }

    public void update(double dt) {       // 60 fois par seconde : logique
        if (touche("droite")) x += 5;
    }

    public void draw() {                  // 60 fois par seconde : dessin
        effacer("black");
        rect(x, 140, 40, 40, "blue");
    }

    public static void main(String[] args) {
        lancer(new Main());               // démarre la boucle de jeu
    }
}

La classe abstraite Jeu (fournie par le labo) contient la boucle et les méthodes de dessin. Tu en hérites et tu redéfinis setup, update et draw : c'est le patron de conception méthode modèle.

2. Des objets pour les entités

import java.util.ArrayList;

class Ennemi {
    double x, y, vitesse;
    Ennemi(double x, double vitesse) { this.x = x; this.y = 0; this.vitesse = vitesse; }
    void avancer() { y += vitesse; }
    boolean sorti() { return y > Jeu.HAUTEUR; }
}

public class Main extends Jeu {
    ArrayList<Ennemi> ennemis = new ArrayList<>();
    int score = 0;

    public void update(double dt) {
        if (hasard(1, 30) == 1) ennemis.add(new Ennemi(hasard(20, 460), hasard(2, 5)));
        for (Ennemi e : ennemis) e.avancer();
        ennemis.removeIf(Ennemi::sorti);           // retire ceux qui sont sortis
    }

    public void draw() {
        effacer("black");
        for (Ennemi e : ennemis) cercle(e.x, e.y, 10, "red");
        texte("Score : " + score, 10, 10, 20, "white");
    }

    public static void main(String[] args) { lancer(new Main()); }
}
Supprimer en parcourant

Retirer un élément d'une ArrayList pendant un for (Ennemi e : ennemis) provoque une ConcurrentModificationException. Utilise removeIf ou un Iterator.

3. Collisions et états

boolean collision(double ax, double ay, double aw, double ah,
                  double bx, double by, double bw, double bh) {
    return ax < bx + bw && ax + aw > bx && ay < by + bh && ay + ah > by;
}

enum Etat { MENU, JEU, PERDU }
Etat etat = Etat.MENU;

Une énumération représente proprement les états du jeu ; update et draw font un switch (etat).
