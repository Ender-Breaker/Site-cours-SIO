Linux sait lire, filtrer, trier et transformer du texte avec de petites commandes qu'on enchaîne. C'est la force du shell : chaque commande fait une chose, et les redirections et pipes les assemblent.

1. Lire un fichier

CommandeEffet
cat faffiche tout le fichier
less fpage par page : espace = suite, q = quitter, /mot puis n pour chercher
head f · head -5 fles 10 (ou 5) premières lignes
tail f · tail -15 fles 10 (ou 15) dernières lignes
wc -l fnombre de lignes (-w : mots, -c : caractères)

2. Chercher avec grep

grep mot fichier          # lignes contenant « mot » (sensible à la casse)
grep -i mot fichier       # ignore la casse
grep -v mot fichier       # lignes qui NE correspondent PAS
grep -n mot fichier       # préfixe par le numéro de ligne
grep -c mot fichier       # compte les lignes trouvées
grep -i 'deux mots' f     # phrase entre apostrophes

3. Redirections

Par défaut, une commande lit le clavier et écrit à l'écran. On peut changer ça :

SyntaxeEffet
cmd > fécrit la sortie dans f (écrase le contenu)
cmd >> fajoute à la fin de f
cmd < fl'entrée vient du fichier f
cat f1 f2 > f0concatène f1 et f2 dans f0
> écrase !

echo bonjour > notes.txt remplace tout le contenu de notes.txt. Pour conserver l'existant, utilise >>.

4. Les pipes

Le pipe | envoie la sortie d'une commande vers l'entrée de la suivante : cmd1 | cmd2.

who | wc -l                         # nombre d'utilisateurs connectés
grep banane liste.txt | wc -l       # combien de lignes avec « banane »
sort liste.txt | head -3            # les 3 premières après tri

5. Trier et extraire

CommandeEffet
sorttri alphabétique (-r inverse, -n numérique, -u supprime les doublons)
cut -d';' -f1 f.csvgarde le champ n° 1, séparateur ;
cut -d';' -f1,3 f.csvchamps 1 et 3
cut -d: -f1 /etc/passwdexemple : les noms des comptes

Exemple complet

# noms des élèves, triés à l'envers, enregistrés dans un fichier
cut -d';' -f1 eleves.csv | sort -r > res.txt
wc -l res.txt      # vérifie le nombre de lignes
cat res.txt        # contrôle visuel
Résumé express
  • Lire : cat, less, head, tail, wc.
  • Filtrer : grep (-i -v -n -c).
  • Rediriger : > écrase, >> ajoute, < lit un fichier.
  • Chaîner : cmd1 | cmd2.
  • Trier/extraire : sort (-r -n -u), cut -d';' -f1.
