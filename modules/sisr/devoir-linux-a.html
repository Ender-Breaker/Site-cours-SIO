Ce chapitre reprend le devoir Linux A (novembre 2026) avec une solution commentée pour chacun des quatre exercices, les erreurs qui ont coûté le plus de points et un récapitulatif. D'autres solutions étaient acceptées si elles donnaient exactement le même résultat avec les commandes demandées.

Pour s'entraîner

Le labo Devoir Linux A rejoue tout le sujet dans un terminal simulé, avec le même fichier employes.csv et le même dossier projet_web : chaque consigne est vérifiée automatiquement.

1. Arborescence et fichiers

Le script travaille dans ~/ex1. Une solution possible :

#!/bin/bash
cd ~/ex1

# 1. Arborescence : -p crée les dossiers parents manquants
mkdir -p Agence/Direction Agence/Compta Agence/Informatique/Serveurs Agence/Informatique/Postes Agence/Temp

# 2. Fichiers vides
touch Agence/Direction/notes.txt Agence/Compta/factures.txt

# 3. et 4. Fichiers avec contenu : > crée le fichier et écrit dedans
echo "Serveur web principal" > Agence/Informatique/Serveurs/web01.txt
echo "Poste a installer" > Agence/brouillon.txt

# 5. Copie : le fichier reste aussi dans Compta
cp Agence/Compta/factures.txt Agence/Direction/

# 6. Renommer = déplacer vers un nouveau nom dans le même dossier
mv Agence/Direction/notes.txt Agence/Direction/compte_rendu.txt

# 7. Déplacer ET renommer en une seule commande
mv Agence/brouillon.txt Agence/Informatique/Postes/poste01.txt

# 8. Supprimer un dossier vide
rmdir Agence/Temp

# 9. Date de modification au format AAAAMMJJhhmm
touch -t 202601150900 Agence/Compta/factures.txt

# 10. Compter les fichiers seulement (-type f), écrire le nombre seul
find Agence -type f | wc -l > nb_fichiers.txt

# 11. Affichage détaillé (-l) et récursif (-R)
ls -lR Agence

# Bonus : taille en octets, nombre seul
wc -c < Agence/Informatique/Serveurs/web01.txt

Résultats attendus : nb_fichiers.txt contient 5 et le bonus affiche 22 (21 caractères plus le retour à la ligne ajouté par echo).

L'étape 1 peut tenir en une ligne grâce aux accolades :

mkdir -p Agence/{Direction,Compta,Temp,Informatique/{Serveurs,Postes}}
Erreurs fréquentes
  • ls -R Agence | wc -l compte aussi les dossiers, les titres de section et les lignes vides.
  • wc -l fichier affiche le nombre suivi du nom du fichier ; wc -l < fichier ou … | wc -l donne le nombre seul.
  • Oublier -p : mkdir Agence/Informatique/Serveurs échoue tant que Agence/Informatique n'existe pas.
  • cp puis rm à l'étape 7 : même résultat, mais la consigne demandait une seule commande, c'est le rôle de mv.
  • Oublier #!/bin/bash en première ligne, ou chmod +x ex1.sh avant de lancer le script.

2. Utilisateurs, groupes et droits

Ce script se lance avec sudo ./ex2.sh : toutes ses commandes tournent en root.

#!/bin/bash
# 1. Groupes (-f : pas d'erreur si le groupe existe déjà)
groupadd -f compta
groupadd -f rh

# 2. Utilisateurs : -m crée /home/nom, -s choisit le shell
useradd -m -s /bin/bash alice
useradd -m -s /bin/bash bob
useradd -m -s /bin/bash chloe

# 3. Ajout aux groupes : -a (append) est indispensable
usermod -aG compta alice
usermod -aG rh bob
usermod -aG compta,rh chloe

# 4. Commentaire
usermod -c "Service comptabilite" alice

# 5. Dossiers, propriétaires, droits
mkdir -p /srv/agence/compta /srv/agence/rh /srv/agence/commun
chown alice:compta /srv/agence/compta
chown bob:rh /srv/agence/rh
chmod 770 /srv/agence/compta /srv/agence/rh
chmod 755 /srv/agence/commun

# 6. Fichier protégé, notation symbolique
echo "Budget 2027 : 150000 euros" > /srv/agence/compta/budget.txt
chown alice:compta /srv/agence/compta/budget.txt
chmod u=rw,g=r,o= /srv/agence/compta/budget.txt

# 7. Vérification
ls -l /srv/agence /srv/agence/compta
id alice
id bob
id chloe

Chaque chiffre octal est la somme r = 4, w = 2, x = 1, dans l'ordre propriétaire, groupe, autres.

NotationPropriétaireGroupeAutresUsage
770rwxrwx---dossiers compta et rh, réservés au service
755rwxr-xr-xdossier commun, lisible par tous
640 = u=rw,g=r,o=rw-r-----budget.txt

Bonus : sudo -u bob cat /srv/agence/compta/budget.txt est refusé (« Permission denied »). bob n'est ni le propriétaire ni membre de compta : il fait partie des « autres », qui n'ont aucun droit sur le dossier (770). Il ne peut même pas y entrer.

Erreurs fréquentes
  • usermod -G sans -a remplace tous les groupes secondaires : après usermod -G compta chloe puis usermod -G rh chloe, chloe n'est plus que dans rh.
  • Oublier -m : l'utilisateur est créé sans dossier personnel.
  • chmod 640 au lieu de la notation symbolique demandée : même résultat, consigne non respectée.
  • Oublier le chown de budget.txt : créé par sudo, il appartient alors à root.

3. Exploiter un CSV avec cut

cut -d';' -f2 découpe chaque ligne à chaque ; et garde le 2e morceau. tail -n +2 retire la ligne d'en-tête. Le pipe | passe le résultat d'une commande à la suivante.

Colonnes du fichier :

id;nom;prenom;service;ville;date_embauche;salaire;email
#!/bin/bash
cd ~/ex3
cp /mnt/DevoirLinux-2026/employes.csv .
mkdir -p resultats

wc -l < employes.csv > resultats/q1.txt
head -n 1 employes.csv > resultats/q2.txt
tail -n +2 employes.csv | cut -d';' -f2 > resultats/q3.txt
tail -n +2 employes.csv | cut -d';' -f2,3 > resultats/q4.txt
cut -d';' -f1-4 employes.csv > resultats/q5.txt
cut -d';' -f1-6,8 employes.csv > resultats/q6.txt
tail -n +2 employes.csv | cut -d';' -f4 | sort -u > resultats/q7.txt
tail -n +2 employes.csv | cut -d';' -f4 | grep -x "Informatique" | wc -l > resultats/q8.txt
tail -n +2 employes.csv | cut -d';' -f6 | cut -c1-4 | sort -u > resultats/q9.txt
tail -n +2 employes.csv | cut -d';' -f5 | sort | uniq -c > resultats/q10.txt
grep ";Lyon;" employes.csv | cut -d';' -f8 | cut -d'@' -f1 | sort > resultats/q11.txt
cut -d: -f1,7 /etc/passwd > resultats/q12.txt
tail -n +2 employes.csv | sort -t';' -k7 -n | tail -n 1 | cut -d';' -f2,7 > resultats/q13.txt

Erreurs fréquentes
  • Oublier l'en-tête : « nom » ou « service » apparaît dans la liste.
  • uniq -c sans sort avant : uniq ne regroupe que les lignes identiques qui se suivent, donc une ville apparaît plusieurs fois.
  • Oublier -d : sans séparateur, cut utilise la tabulation et renvoie la ligne entière.
  • Écrire la réponse à la main (echo 10 > q8.txt) : le résultat est juste, mais il fallait le calculer avec les commandes.
  • grep "Lyon" sans les ; attraperait aussi un nom ou un e-mail contenant « Lyon ».

4. Script de sauvegarde et archivage

Le script sauvegarde.sh

#!/bin/bash
# Usage : ./sauvegarde.sh projet_web    ($1 vaut alors "projet_web")
mkdir -p ~/ex4/sauvegardes
tar -czf ~/ex4/sauvegardes/backup_$(date +%Y%m%d).tar.gz "$1"
tar -tzf ~/ex4/sauvegardes/backup_$(date +%Y%m%d).tar.gz > ~/ex4/sauvegardes/contenu.txt
wc -l < ~/ex4/sauvegardes/contenu.txt > ~/ex4/sauvegardes/nb_elements.txt
echo "Sauvegarde de $1 terminee le $(date)"
  • $1 est le premier paramètre donné au script.
  • $(date +%Y%m%d) est remplacé par le résultat de la commande, par exemple 20261110.
  • Options de tar : c créer, t lister, x extraire, z compresser avec gzip, f nom du fichier archive.

Les commandes tapées au terminal (depuis ~/ex4)

# Étape 1 : -r copie le dossier et tout son contenu
cp -r /mnt/DevoirLinux-2026/projet_web .

# Étape 2
chmod +x sauvegarde.sh
./sauvegarde.sh projet_web                 # nb_elements.txt contient 12

# Étape 3 : --exclude se place AVANT le nom du dossier
tar --exclude='*.log' -czf sauvegardes/backup_sans_logs.tar.gz projet_web
tar -tzf sauvegardes/backup_sans_logs.tar.gz       # vérification : aucun .log

# Étape 4 : on extrait un seul dossier en le nommant à la fin
rm -r projet_web/config
tar -xzf sauvegardes/backup_20261110.tar.gz projet_web/config

# Étape 5 : $( ) fournit la liste des services à mkdir
mkdir services && cd services
mkdir $(tail -n +2 /mnt/DevoirLinux-2026/employes.csv | cut -d';' -f4 | sort -u)

# Bonus : 7 = rwx pour le propriétaire, 0 pour les autres
chmod 700 Direction
Erreurs fréquentes
  • --exclude après le nom du dossier : tar l'ignore sans erreur, et les .log restent dans l'archive.
  • Chemin absolu (./sauvegarde.sh ~/ex4/projet_web) : l'archive contient home/nom/ex4/projet_web/… et tar -xzf … projet_web/config ne trouve plus rien.
  • wc -l contenu.txt ajoute le nom du fichier après le nombre.
  • Ne pas supprimer config avant de le restaurer : on n'a alors jamais vérifié que la restauration fonctionne.
  • Taper les noms des services à la main à l'étape 5 : il fallait les extraire du CSV.
