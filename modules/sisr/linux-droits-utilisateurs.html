Sous Linux, chaque fichier a un propriétaire, un groupe et des droits qui disent qui peut lire, modifier ou exécuter. C'est la base de la sécurité d'un serveur.

2. Modifier les droits avec chmod

Notation symbolique

chmod go-rwx f      # retire tout au groupe et aux autres
chmod a+rw f        # donne lecture/écriture à tous
chmod u+x script.sh # rend exécutable pour le propriétaire

u propriétaire, g groupe, o autres, a tous ; + ajoute, - retire, = fixe.

Notation octale

On additionne r=4, w=2, x=1 pour chaque catégorie (user, group, other) :

OctalDroitsUsage typique
755rwxr-xr-xprogramme, dossier public
644rw-r--r--fichier lisible par tous
600rw-------fichier privé
640rw-r-----lisible par le groupe
chmod 755 f
chmod -R 644 dossier/   # -R : applique à tout l'arbre

3. Propriétaire et groupe

CommandeEffet
sudo chown user fchange le propriétaire (réservé à root)
sudo chown -R user didem pour tout le dossier
sudo chown user:groupe fpropriétaire et groupe d'un coup
chgrp -R groupe dchange seulement le groupe

4. Utilisateurs et groupes

CommandeEffet
sudo adduser nomcrée l'utilisateur, son groupe du même nom et son dossier personnel
sudo useradd -m -G g1 nom-m crée le home, -G ajoute des groupes supplémentaires
sudo groupadd gcrée un groupe
sudo usermod -aG g nomajoute nom au groupe g (-a obligatoire, sinon les autres groupes sont remplacés)
id nom · groups nomaffiche uid et groupes

Les comptes sont dans /etc/passwd, les groupes dans /etc/group.

sudo

sudo exécute une commande avec les droits d'administrateur. Un utilisateur normal qui essaie adduser sans sudo reçoit « Permission non accordée ».

Résumé express
  • ls -l : -rwxrw-r-- = type, user, group, other.
  • chmod en symbolique (go-rwx, a+rw) ou octal (755, 644, 600) ; -R récursif.
  • chown user:groupe, chgrp ; adduser, groupadd, usermod -aG, id.
