Un serveur Linux n'a souvent pas d'interface graphique : on le pilote en ligne de commande, dans un terminal. Ce chapitre pose les bases : l'invite, l'aide, l'arborescence et la manipulation de fichiers.

Essaie tout de suite

Le terminal ci-dessous est simulé : il fonctionne vraiment (fichiers, dossiers, droits…) mais ne touche à rien de réel. Tape ls, pwd, cat notes.txt… Tab complète les noms, ↑ rappelle l'historique.

1. Le système Unix en 30 secondes

  • Le noyau gère la mémoire, les fichiers et les programmes. Le shell est l'interface entre toi et le noyau : il interprète ce que tu tapes.
  • Tout est fichier ou processus : un dossier est un fichier spécial, un processus est un programme en cours (identifié par un PID).
  • L'arborescence est un arbre inversé dont la racine est /.
  • Unix est sensible à la casse : fichier.txt, Fichier.txt et FICHIER.TXT sont trois fichiers différents.
  • Rien n'est exécuté avant d'avoir appuyé sur Entrée.

2. L'invite de commande

etu@lab:~/docs$
PartieSignification
etunom de l'utilisateur (commande whoami)
labnom de l'hôte, c'est-à-dire de l'ordinateur (commande hostname)
~/docsrépertoire courant (commande pwd pour le chemin absolu)
$ ou #$ = utilisateur normal ; # = super-utilisateur (root)

Le symbole ~ désigne le dossier personnel de l'utilisateur (son « home »).

Quelle commande pour chercher un fichier ?

find cherche un fichier dans une arborescence : find /etc -name "*.conf". (apropos fichier t'aurait aussi mis sur la piste.)

4. Se déplacer dans l'arborescence

CommandeEffet
pwdaffiche le chemin absolu du dossier courant
lsliste le dossier courant
ls -ainclut les fichiers cachés (dont le nom commence par .)
ls -lformat long : droits, propriétaire, taille, date
cd dossierentre dans le dossier
cd ou cd ~retourne au dossier personnel
cd ..monte d'un niveau (dossier parent)
cd .reste ici (. = dossier courant)

Chemin absolu et chemin relatif

  • Absolu : commence par / (ou ~), marche depuis n'importe où : ls /home/etu/docs, ls ~/docs.
  • Relatif : part du dossier courant : ls docs/backups, ls ../autre.

5. Créer, copier, déplacer, supprimer

CommandeEffet
mkdir nomcrée un dossier (mkdir -p a/b/c crée toute la chaîne)
touch fcrée un fichier vide
cp f1 f2copie f1 sous le nom f2 ; cp f dossier/ copie dedans ; cp -r d1 d2 copie un dossier entier
mv f1 f2renomme ou déplace (mv f dossier/)
rm fsupprime un fichier (sans corbeille !)
rmdir dsupprime un dossier vide seulement
rm -r dsupprime un dossier et son contenu
clearvide l'écran
Pas de corbeille

rm est définitif. Relis ta commande avant d'appuyer sur Entrée, surtout avec rm -r ou un joker.

6. Les jokers

JokerSignificationExemple
*zéro ou plusieurs caractèresls list* ; rm *.csv
?exactement un caractèrels ?ouse → house, mouse

Côté noms de fichiers : évite / * & % et les espaces ; privilégie lettres, chiffres, _ et .. L'extension (.c, .txt) indique le contenu par convention.

7. Gagner du temps

  • Tab complète un nom de commande, de fichier ou de dossier ; Tab Tab liste les choix.
  • ↑ ↓ rappellent les commandes déjà tapées ; history les liste avec leur numéro.
  • !! rappelle la dernière commande, !5 la n° 5, !-3 la 3ᵉ plus récente, !grep la dernière qui commençait par grep.
  • tree donne une vue graphique de l'arborescence (à installer : apt install tree).
Résumé express
  • Invite : utilisateur@hôte:dossier$ (# = root). whoami, hostname, pwd.
  • Aide : man, whatis, apropos, type.
  • Navigation : cd, cd .., cd ~, ls -a -l ; chemins absolus (/) et relatifs.
  • Fichiers : mkdir -p, touch, cp -r, mv, rm -r, jokers * et ?.
  • Confort : Tab, flèches, history, !!.
