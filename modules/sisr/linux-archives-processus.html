Ce chapitre rassemble trois outils du quotidien d'un administrateur : archiver (sauvegardes), gérer les processus et utiliser les variables d'environnement.

1. Archiver et compresser

CommandeEffet
tar -czvf a.tar.gz d/crée une archive, compressée en gzip, verbeuse, nommée par f
tar -tf a.tar.gzt liste le contenu sans extraire
tar -xzvf a.tar.gzextrait et décompresse en une fois
tar -xzf a.tar.gz chemin/fextrait un seul fichier (chemin tel que listé)
gzip f / gunzip f.gzcompresse en f.gz / décompresse
cp -r d1 d2 · rm -r dcopie / supprime un dossier entier
file ftype de contenu d'un fichier
tar -tf a.tar.gz | grep nom   # cherche un fichier dans l'archive
ls -R d                        # liste récursive pour vérifier
Sauvegarde

Une archive .tar.gz est la base d'une sauvegarde : on archive le dossier (tar -czvf), on vérifie (tar -tf), puis on met l'archive à l'abri.

2. Processus et jobs

Chaque programme en cours est un processus avec un numéro, le PID.

CommandeEffet
psliste mes processus avec leur PID
cmd &lance en arrière-plan
Ctrl+Z puis bgsuspend, puis relance en arrière-plan
jobsliste les jobs suspendus ou en arrière-plan
fg %1ramène le job 1 au premier plan
Ctrl+Ctue le job au premier plan
kill %4tue le job n° 4
kill PIDtue par numéro de processus
kill -9 PIDforce si le processus résiste

3. Les variables

SyntaxeEffet
echo $HOMEaffiche la valeur d'une variable (HOME, USER, PATH…)
printenv · envvariables d'environnement
V=valvariable du shell (pas d'espaces autour du =)
export V=valvariable d'environnement (transmise aux programmes lancés)
unset Vsupprime une variable
export PATH=$PATH:~/dir/binajoute un dossier au PATH
cmd1; cmd2plusieurs commandes sur une ligne
  • Convention : MAJUSCULES pour l'environnement, minuscules pour le shell.
  • ~/.bashrc est lu à chaque shell, ~/.profile à la connexion ; source ~/.bashrc le relit sans se reconnecter.
  • command not found : la commande est absente du système ou son dossier n'est pas dans le PATH.
Résumé express
  • tar -czvf crée, tar -tf liste, tar -xzvf extrait ; gzip/gunzip.
  • ps, cmd &, jobs, fg %n, kill %n, kill -9 PID.
  • $VAR lit une variable, export V=val l'exporte, PATH dit où chercher les commandes.
