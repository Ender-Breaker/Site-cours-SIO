MétéoSuisse publie les données de plus de 600 stations météorologiques et pluviométriques, utiles par exemple aux entreprises de l'énergie et aux assureurs. Ce TP en isole 9 dans une table pour pratiquer les requêtes de base : ajouter, modifier, supprimer et rechercher des lignes.

Pour pratiquer

Chaque question est une mission du labo TP SQL, avec la même table et une vérification automatique. Pour MySQL (phpMyAdmin, MySQL Workbench…), télécharge le script CrePluviometrie.sql.

1. La table Pluvio

Pluvio(ISM, NomStation, altitude, precipitation)

  • ISM : numéro de la station, clé primaire (deux stations ne peuvent pas avoir le même) ;
  • NomStation : nom de la station ;
  • altitude : altitude en mètres ;
  • precipitation : lame d'eau moyenne tombée, en mm par an.

Installer la table sur MySQL

  1. Sélectionne ta base de données personnelle.
  2. Dans le requêteur (onglet SQL), colle le contenu de CrePluviometrie.sql et exécute-le.
  3. Vérifie avec SELECT * FROM Pluvio; : 9 lignes.

Le script crée la table (CREATE TABLE), déclare la clé primaire (ALTER TABLE … ADD CONSTRAINT … PRIMARY KEY) puis insère les lignes (INSERT INTO).

3. Manipulation de données (corrigé)

Ouvre chaque question pour voir la requête, l'explication et le résultat obtenu sur la table.

1. Ajouter la station 8060 · Tour de Gourze · 915 m · 1266 mm/an
INSERT INTO Pluvio (ISM, NomStation, altitude, precipitation)
VALUES (8060, 'Tour de Gourze', 915, 1266);

Les textes vont entre apostrophes, les nombres sans. Lister les colonnes rend la requête lisible et indépendante de l'ordre des colonnes dans la table.

2. Passer l'altitude de la station 8060 à 920 m
UPDATE Pluvio SET altitude = 920
WHERE ISM = 8060;

Le WHERE sur la clé primaire limite la modification à une seule ligne.

3. Supprimer la station 8060
DELETE FROM Pluvio WHERE ISM = 8060;

Après cette requête, la table retrouve ses 9 lignes de départ.

À ne pas oublier
  • Un UPDATE ou un DELETE sans WHERE s'applique à toutes les lignes.
  • Cibler la ligne par sa clé primaire (WHERE ISM = 8060) garantit de ne toucher qu'elle.
  • Insérer deux fois la station 8060 provoque une erreur de clé primaire en double (Duplicate entry).

Erreurs fréquentes
  • Oublier les apostrophes autour d'un texte : WHERE NomStation = Semsales fait chercher une colonne nommée Semsales.
  • Mettre des apostrophes autour d'un nombre : ça marche en MySQL, mais la comparaison devient alors une comparaison de textes dans d'autres bases.
  • Confondre AND (les deux conditions) et OR (au moins une).
  • « Plus de 800 m » : > 800 ; « 800 m ou plus » : >= 800.
