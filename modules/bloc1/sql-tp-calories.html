Le site tabledescalories.com propose une table des calories collaborative : chacun peut consulter les fiches, ajouter des aliments ou corriger une valeur fausse. Ce TP en reprend un extrait de 66 aliments pour s'entraîner aux requêtes de recherche et de modification.

Pour pratiquer

Les 17 questions sont des missions du labo TP SQL, vérifiées automatiquement. Pour MySQL : CreCalorie.sql (accents réparés : le script d'origine les avait perdus).

1. La table CALORIE

CALORIE(CatAl, NomAl, Cal, Prot, Glu, Lip)

  • CatAl : catégorie d'aliment, champ facultatif (peut être NULL) ;
  • NomAl : nom de l'aliment, clé primaire ;
  • Cal : nombre de kilocalories ;
  • Prot, Glu, Lip : quantités de protides, glucides et lipides (g).

Le script crée la table et insère 66 lignes. Début de la table :

Deux détails du script
  • Les colonnes chiffrées sont de type INTEGER alors que le script insère des décimales (25.1, 0.5…). MySQL les arrondit à l'entier le plus proche : 25.1 devient 25, 0.5 devient 1, 0.2 devient 0. Ça change le résultat de la question 8.
  • Certains noms contiennent des guillemets doubles (Actifidus "délisse"…). Entre apostrophes, ce sont des caractères comme les autres.

Filtrer… WHERE condition; avec = <> < > <= >=, AND, OR, IN (…), LIKE '…%', IS NULL

En plus : LIKE cherche un motif (% = n'importe quelle suite de caractères, _ (tiret bas) = un seul caractère) ; IN ('a', 'b') remplace = 'a' OR = 'b' ; IS NULL teste une case vide.

4. Modifier (corrigé)

11. Ajouter le Mac do big mac (100g) : 1500 kcal, 50 g de protides, 50 g de glucides, 0 lipide
INSERT INTO CALORIE (NomAl, Cal, Prot, Glu, Lip)
VALUES ('Mac do big mac (100g)', 1500, 50, 50, 0);

La catégorie n'est pas donnée : on ne liste que les colonnes renseignées, CatAl vaut NULL.

12. Corriger : 246 kcal, 12 g de protides, 21 g de glucides, 12 g de lipides
UPDATE CALORIE SET Cal = 246, Prot = 12, Glu = 21, Lip = 12
WHERE NomAl = 'Mac do big mac (100g)';

Un seul UPDATE modifie plusieurs colonnes, séparées par des virgules.

13. Il y a 2 fois plus de glucides que de lipides
UPDATE CALORIE SET Glu = 2 * Lip
WHERE NomAl = 'Mac do big mac (100g)';

La nouvelle valeur est calculée à partir d'une autre colonne : Glu passe à 24.

14. Placer les Abats en sauce dans la catégorie Plat cuisiné
UPDATE CALORIE SET CatAl = 'Plat cuisiné'
WHERE NomAl = 'Abats en sauce (100g)';

On cible la ligne par sa clé primaire, le nom exact.

15. Supprimer les plats cuisinés
DELETE FROM CALORIE
WHERE CatAl = 'Plat cuisiné';

Après la question 14, les Abats en sauce font partie des plats cuisinés : 5 lignes sont supprimées.

16. Supprimer les aliments de catégorie Fruit ou Confiserie
DELETE FROM CALORIE
WHERE CatAl IN ('Fruit', 'Confiserie');

Équivalent : WHERE CatAl = 'Fruit' OR CatAl = 'Confiserie'.

Erreurs fréquentes
  • WHERE CatAl = NULL ne renvoie jamais rien : il faut IS NULL.
  • WHERE CatAl = 'Fruit' OR 'Confiserie' : la 2e partie n'est pas une condition complète. Écrire CatAl = 'Fruit' OR CatAl = 'Confiserie', ou CatAl IN ('Fruit', 'Confiserie').
  • Oublier les accents ('Cereale') : MySQL est souvent tolérant (collation utf8_general_ci), mais pas tous les SGBD. Le labo, lui, exige l'orthographe exacte.
  • Recopier les valeurs à la main dans la question 13 (SET Glu = 24) : le résultat est juste, mais la consigne demande de le calculer à partir des lipides.
  • Faire un DELETE sans avoir testé le WHERE avec un SELECT avant.
