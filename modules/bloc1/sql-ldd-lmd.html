SQL ne sert pas qu'à lire : il crée la structure de la base et en modifie le contenu. On distingue deux familles de commandes :

FamilleRôleCommandes
LDD (langage de définition des données)Créer et modifier la structureCREATE, ALTER, DROP
LMD (langage de manipulation des données)Lire et modifier le contenuSELECT, INSERT, UPDATE, DELETE

1. Créer une table

CREATE TABLE logiciel (
  id          INTEGER PRIMARY KEY,
  nom         TEXT NOT NULL,
  editeur     TEXT,
  fin_licence DATE,
  postes      INTEGER DEFAULT 1
);
ContrainteEffet
PRIMARY KEYIdentifiant unique de la ligne (souvent auto-incrémenté : AUTO_INCREMENT en MySQL).
NOT NULLValeur obligatoire.
UNIQUEPas deux fois la même valeur (une adresse e-mail, par exemple).
DEFAULT vValeur utilisée si on n'en donne pas.
REFERENCES table(col)Clé étrangère : la valeur doit exister dans l'autre table.

Types courants : INT/INTEGER, DECIMAL(8,2) (montants), VARCHAR(100) (texte limité), TEXT, DATE, DATETIME, BOOLEAN.

CREATE TABLE pret (
  id          INTEGER PRIMARY KEY,
  materiel_id INTEGER NOT NULL,
  employe_id  INTEGER NOT NULL,
  date_debut  DATE,
  FOREIGN KEY (materiel_id) REFERENCES materiel(id),
  FOREIGN KEY (employe_id)  REFERENCES employe(id)
);
L'intégrité référentielle

Grâce aux clés étrangères, le SGBD refuse un prêt pour un matériel qui n'existe pas, et (selon les réglages) refuse de supprimer un matériel encore prêté. La base reste cohérente même si l'application a un bug.

2. Modifier ou supprimer une table

ALTER TABLE employe ADD COLUMN telephone VARCHAR(20);
ALTER TABLE employe DROP COLUMN telephone;
DROP TABLE logiciel;          -- supprime la table ET toutes ses données

3. Ajouter des lignes : INSERT

INSERT INTO service (nom, etage) VALUES ('Qualité', 1);

INSERT INTO logiciel (nom, editeur, fin_licence)
VALUES ('Office 365', 'Microsoft', '2026-09-01'),
       ('GLPI', 'Teclib', NULL);

On liste les colonnes puis les valeurs, dans le même ordre. Les colonnes omises prennent leur valeur par défaut (ou NULL) ; la clé primaire auto-incrémentée est calculée par le SGBD.

4. Modifier des lignes : UPDATE

UPDATE intervention SET resolue = 1 WHERE id = 14;
UPDATE materiel SET prix = prix * 0.9 WHERE type = 'Tablette';
UPDATE employe SET ville = 'Rennes', poste = 'Technicien' WHERE id = 14;

5. Supprimer des lignes : DELETE

DELETE FROM intervention WHERE resolue = 1 AND date_inter < '2025-01-01';
Toujours un WHERE

UPDATE materiel SET prix = 0; ou DELETE FROM employe; sans WHERE touchent toutes les lignes. Bon réflexe : écrire d'abord le SELECT … WHERE … pour vérifier quelles lignes seront concernées, puis le transformer en UPDATE ou DELETE. Et faire une sauvegarde avant les grosses opérations.

6. SQL et sécurité

Dans une application PHP, une requête construite en collant directement la saisie de l'utilisateur est vulnérable à l'injection SQL :

// DANGEREUX : si $nom vaut  ' OR '1'='1  la requête renvoie tout
$sql = "SELECT * FROM employe WHERE nom = '" . $_GET['nom'] . "'";

// CORRECT : requête préparée, la saisie est traitée comme une simple valeur
$req = $pdo->prepare("SELECT * FROM employe WHERE nom = ?");
$req->execute([$_GET['nom']]);

On donne aussi à l'application un compte de base de données avec les seuls droits nécessaires (pas le compte root), et on ne laisse jamais un mot de passe de base dans un fichier public.
