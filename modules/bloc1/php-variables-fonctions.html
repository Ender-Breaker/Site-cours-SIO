PHP est un langage exécuté sur le serveur : il produit du HTML que le navigateur affiche. Ce chapitre couvre les bases : écrire un programme, utiliser des variables et des constantes, et appeler des fonctions.

1. Un premier programme

<?php
ini_set("display_errors", 1);   // affiche les erreurs (utile pour apprendre)

echo "Bonjour";                 // affiche du texte
?>
  • Le code PHP se place entre <?php et ?> (la balise fermante est facultative si le fichier ne contient que du PHP).
  • Chaque instruction se termine par un point-virgule ;.
  • echo affiche du texte ou du HTML dans la page.
  • Commentaires : // une ligne ou /* plusieurs lignes */.

2. Variables et constantes

<?php
// constantes : valeur fixe, jamais modifiée
define("maxi", 100);
define("mini", 0);

// variables : elles commencent par $
$jour = 4;
$mois = 6;
$annee = 2026;

$nom = "DURAND";       // chaîne de caractères
$prenom = "Jean";
$monbool = true;       // booléen

À retenir

En PHP on n'écrit pas le type : il est déduit de la valeur. = sert à affecter une valeur à une variable.

3. Afficher et concaténer

Pour coller des morceaux de texte, PHP utilise le point . (et non le +).

<?php
echo "<h1>" . $nom . " " . $prenom . " né le " . $jour . "/" . $mois . "/" . $annee . "</h1>";
// affiche : DURAND Jean né le 4/6/2026
Guillemets simples ou doubles ?

Avec des guillemets doubles, les variables sont remplacées par leur valeur : "Bonjour $prenom".

Avec des guillemets simples, le texte est affiché tel quel : 'Bonjour $prenom' affiche $prenom.

5. Convertir un type

On peut forcer le type d'une valeur avec un cast : (integer), (string)…

<?php
$machaine = "1234";
var_dump($machaine);                // string(4) "1234"
echo (integer)$machaine + 1;        // 1235

$monentier = 1234;
echo (string)$monentier . "1";      // 12341 (concaténation)
Résumé express
  • Programme entre <?php … ?>, instructions terminées par ;.
  • Variables : $nom (casse sensible). Constantes : define("NOM", valeur).
  • . concatène ; echo affiche ; guillemets doubles → variables remplacées.
  • strlen, ord, chr, var_dump ; casts (integer), (string).
