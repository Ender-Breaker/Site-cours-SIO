Une conditionnelle permet d'exécuter une instruction seulement si une condition est vraie. PHP propose if / elseif / else et switch.

1. if … else

<?php
if ($a > $b) {
    echo "a est plus grand que b";
} else {
    echo "a est plus petit que b";
}

Le bloc else ne s'exécute que si la condition du if est fausse.

Comparaisons et opérateurs logiques

= n'est pas ==

$x = 5 affecte 5 à $x. $x == 5 teste si $x vaut 5. Écrire if ($x = 5) est une erreur classique.

2. Plusieurs cas : if / elseif / else

Exemple du TP « tarif cinéma » : moins de 12 ans 5 €, de 12 à 17 ans 7 €, de 18 à 64 ans 10 €, 65 ans et plus 8 €.

<?php
$age = 16;

if ($age < 12) {
    $tarif = 5;
} elseif ($age < 18) {
    $tarif = 7;
} elseif ($age < 65) {
    $tarif = 10;
} else {
    $tarif = 8;
}

echo "Âge : $age <br /> Tarif : $tarif €";
À retenir

Les conditions sont testées dans l'ordre : dès qu'une est vraie, les suivantes sont ignorées. C'est pour cela que $age < 18 suffit au deuxième test (on sait déjà que $age >= 12).

3. switch

switch compare une variable à une liste de valeurs. Chaque cas se termine par break, sinon PHP continue dans le cas suivant.

<?php
$note = "E";

switch ($note) {
    case "A":
        $signification = "Excellent";
        break;
    case "B":
        $signification = "Bien";
        break;
    case "C":
        $signification = "Moyen";
        break;
    case "D":
        $signification = "Insuffisant";
        break;
    default:
        $signification = "Note invalide";
}

echo "Note : $note - Signification : $signification";

Regrouper plusieurs valeurs

<?php
$x = 5;
switch ($x) {
    case 1: case 2: case 3: case 4: case 5:
    case 6: case 7: case 8: case 9:
        echo "Positif";
        break;
    case 0:
        echo "Nul";
        break;
    default:
        echo "Pas un chiffre";
}

Les cas sans break se « déversent » dans le suivant : c'est ce qui permet de regrouper les valeurs 1 à 9.

À retenir

default s'exécute quand aucun cas ne correspond.

Oublier break fait continuer dans le cas suivant.

4. Exemple : valeur absolue

<?php
$x = -6;

if ($x < 0) {
    $vabs = $x * -1;
} else {
    $vabs = $x;
}

echo "La valeur absolue de " . $x . " est : " . $vabs;
Pour aller plus loin : le jour de la semaine (TP2)
  • On calcule un entier JS (1 = lundi … 7 = dimanche) avec la formule donnée dans le sujet, puis un switch transforme JS en nom de jour.
  • Janvier et février sont traités comme les 13e et 14e mois de l'année précédente.
  • On compare la date saisie à celle du jour avec mktime(0, 0, 0, mois, jour, annee) : égale → « est », plus tard → « sera », plus tôt → « était ».
  • empty($variable) permet de vérifier qu'une date a bien été saisie.
Résumé express
  • if / elseif / else : les conditions sont testées dans l'ordre.
  • switch : un case par valeur, break à la fin, default pour le reste.
  • == teste, = affecte. && = et, || = ou, ! = non.
