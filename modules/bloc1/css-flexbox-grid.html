Pour placer les blocs d'une page (en-tête, colonnes, cartes), le CSS moderne offre deux outils : Flexbox, pour aligner des éléments sur une ligne ou une colonne, et Grid, pour une grille à deux dimensions. Les media queries adaptent la mise en page à la taille de l'écran : c'est le responsive design.

1. Le modèle de boîte (rappel)

Chaque élément est une boîte : contenu, puis padding (marge intérieure), border, margin (marge extérieure). Par défaut, width ne compte que le contenu ; avec box-sizing: border-box, elle inclut padding et bordure, ce qui simplifie tous les calculs :

* { box-sizing: border-box; }
.carte { width: 300px; padding: 20px; border: 2px solid; }  /* fait bien 300 px au total */
main { max-width: 960px; margin: 0 auto; }                 /* bloc centré */

2. Flexbox : aligner sur un axe

On active Flexbox sur le conteneur ; ce sont ses enfants directs qui sont placés.

.cartes {
  display: flex;
  gap: 16px;                         /* espace entre les éléments */
  justify-content: space-between;    /* axe principal */
  align-items: center;               /* axe secondaire */
  flex-wrap: wrap;                   /* retour à la ligne autorisé */
}
.carte { flex: 1; }                  /* chaque carte prend une part égale */

flex-directionrow (défaut, en ligne), column (empilés)
justify-contentflex-start, center, space-between, space-around
align-itemsstretch (défaut), center, flex-start, flex-end

Les deux axes

justify-content agit sur l'axe principal (horizontal en row, vertical en column) ; align-items sur l'axe secondaire. Centrer un élément dans un bloc : display: flex; justify-content: center; align-items: center;

3. Grid : une grille en deux dimensions

.galerie {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 3 colonnes égales */
  gap: 20px;
}
.page {
  display: grid;
  grid-template-columns: 250px 1fr;        /* barre latérale fixe + contenu */
}
.bandeau { grid-column: 1 / 3; }           /* s'étend de la ligne 1 à la ligne 3 */

L'unité fr représente une fraction de l'espace restant : 1fr 2fr donne une colonne deux fois plus large que l'autre. repeat(auto-fill, minmax(200px, 1fr)) crée automatiquement autant de colonnes d'au moins 200 px que la place le permet.

Une dimension (ligne ou colonne)Deux dimensions (lignes et colonnes)

4. Le positionnement

Valeur de positionComportement
staticDéfaut : dans le flux normal.
relativeDécalé par rapport à sa place normale ; sert de repère aux enfants en absolute.
absoluteSorti du flux, placé par rapport au premier ancêtre positionné (badge sur une image).
fixedFixé par rapport à la fenêtre (bouton « haut de page »).
stickyNormal, puis collé quand on fait défiler (en-tête avec top: 0).

z-index règle l'ordre d'empilement des éléments positionnés (le plus grand passe devant).

5. Le responsive design

Le même site doit être lisible sur téléphone, tablette et ordinateur. Trois ingrédients :

  1. La balise <meta name="viewport" content="width=device-width, initial-scale=1">.
  2. Des largeurs souples (%, fr, max-width) plutôt que fixes.
  3. Des media queries qui changent la mise en page selon la largeur :
.cartes { display: grid; grid-template-columns: repeat(3, 1fr); }

@media (max-width: 600px) {
  .cartes { grid-template-columns: 1fr; }   /* une colonne sur téléphone */
  nav ul { flex-direction: column; }
}
Mobile first

On peut aussi écrire d'abord le style pour téléphone, puis l'enrichir pour les grands écrans avec @media (min-width: 768px). L'outil « mode responsive » des outils de développement (F12) permet de tester toutes les tailles.
