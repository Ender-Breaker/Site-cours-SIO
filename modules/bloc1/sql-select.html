Une application web stocke ses données (utilisateurs, commandes, matériel…) dans une base de données relationnelle : un ensemble de tables, chacune faite de colonnes (les champs) et de lignes (les enregistrements). On l'interroge avec le langage SQL (Structured Query Language), commun à MySQL/MariaDB, PostgreSQL, SQLite, SQL Server…

1. Vocabulaire

TermeDéfinition
TableEnsemble de données sur un même sujet (ex. employe).
Colonne (attribut)Une information, avec un type : entier, texte, date, décimal…
Ligne (enregistrement)Un élément de la table : un employé.
Clé primaireColonne dont la valeur identifie chaque ligne de façon unique (souvent id).
Clé étrangèreColonne qui contient la clé primaire d'une ligne d'une autre table (ex. employe.service_id → service.id).
SGBDLogiciel qui gère la base : MariaDB, PostgreSQL, SQLite…

Les exemples de ce chapitre et du labo utilisent la base d'un parc informatique :

TableColonnes
serviceid, nom, etage
employeid, nom, prenom, poste, ville, service_id
materielid, type, marque, modele, prix, date_achat, employe_id
interventionid, materiel_id, date_inter, technicien, duree, motif, resolue

Clé primaire soulignée, clés étrangères en italique.

2. SELECT … FROM

SELECT * FROM employe;                  -- toutes les colonnes
SELECT nom, prenom FROM employe;         -- certaines colonnes
SELECT DISTINCT ville FROM employe;      -- sans doublons
SELECT modele, prix * 1.2 AS prix_ttc FROM materiel;   -- calcul + alias

Une requête se termine par un point-virgule. Les mots-clés s'écrivent souvent en majuscules par convention (SQL ne distingue pas). Les commentaires commencent par --.

3. Filtrer avec WHERE

SELECT * FROM materiel WHERE prix > 1000;
SELECT * FROM materiel WHERE type = 'Portable' AND marque = 'Dell';
SELECT * FROM employe WHERE ville = 'Rennes' OR ville = 'Vannes';
SELECT * FROM employe WHERE ville IN ('Rennes', 'Vannes');
SELECT * FROM materiel WHERE date_achat BETWEEN '2024-01-01' AND '2024-12-31';
SELECT * FROM employe WHERE nom LIKE 'M%';      -- commence par M
SELECT * FROM materiel WHERE employe_id IS NULL;
OpérateurSens
= <> < > <= >=comparaisons (<> = différent, aussi !=)
AND, OR, NOTcombiner des conditions (parenthèses si on mélange AND et OR)
IN (…)appartient à une liste
BETWEEN a AND bentre a et b, bornes incluses
LIKEmotif : % = n'importe quelle suite de caractères, _ = un caractère
IS NULL, IS NOT NULLabsence de valeur
Les pièges

Les textes et les dates s'écrivent entre apostrophes : 'Rennes'. Et NULL ne se compare jamais avec = : WHERE employe_id = NULL ne renvoie rien, il faut IS NULL.

4. Trier et limiter

SELECT modele, prix FROM materiel ORDER BY prix DESC;           -- du plus cher au moins cher
SELECT nom, prenom FROM employe ORDER BY nom, prenom;            -- tri sur deux colonnes
SELECT modele, prix FROM materiel ORDER BY prix DESC LIMIT 3;    -- les 3 plus chers

ASC (croissant) est le tri par défaut. LIMIT se place à la fin.

5. Les fonctions d'agrégat

SELECT COUNT(*) FROM materiel;                          -- nombre de lignes
SELECT COUNT(*) FROM intervention WHERE resolue = 0;
SELECT SUM(prix), AVG(prix), MIN(prix), MAX(prix) FROM materiel;

Un agrégat résume toutes les lignes retenues en une seule valeur. Pour obtenir un résultat par catégorie (par type, par service…), il faut GROUP BY : c'est l'objet du chapitre suivant.

L'ordre des clauses

SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY … LIMIT. Toujours dans cet ordre.
