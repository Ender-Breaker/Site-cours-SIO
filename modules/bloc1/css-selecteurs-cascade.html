Le CSS (Cascading Style Sheets) décrit l'apparence des éléments HTML. Ce chapitre approfondit la façon dont le navigateur choisit le style d'un élément : quels éléments une règle vise (sélecteurs), laquelle gagne en cas de conflit (cascade et spécificité), ce qui se transmet aux enfants (héritage), et dans quelles unités on exprime les tailles.

1. Rappel : une règle CSS

sélecteur {
  propriété: valeur;
  propriété: valeur;
}

h2 { color: #2b3fe0; font-size: 1.5rem; }

Les règles se placent de préférence dans un fichier séparé relié par <link rel="stylesheet" href="style.css"> dans le head : une seule feuille pour tout le site, mise en cache par le navigateur.

Un élément peut avoir plusieurs classes : class="carte vedette", visé par .carte.vedette (sans espace : les deux à la fois).

3. La cascade et la spécificité

Quand plusieurs règles donnent une valeur différente à la même propriété d'un élément, le navigateur choisit dans cet ordre :

  1. Importance : une déclaration !important l'emporte (à éviter : elle rend le code difficile à maintenir).
  2. Spécificité : le sélecteur le plus précis gagne. On compte (identifiants, classes/attributs/pseudo-classes, balises).
  3. Ordre : à spécificité égale, la règle écrite en dernier gagne.
SélecteurSpécificité (id, classe, balise)
p(0, 0, 1)
.intro(0, 1, 0)
article p.intro(0, 1, 2)
#vedette h2(1, 0, 1)
attribut style="…" dans le HTMLplus fort que toute feuille de style
En pratique

Un identifiant bat n'importe quel nombre de classes, une classe bat n'importe quel nombre de balises. Pour garder un CSS simple, on stylise surtout avec des classes.

4. L'héritage

Certaines propriétés se transmettent aux descendants : surtout celles du texte (color, font-family, font-size, line-height, text-align). C'est pourquoi on règle la police une seule fois sur body. Les propriétés de boîte (margin, padding, border, background, width) ne s'héritent pas.

body { font-family: "Hanken Grotesk", sans-serif; color: #16182b; }
/* tous les paragraphes, titres, listes… héritent de la police et de la couleur */
