Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Lua (« lune » en portugais) est un langage très léger, créé au Brésil en 1993, conçu pour être intégré dans d'autres programmes. On le retrouve dans les jeux (Roblox utilise une variante, Luau ; le moteur LÖVE ; World of Warcraft pour ses extensions), dans Neovim, dans des routeurs et dans le serveur web nginx (OpenResty).

1. Afficher et commenter

print("Bonjour !")
print("Total :", 42)      -- plusieurs valeurs séparées par une tabulation
-- commentaire sur une ligne
--[[ commentaire
     sur plusieurs lignes ]]

Pas de point-virgule obligatoire, pas d'accolades : les blocs se terminent par end.

2. Variables : locales ou globales

local score = 0         -- variable locale (à préférer)
score = score + 10
nom = "Léa"             -- sans local : variable GLOBALE
local a, b = 1, 2       -- affectation multiple
a, b = b, a             -- échange en une ligne
Toujours local

Sans le mot local, une variable est globale : elle est visible partout et peut écraser une autre variable du même nom. Une variable jamais affectée vaut nil.
