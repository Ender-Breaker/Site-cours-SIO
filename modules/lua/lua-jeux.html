Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

Tous les moteurs de jeu fonctionnent de la même façon : ils appellent tes fonctions à des moments précis. Avec LÖVE : love.load() au démarrage, puis love.update(dt) et love.draw() à chaque image. Le labo du site reprend exactement ce principe, avec setup, update et draw.

Où tester ?

Les jeux ont besoin d'un écran : ils se lancent dans le bac à sable du labo. Copie les exemples de ce chapitre et modifie-les.

1. La boucle de jeu

local x = 0

function setup()            -- appelée une fois au démarrage
  x = 50
end

function update(dt)         -- 60 fois par seconde : la logique (déplacer, tester)
  x = x + 2
end

function draw()             -- 60 fois par seconde : l'affichage, rien d'autre
  effacer("black")
  rect(x, 150, 30, 30, "gold")
end

dt est le temps écoulé depuis l'image précédente, en secondes (environ 0,016). Multiplier une vitesse par dt donne un mouvement en pixels par seconde, identique quel que soit l'ordinateur : x = x + 120 * dt.

3. Déplacer un personnage

local joueur = { x = 220, y = 260, l = 40, h = 40, vitesse = 200 }

function update(dt)
  if touche("gauche") then joueur.x = joueur.x - joueur.vitesse * dt end
  if touche("droite") then joueur.x = joueur.x + joueur.vitesse * dt end
  joueur.x = math.max(0, math.min(LARGEUR - joueur.l, joueur.x))   -- reste dans l'écran
end

function draw()
  effacer("#16182b")
  rect(joueur.x, joueur.y, joueur.l, joueur.h, "deepskyblue")
end

4. Gravité et saut

La vitesse verticale vy augmente à chaque image (la gravité) ; un saut lui donne une valeur négative (vers le haut).

local y, vy, SOL = 260, 0, 260

function update(dt)
  if toucheAppuyee("espace") and y >= SOL then vy = -9 end   -- saut seulement au sol
  vy = vy + 0.5                -- gravité
  y = y + vy
  if y > SOL then y, vy = SOL, 0 end
end

5. Collisions

Deux rectangles se touchent s'ils se chevauchent sur les deux axes. Cette fonction (collision AABB) sert dans presque tous les jeux 2D :

local function collision(a, b)
  return a.x < b.x + b.l and b.x < a.x + a.l
     and a.y < b.y + b.h and b.y < a.y + a.h
end
local joueur = { x = 100, y = 100, l = 40, h = 40 }
print(collision(joueur, { x = 130, y = 120, l = 20, h = 20 }))   -- true : se chevauchent
print(collision(joueur, { x = 300, y = 100, l = 20, h = 20 }))   -- false : trop loin

Pour deux cercles : ils se touchent si la distance entre les centres est inférieure à la somme des rayons.

local function touche_cercles(a, b)
  local dx, dy = a.x - b.x, a.y - b.y
  return dx * dx + dy * dy < (a.r + b.r) ^ 2      -- sans racine carrée : plus rapide
end
print(touche_cercles({ x = 0, y = 0, r = 10 }, { x = 12, y = 9, r = 6 }))

6. Beaucoup d'objets : une table de tables

Ennemis, projectiles, pièces : on les range dans une liste. Pour supprimer pendant le parcours, on parcourt à l'envers, sinon table.remove décale les éléments et on en saute.

local tirs = { { y = 50 }, { y = -5 }, { y = 120 }, { y = -30 } }
for i = #tirs, 1, -1 do                    -- à l'envers !
  tirs[i].y = tirs[i].y - 10
  if tirs[i].y < 0 then table.remove(tirs, i) end
end
print(#tirs .. " tirs encore à l'écran")

7. Les états du jeu

Menu, partie, fin de partie : une variable d'état décide quoi mettre à jour et quoi dessiner.

local etat, score = "menu", 0

function update(dt)
  if etat == "menu" then
    if toucheAppuyee("espace") then etat, score = "jeu", 0 end
  elseif etat == "jeu" then
    score = score + 1
    if score > 300 then etat = "fin" end
  elseif etat == "fin" and toucheAppuyee("espace") then
    etat = "menu"
  end
end

function draw()
  effacer("black")
  if etat == "menu" then texte("ESPACE pour jouer", 130, 150, 24, "white")
  elseif etat == "jeu" then texte("Score : " .. score, 16, 16, 24, "white")
  else texte("Perdu ! Score : " .. score, 130, 150, 24, "tomato") end
end

Des météorites qui tombent

Une liste, un compteur d'images pour en créer régulièrement, un parcours à l'envers pour retirer celles qui sortent. Ajoute ces lignes.

local meteores, chrono = {}, 0

-- dans update :
  chrono = chrono + 1
  if chrono % 30 == 0 then
    meteores[#meteores + 1] = { x = hasard(0, LARGEUR - 20), y = -20, l = 20, h = 20 }
  end
  for i = #meteores, 1, -1 do
    meteores[i].y = meteores[i].y + 3
    if meteores[i].y > HAUTEUR then table.remove(meteores, i) end
  end

-- dans draw :
  for _, m in ipairs(meteores) do rect(m.x, m.y, m.l, m.h, "orange") end
