1. LÖVE (love2d)

LÖVE est un moteur 2D gratuit. Un jeu est un dossier qui contient un fichier main.lua ; on le lance avec la commande love dossier.

local joueur = { x = 100, y = 100 }

function love.load()                       -- ≈ setup()
  love.window.setTitle("Mon jeu")
end

function love.update(dt)                   -- ≈ update(dt)
  if love.keyboard.isDown("right") then joueur.x = joueur.x + 200 * dt end
end

function love.draw()                       -- ≈ draw()
  love.graphics.setColor(1, 0.8, 0)        -- couleurs de 0 à 1
  love.graphics.rectangle("fill", joueur.x, joueur.y, 40, 40)
  love.graphics.print("Score : 0", 10, 10)
end

function love.keypressed(touche)           -- ≈ toucheAppuyee
  if touche == "escape" then love.event.quit() end
end

2. Roblox et Luau

Roblox Studio utilise Luau, un Lua 5.1 enrichi (types optionnels, +=, continue). Les scripts manipulent des objets du jeu et réagissent à des événements.

local Players = game:GetService("Players")          -- un service du moteur
local piece = script.Parent                         -- l'objet auquel le script est attaché

piece.Touched:Connect(function(autre)               -- événement : quelque chose touche la pièce
  local joueur = Players:GetPlayerFromCharacter(autre.Parent)
  if joueur then
    joueur.leaderstats.Pieces.Value += 1            -- += existe en Luau
    piece:Destroy()
  end
end)

task.wait(2)                                        -- attend 2 secondes (une coroutine !)
print("2 secondes plus tard")

Ce que tu reconnais : les deux-points des méthodes, une fonction anonyme passée en argument (une closure), et task.wait qui met le script en pause grâce aux coroutines.

4. Configurer avec Lua : Neovim, nginx, Wireshark

Beaucoup de logiciels utilisent Lua comme langage de configuration et d'extension, ce qui intéresse aussi l'option SISR. Un fichier de configuration Neovim n'est qu'un script qui remplit des tables :

vim.opt.number = true                    -- numéros de ligne
vim.opt.tabstop = 2
vim.keymap.set("n", "<leader>w", ":write<CR>")   -- un raccourci clavier

Avec OpenResty, on écrit en Lua des règles directement dans le serveur web nginx ; Wireshark, HAProxy, Redis et les pare-feu applicatifs acceptent aussi des scripts Lua.

5. Opérateurs binaires

Utiles pour les masques (réseau, droits, drapeaux d'un jeu) :

print(6 & 3, 6 | 3, 6 ~ 3)        -- ET 2, OU 7, OU exclusif 5
print(1 << 4, 256 >> 2, ~0)       -- décalages : 16, 64 ; NON : -1
local LECTURE, ECRITURE, EXECUTION = 4, 2, 1
local droits = LECTURE | EXECUTION
print(droits, droits & ECRITURE ~= 0, droits & LECTURE ~= 0)
print(string.format("%d.%d", (192 << 8 | 168) >> 8, (192 << 8 | 168) & 0xFF))

6. Les bonnes pratiques

  • **local partout**, y compris pour les fonctions et les modules (local M = {}).
  • Des noms explicites ; _ pour une valeur qu'on ignore (for _, v in ipairs(t)).
  • Mettre en cache dans une locale ce qu'on utilise souvent dans une boucle : local floor = math.floor.
  • Construire les longues chaînes avec table.concat, jamais avec .. dans une boucle.
  • Parcourir une liste avec ipairs ou for i = 1, #t ; un dictionnaire avec pairs.
  • Tester l'absence avec if x == nil quand false est une valeur possible ; sinon if not x.
  • Une erreur prévisible renvoie nil, message ; un bug lève error.

Le jeu dans le labo

local x = 220
function update(dt)
  if touche("gauche") then x = x - 200 * dt end
  if touche("droite") then x = x + 200 * dt end
end
function draw()
  effacer("black")
  rect(x, 280, 40, 20, "white")
end

Le même jeu pour LÖVE

Seuls les noms des fonctions du moteur changent : toute la logique Lua reste identique.

local x = 220
function love.update(dt)
  if love.keyboard.isDown("left") then x = x - 200 * dt end
  if love.keyboard.isDown("right") then x = x + 200 * dt end
end
function love.draw()
  love.graphics.clear(0, 0, 0)
  love.graphics.setColor(1, 1, 1)
  love.graphics.rectangle("fill", x, 280, 40, 20)
end

L'installer chez toi

Télécharge LÖVE sur love2d.org, enregistre le code dans un dossier sous le nom main.lua, puis glisse le dossier sur l'icône de LÖVE (ou tape love . dans le dossier).
