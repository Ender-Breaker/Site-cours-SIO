1. Provoquer une erreur : error et assert

local function racine(x)
  if x < 0 then
    error("nombre négatif interdit : " .. x)
  end
  return math.sqrt(x)
end
print(racine(16))
print(racine(-4))        -- le programme s'arrête ici
print("jamais affiché")

assert(condition, message) provoque une erreur si la condition est fausse, sinon renvoie la condition. C'est le raccourci habituel pour vérifier une hypothèse :

local age = assert(tonumber("17"), "âge invalide")
print(age)
local autre = assert(tonumber("abc"), "âge invalide")

2. Attraper une erreur : pcall

pcall(f, arguments…) (*protected call*) appelle f en mode protégé. Il renvoie true suivi des résultats, ou false suivi du message d'erreur. Le programme continue dans les deux cas : c'est le try / catch de Lua.

local function diviser(a, b)
  if b == 0 then error("division par zéro") end
  return a / b
end

local ok, resultat = pcall(diviser, 10, 2)
print(ok, resultat)
local ok2, message = pcall(diviser, 10, 0)
print(ok2, message)
print("le programme continue")

if not pcall(function() local t = nil; return t.x end) then
  print("erreur attrapée : on a indexé nil")
end

L'erreur peut être n'importe quelle valeur, par exemple une table qui décrit le problème. Le second argument de error (le niveau 0) retire le préfixe « fichier:ligne » du message :

local ok, e = pcall(function() error({ code = 404, texte = "introuvable" }) end)
print(ok, e.code, e.texte)
print(pcall(error, "message nu", 0))

3. La convention nil, message

Pour une erreur prévisible (fichier absent, saisie invalide), les fonctions Lua ne lèvent pas d'erreur : elles renvoient nil suivi d'un message. L'appelant teste le premier résultat.

local function lireAge(texte)
  local n = tonumber(texte)
  if not n then return nil, "ce n'est pas un nombre" end
  if n < 0 or n > 130 then return nil, "âge impossible" end
  return n
end

for _, saisie in ipairs({ "17", "abc", "250" }) do
  local age, err = lireAge(saisie)
  if age then print("âge valide :", age) else print("refusé :", err) end
end
Quelle méthode choisir ?

nil, message pour ce qui peut arriver normalement (mauvaise saisie). error pour un bug ou une situation qui ne devrait jamais arriver. pcall à l'endroit où tu sais quoi faire de l'erreur.

4. La bibliothèque math

print(math.floor(3.7), math.ceil(3.2))      -- arrondis bas et haut : 3  4
print(math.floor(3.5 + 0.5))                -- arrondi au plus proche : 4
print(math.max(4, 9, 2), math.min(4, 9, 2))
print(math.abs(-5), math.sqrt(49), math.pi)
print(math.huge, -math.huge)                -- plus et moins l'infini
print(math.tointeger(5.0), 7 // 1)          -- flottant → entier
print(math.random(1, 6))                    -- entier au hasard entre 1 et 6
print(math.random())                        -- flottant entre 0 et 1

5. os et io

print(os.time())                       -- secondes depuis le 1er janvier 1970
print(os.date("%d/%m/%Y %H:%M"))       -- date mise en forme
local debut = os.clock()               -- temps processeur, pour chronométrer
local s = 0
for i = 1, 1000000 do s = s + i end
print(s, os.clock() - debut >= 0)

Sur un ordinateur, io lit et écrit aussi des fichiers. Ce code ne fonctionne pas dans le navigateur (pas de disque), mais c'est celui que tu écriras en vrai :

local f, err = io.open("scores.txt", "w")     -- "r" lire, "w" écrire, "a" ajouter
if not f then error(err) end
f:write("Léa 120\n")
f:close()

for ligne in io.lines("scores.txt") do        -- lit le fichier ligne par ligne
  print(ligne)
end

Remarque la convention nil, message de io.open, et son raccourci : local f = assert(io.open("scores.txt")).

6. Les modules

Un module est un fichier qui renvoie une table de fonctions. On le charge avec require, qui exécute le fichier une seule fois et garde le résultat en mémoire.

-- fichier geometrie.lua
local M = {}

local function carre(x) return x * x end          -- privé : non exporté

function M.aireCercle(r) return math.pi * carre(r) end
function M.aireRectangle(l, h) return l * h end

return M
-- fichier main.lua
local geo = require("geometrie")       -- sans l'extension .lua
print(geo.aireRectangle(3, 4))

Dans le navigateur il n'y a qu'un seul fichier, mais le principe se teste très bien avec un bloc do … end :

local geo
do
  local M = {}
  local function carre(x) return x * x end
  function M.aireCercle(r) return math.pi * carre(r) end
  function M.aireRectangle(l, h) return l * h end
  geo = M
end
print(geo.aireRectangle(3, 4))
print(string.format("%.2f", geo.aireCercle(1)))
print(carre)          -- nil : la fonction privée est invisible

Le calcul fragile

Ce programme s'arrête à la première mauvaise saisie.

local a = io.read("n")
local b = io.read("n")
if b == 0 then error("division par zéro") end
print(a / b)

Protéger avec pcall

local function calcul()
  local a = io.read("n")
  local b = io.read("n")
  if b == 0 then error("division par zéro", 0) end
  return a / b
end
local ok, r = pcall(calcul)
if ok then print("Résultat : " .. r) else print("Erreur : " .. r) end

Vérifier aussi la saisie

io.read("n") renvoie nil si l'utilisateur ne tape pas un nombre. Essaie avec abc en entrée.

local function calcul()
  local a = io.read("n")
  local b = io.read("n")
  if not a or not b then error("il faut deux nombres", 0) end
  if b == 0 then error("division par zéro", 0) end
  return a / b
end
local ok, r = pcall(calcul)
print(ok and ("Résultat : " .. r) or ("Erreur : " .. r))
