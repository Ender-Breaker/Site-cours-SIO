Une coroutine est une fonction qui peut se mettre en pause au milieu de son exécution, rendre la main, puis reprendre exactement là où elle s'était arrêtée, avec toutes ses variables locales intactes. C'est une spécialité de Lua, très utilisée dans les jeux pour écrire des séquences (« avance, attends 2 secondes, tire, attends… ») comme un simple script.

1. Créer, lancer, suspendre

local co = coroutine.create(function()
  print("étape 1")
  coroutine.yield()            -- pause : rend la main
  print("étape 2")
  coroutine.yield()
  print("étape 3")
end)

print(coroutine.status(co))    -- suspended : créée mais pas encore lancée
coroutine.resume(co)           -- exécute jusqu'au premier yield
print("-- retour au programme principal")
coroutine.resume(co)
coroutine.resume(co)
print(coroutine.status(co))    -- dead : terminée
print(coroutine.resume(co))    -- false   cannot resume dead coroutine
FonctionRôle
coroutine.create(f)crée la coroutine (sans la lancer)
coroutine.resume(co, …)lance ou reprend ; renvoie true + les valeurs, ou false + l'erreur
coroutine.yield(…)met en pause, depuis l'intérieur
coroutine.status(co)suspended, running, dead
coroutine.wrap(f)crée la coroutine et renvoie une fonction qui la reprend

2. Échanger des valeurs

yield peut envoyer des valeurs à celui qui a fait resume, et resume peut en envoyer à la coroutine.

local co = coroutine.create(function(a)
  print("reçu au départ :", a)
  local b = coroutine.yield(a * 2)        -- envoie a*2, puis attend
  print("reçu à la reprise :", b)
  return "terminé"
end)

print(coroutine.resume(co, 10))    -- true   20
print(coroutine.resume(co, 99))    -- true   terminé

3. Les générateurs avec coroutine.wrap

Un générateur produit des valeurs une par une, à la demande. coroutine.wrap renvoie directement une fonction : c'est un itérateur tout prêt pour for … in.

local function fibonacci(limite)
  return coroutine.wrap(function()
    local a, b = 0, 1
    while a <= limite do
      coroutine.yield(a)
      a, b = b, a + b
    end
  end)
end

for n in fibonacci(100) do io.write(n, " ") end
print()

La suite pourrait être infinie : le générateur ne calcule que ce qu'on lui demande.

local function compteur()
  return coroutine.wrap(function()
    local n = 0
    while true do n = n + 1; coroutine.yield(n) end    -- boucle infinie… mais en pause
  end)
end
local suivant = compteur()
print(suivant(), suivant(), suivant())

4. Les coroutines dans un jeu

Sans coroutine, une séquence d'actions oblige à gérer des états et des minuteurs. Avec, on écrit la séquence de haut en bas, et on reprend la coroutine une fois par image.

local function attendre(images)
  for _ = 1, images do coroutine.yield() end
end

local boss = coroutine.wrap(function()
  while true do
    print("  le boss avance")
    attendre(2)
    print("  le boss tire")
    attendre(1)
  end
end)

for image = 1, 8 do            -- la boucle de jeu : une reprise par image
  io.write("image ", image, "\n")
  boss()
end
Ce n'est pas du parallélisme

Une seule coroutine s'exécute à la fois, et elle ne s'interrompt que là où elle appelle yield. Il n'y a donc ni course critique ni verrou à gérer, contrairement aux threads du système.

TutorielUn producteur et un consommateur

Le producteur génère des commandes

local producteur = coroutine.wrap(function()
  for _, article in ipairs({ "clavier", "souris", "écran" }) do
    coroutine.yield(article)
  end
end)
print(producteur(), producteur(), producteur(), producteur())

Le consommateur les traite une à une

Quand le producteur est terminé, il renvoie nil : la boucle for s'arrête toute seule.

local function commandes()
  return coroutine.wrap(function()
    for _, article in ipairs({ "clavier", "souris", "écran" }) do
      coroutine.yield(article)
    end
  end)
end
local n = 0
for article in commandes() do
  n = n + 1
  print("commande " .. n .. " : " .. article)
end

Un filtre entre les deux

On enchaîne les générateurs comme des tuyaux (pipes) du shell.

local function nombres(n)
  return coroutine.wrap(function() for i = 1, n do coroutine.yield(i) end end)
end
local function pairs_seulement(source)
  return coroutine.wrap(function()
    for v in source do if v % 2 == 0 then coroutine.yield(v) end end
  end)
end
for v in pairs_seulement(nombres(10)) do io.write(v, " ") end
print()

À retenir

Une coroutine se met en pause avec coroutine.yield et reprend avec coroutine.resume.

Ses variables locales sont conservées entre deux reprises.

coroutine.wrap(f) renvoie une fonction : idéal pour un générateur dans un for … in.

Une seule coroutine s'exécute à la fois : ce n'est pas du parallélisme.
