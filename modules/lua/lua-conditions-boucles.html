Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Comparaisons et logique

a == b    a ~= b    -- égal, différent (~= et non !=)
a < b     a >= b
and   or   not

Seuls false et nil sont faux. Attention : 0 et "" sont vrais en Lua (contrairement à JavaScript ou PHP).

2. if … then … end

if note >= 16 then
  print("Très bien")
elseif note >= 10 then
  print("Admis")
else
  print("Recalé")
end

local statut = (age >= 18) and "majeur" or "mineur"   -- équivalent du ternaire

3. Les boucles

for i = 1, 10 do            -- de 1 à 10 inclus
  print(i)
end
for i = 10, 1, -1 do        -- à rebours (pas de -1)
  print(i)
end

local n = 100
while n > 1 do
  n = n // 2
end

repeat                       -- s'exécute au moins une fois
  local r = io.read("n")
until r == 0

break sort d'une boucle. Lua n'a pas de continue (on utilise un if ou goto).

Les mots-clés de bloc

if … then … end, for … do … end, while … do … end, repeat … until, function … end. Un end oublié est l'erreur la plus fréquente.

Passe à la pratique

Le labo Lua te fait écrire ces programmes pour de vrai, vérifiés automatiquement.
