1. Définir et appeler

local function aire(largeur, hauteur)
  return largeur * hauteur
end

print(aire(3, 4))
print(aire(3))        -- erreur : hauteur vaut nil

Un paramètre non fourni vaut nil (d'où l'erreur ci-dessus quand on multiplie), un argument en trop est ignoré. Une fonction sans return renvoie nil.

Valeurs par défaut

Lua n'a pas de syntaxe dédiée : on utilise or.

local function saluer(nom, politesse)
  politesse = politesse or "Bonjour"
  print(politesse .. " " .. (nom or "inconnu") .. " !")
end
saluer("Léa")
saluer("Sam", "Salut")
saluer()

2. Plusieurs valeurs de retour

Une fonction Lua peut renvoyer plusieurs valeurs. C'est très utilisé : string.find renvoie un début et une fin, pcall un statut et un résultat.

local function divise(a, b)
  return a // b, a % b
end

local q, r = divise(17, 5)
print(q, r)
local seul = divise(17, 5)        -- les valeurs en trop sont perdues
print(seul)
print(divise(17, 5), "fin")       -- tronqué à 1 valeur : pas en dernière position
print("début", divise(17, 5))     -- toutes les valeurs : dernière position
print((divise(17, 5)))            -- des parenthèses forcent une seule valeur

3. Nombre variable d'arguments : ...

local function somme(...)
  local total = 0
  for _, v in ipairs({...}) do     -- {...} range les arguments dans une table
    total = total + v
  end
  return total
end

print(somme(1, 2, 3), somme(10, 20, 30, 40), somme())
print(select("#", "a", "b", "c"))   -- nombre d'arguments : 3
print(select(2, "a", "b", "c"))     -- à partir du 2e : b   c

4. Les fonctions sont des valeurs

Une fonction se range dans une variable, se passe en argument, se renvoie. function f() end n'est qu'un raccourci de f = function() end.

local double = function(x) return x * 2 end

local function appliquer(f, valeur)
  return f(valeur)
end

print(appliquer(double, 21))
print(appliquer(function(x) return x * x end, 9))   -- fonction anonyme
print(appliquer(string.upper, "lua"))

5. Récursivité

Une fonction récursive s'appelle elle-même. Il lui faut un cas d'arrêt.

local function factorielle(n)
  if n <= 1 then return 1 end           -- cas d'arrêt
  return n * factorielle(n - 1)
end
print(factorielle(5), factorielle(20))
local function ou local f = function ?

Pour une fonction récursive, écris local function f(). Avec local f = function() … f() … end, le nom f n'existe pas encore à l'intérieur de la fonction au moment où elle est créée.

Une fonction qui renvoie deux résultats

local function minmax(t)
  local mini, maxi = t[1], t[1]
  for _, v in ipairs(t) do
    if v < mini then mini = v end
    if v > maxi then maxi = v end
  end
  return mini, maxi
end
print(minmax({12, 5, 19, 8}))

Réutiliser une fonction dans une autre

local function somme(t)
  local s = 0
  for _, v in ipairs(t) do s = s + v end
  return s
end
local function moyenne(t)
  return somme(t) / #t
end
print(moyenne({12, 5, 19, 8}))

Passer une fonction en argument

compter reçoit un test sous forme de fonction : la même fonction sert pour tous les critères. Ajoute ton propre test.

local function compter(t, test)
  local n = 0
  for _, v in ipairs(t) do
    if test(v) then n = n + 1 end
  end
  return n
end
local notes = {12, 5, 19, 8, 10}
print(compter(notes, function(v) return v >= 10 end))
print(compter(notes, function(v) return v % 2 == 0 end))
