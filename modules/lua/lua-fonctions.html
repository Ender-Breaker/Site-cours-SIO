Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Définir et appeler

function carre(x)
  return x * x
end
print(carre(5))              -- 25

local function aire(l, h)    -- fonction locale (à préférer)
  return l * h
end

Un paramètre non fourni vaut nil ; pour une valeur par défaut : nom = nom or "inconnu".

2. Plusieurs valeurs de retour

local function divmod(a, b)
  return a // b, a % b
end
local q, r = divmod(17, 5)   -- q = 3, r = 2

3. Fonctions anonymes et callbacks

local double = function(x) return x * 2 end

local function appliquer(t, f)
  for i, v in ipairs(t) do t[i] = f(v) end
end
appliquer(notes, function(n) return n + 1 end)

table.sort(noms, function(a, b) return a > b end)   -- tri décroissant

4. Nombre variable d'arguments

local function somme(...)
  local s = 0
  for _, v in ipairs({...}) do s = s + v end
  return s
end
somme(1, 2, 3)   -- 6

5. Fermetures (closures)

local function compteur()
  local n = 0
  return function()
    n = n + 1
    return n
  end
end
local c = compteur()
c()  c()   -- 1, puis 2 : la fonction se souvient de n
