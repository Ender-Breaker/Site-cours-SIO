Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

En Lua, il n'y a qu'une structure de données : la table. Elle sert à la fois de tableau, de dictionnaire, d'objet et de module.

1. La table comme tableau

local fruits = {"pomme", "kiwi", "poire"}
fruits[1]               -- "pomme" : les indices commencent à 1 !
#fruits                 -- 3
fruits[#fruits + 1] = "mangue"        -- ajouter à la fin
table.insert(fruits, "fraise")        -- idem
table.insert(fruits, 1, "cerise")     -- insérer en tête
table.remove(fruits)                  -- retirer le dernier
print(table.concat(fruits, ", "))
Indice 1

Contrairement à la plupart des langages, le premier élément est t[1]. t[0] vaut nil (sauf si on l'a rempli).

2. Parcourir

for i, f in ipairs(fruits) do     -- dans l'ordre, indices 1, 2, 3…
  print(i, f)
end
for cle, valeur in pairs(eleve) do  -- toutes les clés, ordre non garanti
  print(cle, valeur)
end

3. La table comme dictionnaire

local eleve = { nom = "Léa", age = 19 }
eleve.nom            -- "Léa"
eleve["age"]         -- 19
eleve.ville = "Rennes"
eleve.age = nil      -- supprime la clé

4. Tables imbriquées

local ennemis = {
  { x = 10, y = 20, pv = 3 },
  { x = 80, y = 40, pv = 1 },
}
for _, e in ipairs(ennemis) do e.y = e.y + 1 end

Une table est passée par référence : si une fonction la modifie, l'original est modifié.

5. La bibliothèque string

local s = "Bonjour"
s:upper()            -- "BONJOUR"
s:sub(1, 3)          -- "Bon"
s:reverse()          -- "ruojnoB"
s:find("jour")       -- 4  7
string.format("%.2f €", 3.5)   -- "3.50 €"
