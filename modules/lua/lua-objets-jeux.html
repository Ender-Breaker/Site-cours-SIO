Cours bonus

Ce cours est hors programme du BTS : il ne compte ni dans ta progression ni au classement. Il est là pour aller plus loin.

1. Des objets avec des tables

Lua n'a pas de mot-clé class, mais une table peut contenir des données et des fonctions. La syntaxe : passe automatiquement l'objet en premier paramètre, nommé self.

local joueur = { nom = "Léa", pv = 10 }
function joueur:blesser(n)          -- équivaut à joueur.blesser(self, n)
  self.pv = self.pv - n
end
joueur:blesser(3)                   -- équivaut à joueur.blesser(joueur, 3)

2. Une « classe » avec une métatable

local Ennemi = {}
Ennemi.__index = Ennemi              -- les méthodes manquantes sont cherchées dans Ennemi

function Ennemi.nouveau(x, y)
  local e = { x = x, y = y, pv = 3 }
  return setmetatable(e, Ennemi)
end

function Ennemi:avancer(dy)
  self.y = self.y + dy
end

local e = Ennemi.nouveau(100, 0)
e:avancer(2)

Une métatable modifie le comportement d'une table. Avec __index, quand on demande e.avancer et que e ne l'a pas, Lua la cherche dans Ennemi : toutes les instances partagent les mêmes méthodes. D'autres métaméthodes redéfinissent les opérateurs (__add, __eq, __tostring…).

3. Lua dans les jeux

Les moteurs de jeu appellent des fonctions Lua à des moments précis. Avec LÖVE : love.load() au démarrage, love.update(dt) et love.draw() à chaque image. Le labo reprend ce principe :

local ennemis = {}

function setup()                      -- une fois au début
  for i = 1, 5 do
    ennemis[#ennemis + 1] = Ennemi.nouveau(i * 80, 0)
  end
end

function update(dt)                   -- 60 fois par seconde
  for _, e in ipairs(ennemis) do e:avancer(1) end
  if touche("gauche") then joueurX = joueurX - 5 end
end

function draw()
  effacer("black")
  for _, e in ipairs(ennemis) do cercle(e.x, e.y, 12, "red") end
end
Supprimer pendant un parcours

Pour retirer des ennemis touchés, parcours la table à l'envers : for i = #ennemis, 1, -1 do if ennemis[i].pv <= 0 then table.remove(ennemis, i) end end. À l'endroit, on sauterait un élément.

4. Modules

-- fichier vecteur.lua
local M = {}
function M.longueur(x, y) return math.sqrt(x * x + y * y) end
return M

-- ailleurs
local vecteur = require("vecteur")
vecteur.longueur(3, 4)   -- 5.0
