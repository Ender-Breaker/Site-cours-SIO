Chapitre bonus

Ce chapitre est un complément créé pour Étude Facile (il ne vient pas d'un support de cours). Les exemples sont à tester dans un terminal Python ou sur un éditeur en ligne.

Un programme communique avec l'utilisateur : il affiche avec print() et lit avec input().

1. Afficher avec print

>>> print('Bonjour')
Bonjour
>>> print('x =', 5)
x = 5
>>> print(2 + 3)
5

print accepte plusieurs valeurs séparées par des virgules : elles sont affichées avec un espace entre chaque.

2. Lire avec input

nom = input('Ton prénom ? ')
print('Salut', nom)
input renvoie toujours du texte

Même si l'utilisateur tape 12, input() renvoie la chaîne '12'. Pour calculer, il faut convertir : int(...) pour un entier, float(...) pour un décimal.

age = int(input('Ton âge ? '))
print('Dans 10 ans :', age + 10)

3. Les f-strings

>>> nom = 'Léa'
>>> age = 17
>>> print(f'{nom} a {age} ans')
Léa a 17 ans

Le préfixe f permet d'insérer des variables ou calculs entre {} dans le texte : f'{2+3}' donne '5'.
