Chapitre bonus

Ce chapitre est un complément créé pour Étude Facile (il ne vient pas d'un support de cours). Les exemples sont à tester dans un terminal Python ou sur un éditeur en ligne.

Une fonction est un bloc de code nommé, réutilisable. Elle évite de recopier le même code et rend le programme lisible.

1. Définir et appeler

def carre(x):
    return x * x

print(carre(5))   # 25
  • def introduit la fonction, suivie de son nom et de ses paramètres entre parenthèses, puis :.
  • return renvoie un résultat et termine la fonction.
  • Une fonction sans return renvoie None.
  • L'appel carre(5) passe l'argument 5 au paramètre x.

2. Paramètres multiples et valeur par défaut

def ttc(prix, taux=0.2):
    return prix * (1 + taux)

print(ttc(100))        # 120.0
print(ttc(100, 0.1))   # 110.00000000000001

3. Variables locales

Une variable créée dans une fonction est locale : elle n'existe pas en dehors. Les paramètres aussi.

print ≠ return

print affiche une valeur à l'écran ; return renvoie la valeur à l'appelant, qui peut la réutiliser dans un calcul.

4. Exemple complet

def est_pair(n):
    return n % 2 == 0

def somme(l):
    total = 0
    for x in l:
        total += x
    return total

print(est_pair(7))        # False
print(somme([1, 2, 3]))   # 6
