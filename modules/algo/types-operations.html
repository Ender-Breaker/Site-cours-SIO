En algorithmique, on manipule des données. Chaque donnée a un type qui décide de ce qu'on peut faire avec elle.

1. Les types de données

TypeNom PythonExemples
BooléenboolTrue, False
Entierint-3, 0, 42
Réelfloat5.37, 15.0, -14.001
Chaîne de caractèresstr'Bonjour', '41n5K6'

Connaître le type : type(x)

>>> type(7.34)
<class 'float'>
>>> type('43')
<class 'str'>
Attention aux pièges
  • 43 est un entier, mais 43.0 est un réel et '43' est une chaîne.
  • [43] est une liste (à un seul élément). [] est la liste vide, '' la chaîne vide.
  • Une liste peut contenir d'autres listes : [[1],[2,3]].

3. Comparer des nombres

Une comparaison renvoie toujours un booléen : True ou False.

>>> 4 == 4
True
>>> 3 == 7
False
>>> 2 != 3
True
>>> 2 <= 5
True
>>> 2 >= 5
False
SignificationPython
égal à==
différent de!=
strictement inférieur / supérieur< / >
inférieur ou égal / supérieur ou égal<= / >=
= n'est pas ==

= sert à donner une valeur à une variable. == sert à tester l'égalité de deux valeurs.

4. Opérations sur les booléens

>>> not(2 == 3)
True
>>> 2 < 3 and 3 < 2
False
>>> 2 < 3 or 3 < 2
True
LogiquePythonVrai quand…
non Anot(A)A est faux
A et BA and BA et B sont tous les deux vrais
A ou BA or Bau moins l'un des deux est vrai
A ⇒ BA <= Bsauf si A vrai et B faux
A ⇔ BA == BA et B ont la même valeur
Exemples avec l'implication et l'équivalence 
>>> (2 < 3) <= (1 < 2)
True
>>> (5 < 3) == (5 == 7)
True

Dans le second cas, 5 < 3 est faux et 5 == 7 est faux aussi : les deux ont la même valeur, donc l'équivalence est vraie.

5. Opérations sur les chaînes de caractères

Une chaîne se place entre guillemets simples ou doubles : 'bonjour' ou "bonjour".

Concaténation, longueur, répétition

>>> '11'+'32'
'1132'
>>> len('bonjour')
7
>>> 3*'bonjour'+'23'
'bonjourbonjourbonjour23'

Accéder aux caractères

Les caractères sont numérotés à partir de 0 (l'indice).

Caractèrebonjour
Indice0123456
>>> 'bonjour'[0]
'b'
>>> 'bonjour'[2:4]
'nj'
>>> 'bonjour'[0:4]
'bonj'
À retenir

ch[i:j] prend les caractères des indices i inclus jusqu'à j exclu.

6. Opérations sur les listes

Une liste stocke plusieurs données. Comme pour les chaînes, les éléments sont numérotés à partir de 0.

>>> [1,3,5,7][0]
1
>>> [1,3,5,7,9][1:4]
[3, 5, 7]
>>> [1,[3,5],7,9][1]
[3, 5]
>>> [1,[3,5],7,9][1][0]
3

Ajouter un élément : append

>>> L = [1,3,5]
>>> L.append(7)
>>> L
[1, 3, 5, 7]

L'élément est ajouté à la fin de la liste.

Résumé express

Les 6 points à connaître par cœur
  • 5 types : bool, int, float, str, list.
  • // = quotient, % = reste, ** = puissance.
  • Une comparaison donne un booléen ; == teste, = affecte.
  • not, and, or combinent des booléens.
  • Indices à partir de 0 ; [i:j] exclut j.
  • str(), int(), float() convertissent.
