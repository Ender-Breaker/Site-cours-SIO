Chapitre bonus

Ce chapitre est un complément créé pour Étude Facile (il ne vient pas d'un support de cours). Les exemples sont à tester dans un terminal Python ou sur un éditeur en ligne.

Une variable est une case mémoire portant un nom, qui contient une valeur. En Python, on la crée simplement avec = (l'affectation).

>>> age = 17
>>> nom = 'Léa'
>>> age = age + 1
>>> age
18

1. Affectation

  • x = 5 signifie « x prend la valeur 5 », ce n'est pas une égalité mathématique.
  • x = x + 1 est donc possible : on calcule d'abord à droite, puis on range le résultat dans x.
  • Python lit les instructions de haut en bas : la dernière valeur affectée gagne.

2. Noms de variables

  • lettres, chiffres et _, sans commencer par un chiffre ;
  • sensible à la casse : Age et age sont deux variables différentes ;
  • éviter les mots réservés (if, for, while, print…) ;
  • choisir des noms parlants : prix_ttc plutôt que x.

3. Échanger deux variables

a = 3
b = 8
c = a      # on garde a en mémoire
a = b
b = c
# a vaut 8, b vaut 3

# version Python
a, b = b, a
