Chapitre bonus

Ce chapitre est un complément créé pour Étude Facile (il ne vient pas d'un support de cours). Les exemples sont à tester dans un terminal Python ou sur un éditeur en ligne.

Une condition permet d'exécuter des instructions seulement si un test est vrai. Le test donne un booléen : True ou False.

1. Comparaisons

OpérateurSignification
==égal à
!=différent de
< >inférieur, supérieur
<= >=inférieur ou égal, supérieur ou égal
= ou == ?

= affecte une valeur, == compare. Écrire if x = 3: est une erreur de syntaxe.

2. if / elif / else

note = 14
if note >= 16:
    print('Très bien')
elif note >= 10:
    print('Admis')
else:
    print('Refusé')
  • Chaque test se termine par :.
  • Le bloc est indenté (4 espaces) : l'indentation fait partie de la syntaxe.
  • Seul le premier bloc dont le test est vrai s'exécute ; else est le cas par défaut.

3. Opérateurs logiques

OpérateurVrai quand…

a or bau moins l'un des deux est vrai
not aa est faux
age = 20

    print('Actif')

Test d'appartenance : 3 in [1, 2, 3] donne True. Parité : n % 2 == 0 est vrai si n est pair.
