Chapitre bonus

Ce chapitre est un complément créé pour Étude Facile (il ne vient pas d'un support de cours). Les exemples sont à tester dans un terminal Python ou sur un éditeur en ligne.

Les chaînes (str) et les listes (list) sont des séquences : leurs éléments sont indexés à partir de 0.

1. Chaînes de caractères

>>> s = 'Python'
>>> s[0]
'P'
>>> s[-1]
'n'
>>> s[1:4]
'yth'
>>> len(s)
6
>>> s.upper()
'PYTHON'
  • s[i] : caractère d'indice i ; s[-1] : le dernier ;
  • s[a:b] : tranche de a (inclus) à b (exclu) ;
  • len(s) : nombre de caractères ;
  • les chaînes sont immuables : on ne peut pas faire s[0] = 'J'.

2. Listes

>>> notes = [12, 8, 15]
>>> notes.append(10)
>>> notes
[12, 8, 15, 10]
>>> notes[1] = 9
>>> len(notes)
4
>>> sum(notes) / len(notes)
11.5
