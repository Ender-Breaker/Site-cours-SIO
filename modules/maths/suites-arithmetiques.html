Une suite (uₙ) est une liste de nombres indexés par n. Elle est arithmétique si on passe d'un terme au suivant en ajoutant toujours le même nombre r, la raison.

1. Définition et terme général

u(n+1) = u(n) + r
u(n) = u(0) + n×r        (suite indexée à partir de 0)
u(n) = u(p) + (n − p)×r   (formule générale)

Pour montrer qu'une suite est arithmétique, on calcule u(n+1) − u(n) : si le résultat est constant, c'est gagné. Exemple : −2, 5, 12 → 5−(−2) = 12−5 = 7 : raison 7.

Variations

  • r > 0 : suite croissante
  • r < 0 : suite décroissante
  • r = 0 : suite constante

2. Somme de termes consécutifs

S = nombre de termes × (premier terme + dernier terme) / 2

Le nombre de termes de u(p) à u(n) est n − p + 1. Exemple : un athlète court 3000 m le jour 0 puis 150 m de plus chaque jour. u(n) = 3000 + 150n. Du jour 0 au jour 15 : 16 termes, u(15) = 5250, somme = 16 × (3000+5250)/2 = 66 000 m.

3. Moyenne arithmétique

La moyenne arithmétique de a et b est (a+b)/2. Dans une suite arithmétique, tout terme est la moyenne de ses deux voisins : u(n) = (u(n−1) + u(n+1))/2.

Applications
