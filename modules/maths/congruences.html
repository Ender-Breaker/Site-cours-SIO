Les congruences permettent de calculer avec les restes. Elles servent pour les clés de contrôle (IBAN, ISBN), le hachage, la cryptographie.

1. Définition

Soit n ≥ 2. Deux entiers a et b sont congrus modulo n si ils ont le même reste dans la division par n, c'est-à-dire si n divise a − b. On note a ≡ b [n].

17 ≡ 2 [5]   car 17 − 2 = 15 = 5×3
−1 ≡ 6 [7]   car −1 − 6 = −7
38 ≡ 3 [5]
Reste

a ≡ r [n] avec 0 ≤ r < n signifie que r est le reste de a par n.

2. Calculer avec les congruences

Si a ≡ b [n] et c ≡ d [n], alors :

  • a + c ≡ b + d [n]
  • a × c ≡ b × d [n]
  • a^k ≡ b^k [n] pour tout entier k ≥ 0
Pas de division

On ne peut pas « simplifier » librement : 6 ≡ 0 [6] ne permet pas de dire 3 ≡ 0 [6] après division par 2.

3. Exemple : un reste de puissance

Reste de 7¹⁰⁰ modulo 5 ? 7 ≡ 2 [5] ; 2² ≡ 4 ; 2³ ≡ 3 ; 2⁴ ≡ 1 [5]. Les puissances de 2 se répètent tous les 4 : 100 = 4×25 donc 7¹⁰⁰ ≡ 2¹⁰⁰ ≡ (2⁴)²⁵ ≡ 1 [5].

4. Tableau des restes

Pour résoudre a×x ≡ b [n] avec de petits n, on teste x = 0, 1, …, n−1 dans un tableau. Exemple : 3x ≡ 2 [7] → x = 3 (car 9 ≡ 2 [7]).
