Un nombre s'écrit toujours dans une base p (entier ≥ 2). En informatique : base 2 (binaire), base 8 (octal), base 16 (hexadécimal).

1. Écriture dans une base

Dans la base p, un nombre s'écrit avec des chiffres ai compris entre 0 et p−1 : N = an×p^n + … + a1×p + a0.

4725 = 4×10³ + 7×10² + 2×10¹ + 5×10⁰   (base 10)
10111₂ = 1×2⁴ + 0×2³ + 1×2² + 1×2¹ + 1×2⁰ = 23
Chiffres de la base 16

0 à 9 puis A=10, B=11, C=12, D=13, E=14, F=15. On note la base en indice : 10111₂ = 23 = 17₁₆ (on n'écrit jamais 23 = 10111 = 17).

2. Base p → base 10

On développe selon les puissances de la base. Exemple : 7DE₁₆ = 7×16² + 13×16 + 14 = 1792 + 208 + 14 = 2014.

3. Base 10 → base p : divisions successives

  1. Diviser le nombre par p, garder le reste.
  2. Recommencer avec le quotient, jusqu'à obtenir un quotient nul.
  3. Lire les restes du dernier au premier.
75 = 2×37 + 1
37 = 2×18 + 1
18 = 2×9  + 0
 9 = 2×4  + 1
 4 = 2×2  + 0
 2 = 2×1  + 0
 1 = 2×0  + 1      → 75 = 1001011₂

4. Passer de la base 2 à la base 16 (et inversement)

Comme 16 = 2⁴, on groupe les bits par paquets de 4 en partant de la droite. 1001011₂ → 0100 | 1011 → 4B₁₆. Pour la base 8 (8 = 2³) on groupe par 3.

5. Opérations en binaire

Addition : 0+0=0, 0+1=1, 1+1=10 (on pose 0 et on retient 1). Exemple : 1011₂ + 110₂ = 10001₂ (11 + 6 = 17).

Nombre de chiffres

Avec n bits on représente les entiers de 0 à 2ⁿ−1. Sur 8 bits : 0 à 255 ; sur 16 bits : 0 à 65535.
