La statistique à deux variables étudie le lien entre deux séries de données (x ; y) pour en tirer une prévision.

1. Nuage de points et point moyen

Le nuage de points est l'ensemble des points Mᵢ(xᵢ ; yᵢ). Le point moyen G a pour coordonnées les moyennes : x̄ = Σxᵢ / n et ȳ = Σyᵢ / n.

Exemple : x = 8 ; 10 ; 12 ; 14 ; 16 ; 18 et y = 40 ; 55 ; 55 ; 70 ; 75 ; 95. Alors x̄ = 78/6 = 13 et ȳ = 390/6 = 65 : G(13 ; 65).

2. Ajustement affine

Quand les points sont sensiblement alignés, on les approche par une droite y = ax + b, la droite d'ajustement. Elle permet :

  • l'interpolation : estimer y pour un x situé *dans* la plage des données ;
  • l'extrapolation : estimer y pour un x *en dehors* de cette plage (moins fiable).

Trois méthodes

  • Au jugé : on trace à la règle une droite proche des points.
  • Points moyens : on sépare le nuage en deux groupes, on calcule leurs points moyens G1 et G2 et on trace (G1G2), qui passe par G.
  • Moindres carrés (calculatrice / tableur) : la droite qui minimise la somme des carrés des écarts verticaux.
La droite des moindres carrés passe toujours par G

Si y = ax + b, alors ȳ = a×x̄ + b : on peut retrouver b par b = ȳ − a×x̄.

3. Utiliser la droite

Avec y = 2,1x + 1,1 : pour x = 30, y = 2,1×30 + 1,1 = 64,1. Pour trouver x quand y = 70 : 70 = 2,1x + 1,1 donc x = 68,9/2,1 ≈ 32,8.

4. Ajustement par changement de variable

Si le nuage (x ; y) n'est pas aligné (croissance très rapide), on pose par exemple z = log y. Si le nuage (x ; z) est aligné, on ajuste z = ax + b, puis y = 10^z = 10^b × (10^a)^x : une relation exponentielle.
