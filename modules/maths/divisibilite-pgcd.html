L'arithmétique étudie les nombres entiers : divisibilité, nombres premiers, PGCD. Elle sert en informatique (cryptographie, clés de contrôle…).

1. Division euclidienne

Pour a entier et b > 0, il existe un unique couple (q ; r) tel que a = b×q + r avec 0 ≤ r < b. Exemple : 53 = 6×8 + 5.

b divise a (b | a) si le reste est 0, c'est-à-dire si a = b×k avec k entier. On dit aussi que a est un multiple de b.

3. Nombres premiers

Un entier ≥ 2 est premier s'il n'a que deux diviseurs : 1 et lui-même (2, 3, 5, 7, 11, 13…). Pour tester n : il suffit d'essayer les nombres premiers p avec p² ≤ n.

Tout entier ≥ 2 se décompose de façon unique en produit de nombres premiers. Exemple : 360 = 2³ × 3² × 5.

4. PGCD

Le PGCD de a et b est le plus grand diviseur commun. Avec les décompositions : on prend les facteurs communs avec le plus petit exposant. Exemple : 360 = 2³×3²×5 et 84 = 2²×3×7 → PGCD = 2²×3 = 12.

Algorithme d'Euclide

PGCD(a ; b) = PGCD(b ; r) où r est le reste de a par b. On s'arrête quand le reste est nul : le PGCD est le dernier reste non nul.

PGCD(252 ; 198)
252 = 198×1 + 54
198 = 54×3 + 36
 54 = 36×1 + 18
 36 = 18×2 + 0   → PGCD = 18
Nombres premiers entre eux

a et b sont premiers entre eux si PGCD(a ; b) = 1. Fraction irréductible : on divise numérateur et dénominateur par leur PGCD. PPCM(a ; b) = a×b / PGCD(a ; b).
