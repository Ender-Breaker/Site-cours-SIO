Un formulaire sert à collecter les informations de l'utilisateur. Il est composé de champs de saisie appelés aussi contrôles graphiques ou widgets. Chaque contrôle est identifié par un nom. Ce chapitre couvre le côté HTML ; le traitement côté PHP est dans le chapitre « PHP : formulaires » du Bloc 1.

1. La balise form

<form action="calcul.php" method="get">
    ...contrôles...
    <input type="submit" value="CALCULER" name="BOvalider" />
</form>
AttributRôle
actionfichier à exécuter quand on clique sur le bouton d'envoi (type="submit")
methodmode de passage des paramètres : get (dans l'URL) ou post

2. Label et input

<label for="hauteur">Hauteur :</label>
<input type="text" id="hauteur" name="TXTHauteur" value="10" />
  • <label> est juste un texte affiché (une étiquette).
  • <input> est un contrôle de saisie. Propriétés communes : type (famille du contrôle), name (nom, utile pour récupérer la valeur saisie), value (valeur par défaut), id (identifiant du document, pour CSS et JavaScript).
  • Un bouton type="submit" termine le formulaire : c'est lui qui lance le programme PHP associé à <form>.
À retenir

Le name est indispensable : c'est la clé qu'on retrouve ensuite dans $_GET ou $_POST.

Boutons radio

Pour qu'un seul choix soit possible, tous les boutons radio d'un même groupe doivent avoir le même name. Principe : 1 donnée = 1 seul name, avec plusieurs options possibles.

4. Exemple complet : le rectangle

<!-- formulaire.html -->
<form action="calcul.php" method="get">
    Hauteur : <input type="text" name="TXTHauteur" />
    Largeur : <input type="text" name="TXTLargeur" />
    <input type="submit" name="BOvalider" value="CALCULER" />
</form>

<?php
// calcul.php?TXTHauteur=10&TXTLargeur=5&BOvalider=CALCULER
$hauteur = $_GET["TXTHauteur"];
$largeur = $_GET["TXTLargeur"];

$perimetre = 2 * ($hauteur + $largeur);
$surface   = $hauteur * $largeur;

echo "Périmètre : $perimetre <br /> Surface : $surface";

L'URL transporte les données saisies : calcul.php?TXTHauteur=10&TXTLargeur=5&BOvalider=CALCULER. Avec 10 et 5, on obtient un périmètre de 30 et une surface de 50.

Résumé express
  • <form action="…" method="get|post"> ; le bouton submit envoie le formulaire.
  • <input> : type, name (clé côté PHP), value, id.
  • radio (un choix, même name), checkbox (oui/non), <select> (liste), <textarea> (multiligne).
  • Côté PHP : $_GET["name"] ou $_POST["name"].
