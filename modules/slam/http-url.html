Quand tu tapes une adresse dans ton navigateur, il réclame une page à un serveur. Ce chapitre explique comment : le service HTTP, la composition d'une URL et le passage de paramètres.

1. Le service HTTP (service web)

Un navigateur ne sait qu'exécuter du HTML : il ne comprend pas le PHP. Pour exécuter du PHP, il doit demander à un service HTTP (un serveur web) de le faire et de lui renvoyer du HTML.

Analogie du restaurant

Le client (navigateur) utilise une URL pour réclamer une page au serveur (cuisine), qui prépare la réponse et la renvoie.

OutilExemple
Serveurs webApache, Nginx (Windows et Linux) ; IIS (Windows)
Packs tout intégrésEasyPHP, WAMP/LAMP (Apache, MySQL, PHP), WNMP/LEMP (Nginx, MySQL, PHP)
Fournis par les langagesphp -S localhost:8000 ; python -m http.server 8000

Caractéristiques générales

  • 2 protocoles : http ou https (sécurisé).
  • Le port distingue deux services différents (par exemple intranet et extranet). Port par défaut : 80 (http).
  • Un fichier de paramètres : nginx.conf, apache2.conf ou httpd.conf.
  • Un dossier racine pour stocker les fichiers du site.
  • Page par défaut : index.html ou index.php.

2. Exécuter un programme PHP facilement

php -v                                  # vérifier que PHP est installé
php -S localhost:8000                   # serveur web dans le dossier courant
php -S localhost:8000 -t monRepertoire  # monRepertoire = dossier racine

Le navigateur appelle ensuite le serveur sur le port 8000 : http://localhost:8000/calcul.php.

4. Les paramètres d'une URL

Les paramètres commencent après un ? et forment une liste de paires clé=valeur séparées par & : ?clé1=valeur1&clé2=valeur2. Le serveur peut les utiliser avant d'envoyer la ressource au navigateur. C'est le programmeur qui décide des paramètres.

<?php
// URL : page.php?Nom=Durand&age=17
echo $_REQUEST["Nom"];    // Durand
echo $_REQUEST["age"];    // 17

$_GET, $_POST et $_REQUEST sont des tableaux associatifs qui contiennent les couples clé/valeur. C'est l'attribut method de <form> qui décide de la superglobale chargée.

Résumé express
  • Le navigateur demande une page via une URL à un service HTTP (Apache, Nginx…), qui exécute le PHP et renvoie du HTML.
  • URL : protocole, domaine, port (80 par défaut), chemin/fichier, paramètres ?clé=valeur&clé=valeur.
  • php -S localhost:8000 lance un petit serveur de test.
  • $_GET (visible dans l'URL) / $_POST (non visible) / $_REQUEST.
