CSS (Cascading Style Sheets, « feuilles de style en cascade ») décrit la présentation d'une page : couleurs, polices, marges, positions. HTML décrit le contenu, CSS le décore.

1. Associer une feuille de style

Le style d'un <h1> répété partout est un problème : si on veut le changer, il faut modifier chaque page. Solution : définir le style une seule fois.

<!-- Dans le <head> de la page : balise <style> -->
<style>
  h1 { color: green; }
</style>

<!-- Ou, mieux : un fichier séparé, relié à plusieurs pages -->
<link rel="stylesheet" href="style.css" />
MéthodeAvantages
Style répété dans chaque balise (style="...")à éviter : répétitions, rendu difficile à maintenir
<style> dans le <head>style défini une fois pour la page, rendu homogène
Fichier .css + <link>un seul fichier pour tout le site, HTML plus lisible, facile à maintenir

2. Syntaxe d'une règle

sélecteur {
    propriété: valeur;
    autre-propriété: valeur;
}

h1 { color: blue; font-size: 24px; }

Attention : dans un fichier CSS, la syntaxe est différente de HTML (accolades, deux-points, points-virgules). Si une même propriété est écrite plusieurs fois, la dernière valeur est prioritaire.

3. Structure arborescente du HTML

HTML forme un arbre : chaque balise imbriquée est le « fils » de la balise qui la contient. CSS et JavaScript utilisent cet arbre.

body { color: blue; }      /* l'élément body */
div { color: blue; }       /* toutes les div */
* { color: blue; }         /* tous les éléments */
div div p { color: blue; } /* un paragraphe situé dans 2 div imbriquées */
À retenir

Les styles s'héritent : un style appliqué à un parent s'applique à ses enfants (sauf s'ils définissent le leur).

<div class="menu">...</div>

Classe ou identifiant ?

Une classe (.nom) peut être utilisée sur autant d'éléments qu'on veut. Un identifiant (#nom) ne doit désigner qu'un seul élément de la page.

5. Balises sémantiques HTML5

HTML5 propose des balises qui donnent du sens à la structure : <header> (en-tête), <nav> (menu), <main> (contenu principal), <section>, <article>, <aside> (contenu annexe), <footer> (pied de page).

Résumé express
  • Une feuille de style .css reliée par <link> évite de répéter les styles et homogénéise le site.
  • Règle : sélecteur { propriété: valeur; } ; la dernière valeur écrite est prioritaire.
  • Sélecteur de balise → type ; .classe → plusieurs éléments ; #id → un seul ; :hover/:visited → états.
  • Les styles s'héritent le long de l'arbre HTML.
