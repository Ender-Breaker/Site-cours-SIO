Pour réaliser une mise en page (colonnes, menu, pied de page), on positionne les éléments avec CSS. Les propriétés clés : display, les marges, float, position et surtout flex.

1. La propriété display

display règle le comportement d'une <div> dans la page.

ValeurEffet
blockles blocs sont superposés (l'un sous l'autre)
inline-blockles blocs sont placés en ligne, avec leur taille
inlineles éléments prennent la taille de leur contenu
nonepas d'affichage, et la place est libérée pour les autres éléments
flexblocs flexibles sur un axe : ils s'adaptent à l'espace (écran de PC ou de téléphone)
gridblocs flexibles sur une grille
Responsive

Un bloc flexible s'adapte à l'espace de visualisation, sur PC comme sur téléphone : on dit qu'il est responsive.

2. Le modèle de boîte : marges

Chaque élément est une boîte. De l'intérieur vers l'extérieur : le contenu, le padding (marge intérieure), la bordure (border) et la marge extérieure (margin).

div {
    margin: 10px;           /* espace autour de la boîte */
    padding: 5px;           /* espace entre le contenu et la bordure */
    border: 1px solid #333;
}
.collee { margin: 0; }      /* si la valeur est nulle : 0 et non 0px */

Les valeurs négatives sont autorisées pour les marges.

3. Positionnement flottant : float

float « sort » un élément du flux normal : son parent ne le prend plus en compte pour calculer sa taille, et les autres éléments viennent l'entourer. clear: both dans un autre élément annule ce comportement.

img { float: left; }
footer { clear: both; }

4. La propriété position

ValeurComportement
staticvaleur par défaut : flux normal
relativepositionné par rapport à sa position normale, avec top, left…
absolutepositionné avec top/left par rapport au parent positionné ; sans parent positionné, par rapport à l'élément html
fixedcomme absolute, mais par rapport à la fenêtre : l'élément reste en place même quand on fait défiler la page

5. Conteneur flexible : display flex

Pour créer un conteneur flexible, on met display: flex sur le parent. Ses enfants directs deviennent des éléments flexibles (flex items).

.conteneur {
    display: flex;
}
.item { margin: 1em; padding: 0.5em; width: 110px; }

/* répartir l'espace entre éléments */
.un   { flex: 1; }
.deux { flex: 2; }   /* prend 2 fois plus de place que .un */

Comportement par défaut d'un conteneur flex :

  • les éléments s'affichent en ligne horizontale (flex-direction: row) ;
  • ils sont placés depuis le début de l'axe principal ;
  • ils ne s'étirent pas sur l'axe principal mais peuvent rétrécir ;
  • ils sont étirés sur l'axe secondaire ;
  • flex-wrap: nowrap : tous les éléments restent sur une seule ligne.

Les valeurs de flex (comme flex: 1, flex: 2, flex: auto, flex: none) règlent la part d'espace que prend chaque élément.

Mise en page en colonnes (TP3)

On crée trois <div> : divMenu, divGauche, divDroite, puis on code leur positionnement dans la feuille CSS — par exemple en mettant display: flex sur le conteneur.

Résumé express
  • display : block (empilés), inline-block (en ligne), none (masqué), flex/grid (flexibles, responsive).
  • Boîte : contenu, padding, border, margin (0 sans unité).
  • float sort du flux, clear l'annule. position : static (défaut), relative, absolute, fixed.
  • display: flex : enfants flexibles, en ligne par défaut, flex: 1/2… pour répartir l'espace.
