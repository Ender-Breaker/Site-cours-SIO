HTML5 (HyperText Markup Language) est le langage qui décrit la structure d'une page web. Un texte « seul » s'affiche mal dans un navigateur : il faut lui ajouter des informations, appelées balises, que le navigateur comprend.

1. Ta première page

<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bienvenue</h1>
    <p>Mon premier paragraphe.</p>
  </body>
</html>
ÉlémentRôle
<!doctype html>indique au navigateur qu'il s'agit d'une page HTML5
<head>instructions pour le navigateur et les moteurs de recherche (titre, jeu de caractères…) : non affiché
<title>titre affiché dans l'onglet du navigateur
<body>contenu de la page : tout ce qu'on veut visualiser (texte, image, vidéo…)
<meta charset="utf-8">jeu de caractères : permet d'écrire les accents sans code spécial

Les outils : un éditeur pour coder (éditeur de texte comme Visual Studio Code, ou éditeur WYSIWYG) et un navigateur pour exécuter et voir le résultat. Il suffit d'enregistrer le fichier, puis de recharger la page.

2. Anatomie d'un élément

<p class="intro">Un paragraphe</p>
  • <p> est la balise ouvrante, </p> la balise fermante.
  • class="intro" est un attribut (un nom et une valeur entre guillemets).
  • Le texte entre les deux balises est le contenu.

Un code bien formé

  • Les balises s'imbriquent sans jamais se chevaucher : on referme toujours la dernière balise ouverte. <b><i>texte</i></b> est correct, <b><i>texte</b></i> ne l'est pas.
  • On indente pour visualiser l'imbrication.
  • Jamais de texte isolé sans balise : un paragraphe est toujours dans <p>.
Les exceptions : balises sans fermeture

<br> (saut de ligne), <hr> (ligne horizontale) et <img> (image) n'encadrent aucun texte : elles n'ont pas de balise fermante.

3. Titres, paragraphes et mise en forme

BaliseEffet
<h1> … <h6>titres, du plus grand (h1) au plus petit (h6)
<p>paragraphe
<b> / <strong>texte en gras
<i> / <em>texte en italique
<br>saut de ligne
<hr>trace une ligne horizontale
<pre>reproduit le texte tel qu'il est codé (espaces et sauts de ligne conservés)
Espaces et sauts de ligne

Quel que soit le nombre d'espaces à la suite, le navigateur n'en affiche qu'un seul. Pour en forcer plusieurs : &nbsp; (espace insécable).

Les sauts de ligne du code sont ignorés : il faut <br> pour en forcer un.

4. Listes

<ul>                      <!-- liste à puces (non ordonnée) -->
  <li>Réseaux</li>
  <li>Programmation</li>
</ul>

<ol>                      <!-- liste numérotée (ordonnée) -->
  <li>Étape 1</li>
  <li>Étape 2</li>
</ol>

Chaque élément est un <li>. Pour faire une sous-liste, on imbrique un <ul> ou <ol> dans un <li>.

5. Liens et images

<a href="https://www.cisco.com/">Le site de Cisco</a>

<img src="cisco.jpg" alt="Logo Cisco" />

<!-- image cliquable : on met l'image dans un lien -->
<a href="https://www.cisco.com/"><img src="cisco.jpg" alt="Logo Cisco" /></a>
  • <a> crée un lien ; l'attribut href donne la cible. Le texte entre les balises devient cliquable.
  • <img> insère une image ; l'attribut src donne son emplacement (le fichier doit être dans le bon dossier). alt décrit l'image.
  • Pour une image cliquable, on place <img> dans une balise <a>.

6. Tableaux

<table border="1">
  <caption>Notes</caption>
  <tr>
    <th>Matière</th><th>Note</th>
  </tr>
  <tr>
    <td>Maths</td><td>14</td>
  </tr>
</table>
BaliseRôle
<table>le tableau (border : épaisseur de la bordure)
<caption>titre du tableau
<tr>une ligne (table row)
<td>une cellule de données
<th>une cellule d'en-tête
À retenir

Ajouter une cellule à une ligne revient à ajouter une colonne au tableau entier. Les cellules d'une même colonne ont la même largeur : celle de la plus grande donnée.

7. Structurer l'espace : div et span

BaliseRôle
<div>division : bloc qui occupe toute la largeur, sert à regrouper et organiser la page
<span>portion de texte dans une ligne, sert à mettre en forme quelques mots
Résumé express
  • Squelette : <!doctype html>, <html>, <head> (+ <title>), <body>.
  • Balises ouvrantes/fermantes, bien imbriquées ; <br>, <hr>, <img> sans fermeture.
  • <h1>–<h6>, <p>, <ul>/<ol>/<li>, <a href>, <img src>, <table>/<tr>/<td>/<th>.
  • <div> structure en blocs, <span> met en forme dans une ligne.
