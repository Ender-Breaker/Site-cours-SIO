4Connexion OBS

Pour piloter OBS en direct depuis cette page : dans OBS, Outils → Paramètres du serveur WebSocket → coche « Activer », note le port et le mot de passe.

Astuce : la config dans OBS

  1. OBS → Docks → Docks de navigateur personnalisés.
  2. Nom : Config overlay, URL : celle de cette page.
  3. Connecte-toi une fois ici ; tu pilotes ensuite tout sans quitter OBS.

6Ajouter les calques dans OBS

Sources HTML : Source navigateur, largeur 1920, hauteur 1080. Les PNG sont pour une Source image : télécharge-les d'abord sur ton PC (OBS n'accepte pas d'URL pour une image). Ordre conseillé, de bas en haut : fond, champions, timer, sponsors, logo.

URL simple : suit les réglages de cette page en direct. URL avec réglages : contient les réglages actuels du calque (utile si OBS n'est pas connecté), ils restent prioritaires à chaque rechargement.
