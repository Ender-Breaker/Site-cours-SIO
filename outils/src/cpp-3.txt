=== cpp-stl | C++ : la STL, conteneurs, algorithmes et lambdas | d
La **STL** (*Standard Template Library*) est la boîte à outils du C++ : des **conteneurs** pour ranger les données, des **algorithmes** pour les traiter, et des **itérateurs** pour relier les deux. La connaître évite de réécrire (mal) ce qui existe déjà.

## 1. `map` : le dictionnaire

`map<Clé, Valeur>` associe une valeur à chaque clé, et garde les clés **triées**.

```run h=iostream,map,string main
map<string, int> stock;
stock["souris"] = 3;
stock["clavier"] = 2;
stock["souris"] += 5;                       // modifie
stock["ecran"]++;                           // clé absente : créée avec la valeur 0, puis +1
cout << stock["souris"] << " " << stock.size() << endl;

for (const auto& [nom, quantite] : stock) {     // parcours dans l'ordre des clés
    cout << nom << " : " << quantite << endl;
}
if (stock.count("webcam") == 0) cout << "pas de webcam" << endl;
if (stock.contains("clavier")) cout << "clavier présent" << endl;     // C++20
stock.erase("clavier");
cout << stock.size() << endl;
```

!attention `m[cle]` crée la clé | Lire `stock["webcam"]` **ajoute** la clé avec la valeur 0 si elle n'existe pas. Pour tester la présence sans rien créer, utilise `count`, `contains` ou `find`.

## 2. `set`, `unordered_map`, `pair`

```run h=iostream,set,unordered_map,string,utility main
set<int> vus = {5, 2, 5, 8, 2};             // ensemble : pas de doublon, trié
vus.insert(1);
for (int v : vus) cout << v << " ";
cout << "(" << vus.size() << " valeurs)" << endl;

unordered_map<string, double> prix;         // table de hachage : accès très rapide, pas d'ordre
prix["souris"] = 19.9;
cout << prix["souris"] << endl;

pair<string, int> p = {"Léa", 17};          // deux valeurs réunies
cout << p.first << " " << p.second << endl;
auto [nom, age] = p;                        // décomposition (C++17)
cout << nom << " a " << age << " ans" << endl;
```

| Conteneur | Contenu | Particularité |
| `vector<T>` | suite d'éléments | accès par indice, le choix par défaut |
| `map<K, V>` | clé → valeur | clés triées |
| `unordered_map<K, V>` | clé → valeur | plus rapide, sans ordre |
| `set<T>` | valeurs uniques | triées |
| `pair<A, B>` | deux valeurs | `.first`, `.second` |
| `deque`, `list`, `stack`, `queue` | variantes | file, pile, liste chaînée |

## 3. Les lambdas : des fonctions écrites sur place

```run h=iostream main
auto carre = [](int x) { return x * x; };          // [] capture, () paramètres, {} corps
cout << carre(7) << endl;

int seuil = 10;
auto auDessus = [seuil](int x) { return x > seuil; };   // capture seuil par copie
cout << auDessus(15) << " " << auDessus(3) << endl;

int total = 0;
auto ajouter = [&total](int x) { total += x; };         // capture par référence : peut modifier
ajouter(5);
ajouter(7);
cout << total << endl;
```

| Capture | Signifie |
| `[]` | rien |
| `[x]` | une copie de x |
| `[&x]` | x par référence |
| `[=]` | tout ce qui est utilisé, par copie |
| `[&]` | tout ce qui est utilisé, par référence |

## 4. Les algorithmes

Ils travaillent sur un intervalle `[begin, end)` et prennent souvent une lambda.

```run h=iostream,vector,algorithm,numeric main
vector<int> v = {12, 5, 19, 8, 10};

sort(v.begin(), v.end());                                         // croissant
sort(v.begin(), v.end(), [](int a, int b) { return a > b; });     // décroissant
for (int x : v) cout << x << " ";
cout << endl;

cout << count_if(v.begin(), v.end(), [](int x) { return x >= 10; }) << " notes >= 10" << endl;
cout << accumulate(v.begin(), v.end(), 0) << endl;                // somme (<numeric>)
cout << *max_element(v.begin(), v.end()) << " " << *min_element(v.begin(), v.end()) << endl;

auto it = find(v.begin(), v.end(), 19);                           // renvoie un itérateur
if (it != v.end()) cout << "19 trouvé à l'indice " << it - v.begin() << endl;
cout << any_of(v.begin(), v.end(), [](int x) { return x < 6; }) << endl;
cout << all_of(v.begin(), v.end(), [](int x) { return x > 0; }) << endl;
```

### Transformer et filtrer

```run h=iostream,vector,algorithm main
vector<int> v = {1, 2, 3, 4, 5, 6};

vector<int> doubles(v.size());
transform(v.begin(), v.end(), doubles.begin(), [](int x) { return x * 2; });

vector<int> pairs;
copy_if(v.begin(), v.end(), back_inserter(pairs), [](int x) { return x % 2 == 0; });

v.erase(remove_if(v.begin(), v.end(), [](int x) { return x > 4; }), v.end());   // supprime selon un critère

for (int x : doubles) cout << x << " ";
cout << "| ";
for (int x : pairs) cout << x << " ";
cout << "| ";
for (int x : v) cout << x << " ";
cout << endl;
```

=== cpp-templates | C++ : templates et surcharge d'opérateurs | d
## 1. Le problème : le même code pour plusieurs types

Écrire `maxi` pour les `int`, puis pour les `double`, puis pour les `string`, c'est trois fois le même code. Un **template** est un modèle de fonction dont le type est un **paramètre**.

```run h=iostream,string main
template <typename T>
T maxi(T a, T b) {
    return a > b ? a : b;
}
@@
cout << maxi(3, 8) << endl;                          // T = int, déduit
cout << maxi(2.5, 1.5) << endl;                      // T = double
cout << maxi(string("abc"), string("abd")) << endl;  // T = string
cout << maxi<double>(3, 2.5) << endl;                // T imposé : sinon ambigu (int et double)
```

Le compilateur fabrique une version de la fonction **pour chaque type utilisé**. Il n'y a aucun coût à l'exécution.

## 2. Templates et conteneurs

```run h=iostream,vector,string main
template <typename T>
void afficher(const vector<T>& v) {
    for (const T& x : v) cout << x << " ";
    cout << endl;
}

template <typename T>
T somme(const vector<T>& v) {
    T total = T();                 // valeur par défaut du type : 0, 0.0, ""
    for (const T& x : v) total += x;
    return total;
}
@@
afficher(vector<int>{1, 2, 3});
afficher(vector<string>{"a", "b"});
cout << somme(vector<double>{1.5, 2.5}) << " " << somme(vector<string>{"ab", "cd"}) << endl;
```

## 3. Classes template

`vector<int>`, `map<string, int>`, `unique_ptr<Forme>` sont des classes template. On peut écrire les siennes :

```run h=iostream,vector,string main
template <typename T>
class Pile {
    vector<T> elements;
public:
    void empiler(const T& x) { elements.push_back(x); }
    T depiler() {
        T haut = elements.back();
        elements.pop_back();
        return haut;
    }
    bool vide() const { return elements.empty(); }
    size_t taille() const { return elements.size(); }
};
@@
Pile<int> p;
p.empiler(1); p.empiler(2); p.empiler(3);
cout << p.depiler() << " " << p.depiler() << " " << p.taille() << endl;

Pile<string> mots;
mots.empiler("monde"); mots.empiler("bonjour");
while (!mots.vide()) cout << mots.depiler() << " ";
cout << endl;
```

!attention Les messages d'erreur des templates | Une erreur dans l'utilisation d'un template produit souvent des dizaines de lignes. Remonte toujours à la **première** erreur : elle dit quel type a été utilisé et quelle opération lui manque.

## 4. Surcharger les opérateurs

On peut donner un sens à `+`, `==`, `<`, `<<`… pour ses propres classes. Un opérateur n'est qu'une fonction au nom spécial.

```run h=iostream main
struct Vec {
    double x, y;

    Vec operator+(const Vec& o) const { return {x + o.x, y + o.y}; }
    Vec operator*(double k) const { return {x * k, y * k}; }
    bool operator==(const Vec& o) const { return x == o.x && y == o.y; }
    Vec& operator+=(const Vec& o) { x += o.x; y += o.y; return *this; }
};

ostream& operator<<(ostream& flux, const Vec& v) {      // pour cout << v
    return flux << "(" << v.x << ", " << v.y << ")";
}
@@
Vec a{1, 2}, b{3, 4};
cout << a + b << endl;
cout << a * 10 << endl;
cout << (a == Vec{1, 2}) << endl;
a += b;
cout << a << endl;
```

`operator<<` est une fonction **hors de la classe** : son opérande de gauche est le flux (`cout`), pas l'objet. Elle renvoie le flux pour permettre d'enchaîner `cout << a << b`.

## 5. Rendre une classe triable

`sort`, `set` et `map` ont besoin de savoir comparer : il suffit de définir `operator<`.

```run h=iostream,vector,algorithm,string,set main
struct Version {
    int majeur, mineur;
    bool operator<(const Version& o) const {
        if (majeur != o.majeur) return majeur < o.majeur;
        return mineur < o.mineur;
    }
};
ostream& operator<<(ostream& f, const Version& v) { return f << v.majeur << "." << v.mineur; }
@@
vector<Version> v = {{2, 1}, {1, 9}, {2, 0}, {1, 10}};
sort(v.begin(), v.end());                 // utilise operator<
for (const Version& x : v) cout << x << " ";
cout << endl;
set<Version> uniques(v.begin(), v.end());
cout << uniques.size() << " " << *uniques.rbegin() << endl;     // la plus grande
```

=== cpp-projets | C++ : exceptions, fichiers et organisation d'un projet | m
Ce chapitre couvre ce qui transforme un exercice en vrai programme : gérer les erreurs, lire et écrire des fichiers, découper le code en plusieurs fichiers.

!info Dans le navigateur | Le compilateur du site tourne sans disque et sans gestion des exceptions : les exemples d'exceptions et de fichiers de ce chapitre ne sont pas exécutables ici. Ils fonctionnent tels quels sur ton ordinateur avec `g++`.

## 1. Les exceptions

Une **exception** signale une erreur en interrompant le déroulement normal. Elle remonte d'appel en appel jusqu'à un bloc `catch` capable de la traiter.

```
#include <iostream>
#include <stdexcept>
using namespace std;

double diviser(double a, double b) {
    if (b == 0) throw invalid_argument("division par zéro");     // lève l'exception
    return a / b;
}

int main() {
    try {
        cout << diviser(10, 2) << endl;
        cout << diviser(1, 0) << endl;        // lève : la suite du bloc try est sautée
        cout << "jamais affiché" << endl;
    } catch (const invalid_argument& e) {     // attrape par référence constante
        cout << "Erreur : " << e.what() << endl;
    } catch (const exception& e) {            // toute autre exception standard
        cout << "Erreur inattendue : " << e.what() << endl;
    }
    cout << "le programme continue" << endl;
}
```

| Exception standard | Usage |
| `invalid_argument` | argument incorrect |
| `out_of_range` | indice hors bornes (`v.at(i)`, `stoi`) |
| `runtime_error` | erreur détectée à l'exécution |
| `logic_error` | erreur de logique du programme |
| `bad_alloc` | plus de mémoire (`new`) |

Toutes dérivent de `std::exception` et ont une méthode `what()`. On crée la sienne en héritant de l'une d'elles :

```
class SoldeInsuffisant : public runtime_error {
public:
    SoldeInsuffisant() : runtime_error("solde insuffisant") {}
};
```

Grâce à RAII, les destructeurs des objets locaux sont appelés pendant la remontée de l'exception : rien ne fuit. Sans exceptions, on signale une erreur par une **valeur de retour**, comme dans cet exemple exécutable :

```run h=iostream,optional,string main
optional<double> diviser(double a, double b) {        // optional : une valeur, ou rien
    if (b == 0) return nullopt;
    return a / b;
}
@@
for (double b : {2.0, 0.0}) {
    optional<double> r = diviser(10, b);
    if (r) cout << "Résultat : " << *r << endl;
    else cout << "Erreur : division par zéro" << endl;
}
```

## 2. Lire et écrire des fichiers

La bibliothèque `<fstream>` fournit `ofstream` (écriture) et `ifstream` (lecture). Ils s'utilisent exactement comme `cout` et `cin`.

```
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ofstream sortie("scores.txt");               // crée ou écrase le fichier
    if (!sortie) { cerr << "Impossible d'ouvrir le fichier" << endl; return 1; }
    sortie << "Léa 120" << endl;
    sortie << "Sam 95" << endl;
    sortie.close();                              // facultatif : fermé par le destructeur (RAII)

    ifstream entree("scores.txt");
    string nom;
    int score;
    while (entree >> nom >> score) {             // lit tant qu'il y a des données
        cout << nom << " a " << score << " points" << endl;
    }

    ifstream lignes("scores.txt");
    string ligne;
    while (getline(lignes, ligne)) cout << ligne << endl;     // ligne par ligne

    ofstream ajout("scores.txt", ios::app);      // ios::app : ajoute à la fin
    ajout << "Zoé 150" << endl;
}
```

`cerr` est la sortie d'erreur ; `return 1` dans `main` signale au système que le programme a échoué. Pour découper une ligne, `stringstream` transforme une chaîne en flux, et celui-ci est exécutable :

```run h=iostream,sstream,string main
string ligne = "Léa 120 15.5";
stringstream flux(ligne);
string nom;
int score;
double note;
flux >> nom >> score >> note;
cout << nom << " | " << score + 1 << " | " << note * 2 << endl;
```

## 3. Plusieurs fichiers : `.h` et `.cpp`

Un vrai projet sépare la **déclaration** (ce qui existe : fichier d'en-tête `.h`) de la **définition** (le code : fichier `.cpp`).

```
// ---------- compte.h : la déclaration ----------
#pragma once                       // empêche d'inclure deux fois le même en-tête
#include <string>

class Compte {
    std::string titulaire;         // jamais de « using namespace std » dans un .h
    double solde;
public:
    Compte(const std::string& t, double s);
    void deposer(double montant);
    double getSolde() const;
};
```

```
// ---------- compte.cpp : la définition ----------
#include "compte.h"                // guillemets : fichier du projet

Compte::Compte(const std::string& t, double s) : titulaire(t), solde(s) {}
void Compte::deposer(double montant) { solde += montant; }      // Compte:: = « de la classe Compte »
double Compte::getSolde() const { return solde; }
```

```
// ---------- main.cpp ----------
#include <iostream>
#include "compte.h"

int main() {
    Compte c("Léa", 100);
    c.deposer(50);
    std::cout << c.getSolde() << std::endl;
}
```

```
g++ -Wall -std=c++20 main.cpp compte.cpp -o banque
```

La construction se fait en deux temps : la **compilation** transforme chaque `.cpp` en fichier objet `.o`, puis l'**édition de liens** (*link*) les assemble. D'où deux familles d'erreurs : `error: …` (compilation) et `undefined reference to …` (édition de liens : la fonction est déclarée mais sa définition n'a pas été fournie).

## 4. Les espaces de noms

Un `namespace` regroupe des noms pour éviter les collisions : c'est ce qu'est `std`.

```run h=iostream main
namespace geometrie {
    const double PI = 3.14159;
    double aireCercle(double r) { return PI * r * r; }
}
namespace finance {
    double aireCercle(double) { return 0; }       // même nom, aucun conflit
}
@@
cout << geometrie::aireCercle(1) << endl;
using geometrie::PI;                              // n'importe qu'un nom
cout << PI << endl;
```

## 6. Lire les erreurs du compilateur

| Message | Cause habituelle |
| `expected ';'` | point-virgule oublié, souvent à la ligne **précédente** |
| `'x' was not declared in this scope` | faute de frappe, `#include` manquant, variable hors de portée |
| `no matching function for call to` | mauvais nombre ou mauvais type d'arguments |
| `invalid conversion` / `cannot convert` | types incompatibles |
| `undefined reference to` | définition absente à l'édition de liens (fichier `.cpp` oublié) |
| `segmentation fault` (à l'exécution) | pointeur nul ou indice hors bornes |

Compile toujours avec `-Wall -Wextra` : les avertissements signalent de vrais bugs (variable non initialisée, `=` au lieu de `==`).

=== cpp-jeu | C++ : créer un jeu dans le navigateur | d
La plupart des grands jeux sont écrits en C++ (Unreal Engine, les moteurs maison des studios) : il est rapide et contrôle précisément la mémoire. Dans le navigateur, le C++ est compilé en **WebAssembly**, un format binaire exécuté presque aussi vite que du code natif. C'est ce que fait le labo.

!info Où tester ? | Les jeux ont besoin d'un écran : ils se lancent dans le [bac à sable du labo](labo-cpp.html#libre). Copie les exemples de ce chapitre et modifie-les.

## 1. La boucle de jeu

Le programme n'a pas de `main` : c'est le moteur qui appelle tes fonctions.

```
#include "jeu.h"                 // l'API du labo

double x = 200;                  // l'état du jeu

void setup() {                   // une fois, au démarrage
    x = 50;
}

void update(double dt) {         // 60 fois par seconde : la logique
    if (touche("droite")) x += 200 * dt;      // 200 pixels par seconde
}

void draw() {                    // 60 fois par seconde : l'affichage
    effacer("black");
    rect(x, 140, 40, 40, "gold");
}
```

`dt` est le temps écoulé depuis l'image précédente (environ 0,016 s). Multiplier une vitesse par `dt` donne un mouvement identique sur toutes les machines.

| Fonction | Rôle |
| `effacer(c)` | remplit l'écran (480 × 320) |
| `rect(x, y, l, h, c)` | rectangle plein (coin haut gauche) |
| `cercle(x, y, r, c)` | disque (centre) |
| `ligne(x1, y1, x2, y2, c)` | segment |
| `texte(t, x, y, taille, c)` | texte (`std::to_string` pour les nombres) |
| `touche("gauche")` | vrai tant que la touche est enfoncée |
| `toucheAppuyee("espace")` | vrai une seule image, à l'appui |
| `sourisX()`, `sourisY()`, `clic()` | souris |
| `hasard(a, b)` | entier au hasard entre a et b |
| `LARGEUR`, `HAUTEUR` | 480 et 320 |

L'origine est en **haut à gauche** et `y` augmente vers le **bas**.

## 2. Des entités avec des `struct`

```
#include "jeu.h"
#include <vector>

struct Balle {
    double x, y, vx, vy;
    void avancer() {
        x += vx; y += vy;
        if (x < 10 || x > LARGEUR - 10) vx = -vx;
        if (y < 10 || y > HAUTEUR - 10) vy = -vy;
    }
};

std::vector<Balle> balles;

void setup() {
    for (int i = 0; i < 5; i++)
        balles.push_back({ (double)hasard(20, 460), (double)hasard(20, 300), 3.0, 2.0 });
}

void update(double dt) {
    for (Balle& b : balles) b.avancer();          // Balle& : on modifie l'original
}

void draw() {
    effacer("#16182b");
    for (const Balle& b : balles) cercle(b.x, b.y, 10, "gold");
}
```

## 4. Collisions

Le test de chevauchement de deux rectangles (AABB), exécutable ici car il n'a pas besoin d'écran :

```run h=iostream main
struct Boite { double x, y, l, h; };
```

## 5. Créer et supprimer des objets

On supprime avec l'idiome *erase-remove* : `remove_if` regroupe les éléments à garder, `erase` coupe le reste.

```run h=iostream,vector,algorithm main
struct Tir { double x, y; };
@@
vector<Tir> tirs = {{10, 50}, {20, -5}, {30, 120}, {40, -30}};
for (Tir& t : tirs) t.y -= 10;
tirs.erase(remove_if(tirs.begin(), tirs.end(), [](const Tir& t) { return t.y < 0; }), tirs.end());

```

## 6. Les états du jeu

```
enum class Etat { Menu, Jeu, Fin };
Etat etat = Etat::Menu;
int score = 0;

void update(double dt) {
    switch (etat) {
        case Etat::Menu: if (toucheAppuyee("espace")) { etat = Etat::Jeu; score = 0; } break;
        case Etat::Jeu:  score++; if (score > 300) etat = Etat::Fin; break;
        case Etat::Fin:  if (toucheAppuyee("espace")) etat = Etat::Menu; break;
    }
}

void draw() {
    effacer("black");
    if (etat == Etat::Menu) texte("ESPACE pour jouer", 130, 150, 24, "white");
    else if (etat == Etat::Jeu) texte("Score : " + std::to_string(score), 16, 16, 24, "white");
    else texte("Perdu ! Score : " + std::to_string(score), 130, 150, 24, "tomato");
}
```
