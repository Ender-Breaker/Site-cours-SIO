=== cs-bases | C# : la syntaxe, les types et les collections | f
Le **C#** (« C sharp ») est le langage de la plateforme **.NET** de Microsoft. C'est l'un des langages les plus enseignés en option SLAM : applications de bureau (WinForms, WPF), sites et API (ASP.NET Core), jeux (Unity). Sa syntaxe est très proche de celle de Java : si tu as suivi le cours Java de ce site, tu connais déjà les trois quarts du C#.

!info Pour pratiquer | Installe le **SDK .NET** (gratuit) et **Visual Studio Community** ou VS Code. En ligne de commande : `dotnet new console -n MonProjet`, puis `dotnet run`.

## 1. Le programme minimal

```
// Program.cs : depuis .NET 6, pas besoin de classe ni de Main pour débuter
Console.WriteLine("Bonjour !");
```

La forme complète, que tu verras dans les sujets et les projets plus anciens :

```
using System;

namespace MonProjet
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Bonjour !");
        }
    }
}
```

## 2. Variables et types

```
int age = 17;
double prix = 19.99;
decimal montant = 19.99m;            // decimal : pour l'argent, sans erreur d'arrondi
bool majeur = false;
char initiale = 'L';
string prenom = "Léa";               // string en minuscules
var total = prix * 3;                // var : type déduit (double)
const double TVA = 0.2;              // constante

Console.WriteLine($"{prenom} a {age} ans");          // chaîne interpolée : $"…{variable}…"
Console.WriteLine($"Prix : {prix:F2} €");            // F2 : deux décimales
Console.WriteLine(7 / 2);                            // 3 : division entière, comme en Java
Console.WriteLine((double)7 / 2);                    // 3,5
```

## 3. Lire au clavier et convertir

```
Console.Write("Ton âge : ");
string saisie = Console.ReadLine();
int age = int.Parse(saisie);                         // lève une exception si ce n'est pas un nombre

if (int.TryParse(saisie, out int n))                 // la forme sûre : renvoie true ou false
    Console.WriteLine($"Dans 10 ans : {n + 10}");
else
    Console.WriteLine("Ce n'est pas un nombre");
```

## 4. Conditions et boucles

Identiques à Java : `if / else if / else`, `switch`, `while`, `do … while`, `for`. Le parcours d'une collection s'écrit `foreach … in`.

```
if (note >= 16) Console.WriteLine("Très bien");
else if (note >= 10) Console.WriteLine("Admis");
else Console.WriteLine("Recalé");

string mention = note switch                         // expression switch
{
    >= 16 => "Très bien",
    >= 10 => "Admis",
    _ => "Recalé"                                    // _ : cas par défaut
};

for (int i = 1; i <= 5; i++) Console.Write(i + " ");

string[] fruits = { "pomme", "kiwi", "poire" };
foreach (string f in fruits) Console.WriteLine(f);
```

!info Bonne nouvelle | En C#, `==` compare le **contenu** des `string` (contrairement à Java) : `if (reponse == "oui")` fonctionne comme on s'y attend.

## 5. Méthodes

```
static double Aire(double largeur, double hauteur)   // PascalCase pour les méthodes
{
    return largeur * hauteur;
}

static double Ttc(double ht, double taux = 0.2) => ht * (1 + taux);     // corps d'expression, valeur par défaut

static bool Diviser(int a, int b, out int resultat)                     // out : un second résultat
{
    resultat = b == 0 ? 0 : a / b;
    return b != 0;
}
```

## 7. Du Java au C# : la table de correspondance

| Java | C# |
| `System.out.println(x)` | `Console.WriteLine(x)` |
| `String`, `boolean` | `string`, `bool` |
| `final` | `const` (ou `readonly` pour un attribut) |
| `ArrayList<String>` | `List<string>` |
| `HashMap<K, V>` | `Dictionary<K, V>` |
| `liste.size()`, `liste.get(i)` | `liste.Count`, `liste[i]` |
| `for (String s : liste)` | `foreach (string s in liste)` |
| `a.equals(b)` pour les chaînes | `a == b` |
| `Integer.parseInt(s)` | `int.Parse(s)` |
| `package` / `import` | `namespace` / `using` |
| méthodes en `camelCase` | méthodes en `PascalCase` |
| `"a" + x` ou `String.format` | `$"a{x}"` |

!tuto Un inventaire en console
# Lire des articles
```
var stock = new Dictionary<string, int>();
Console.Write("Nombre d'articles : ");
int n = int.Parse(Console.ReadLine());
for (int i = 0; i < n; i++)
{
    Console.Write("Nom : ");
    string nom = Console.ReadLine();
    Console.Write("Quantité : ");
    int qte = int.Parse(Console.ReadLine());
    stock[nom] = stock.GetValueOrDefault(nom) + qte;     // 0 si la clé est absente
}
```
# Afficher trié
```
foreach (var (nom, qte) in stock.OrderBy(p => p.Key))    // OrderBy : LINQ, chapitre suivant
    Console.WriteLine($"{nom,-15}{qte,5}");              // alignement : 15 à gauche, 5 à droite
```
!fin

=== cs-poo | C# : classes, propriétés, LINQ et accès aux données | m
## 1. Classes et propriétés

Là où Java écrit des accesseurs `getX` / `setX`, C# a des **propriétés** : elles s'utilisent comme des attributs mais peuvent contenir du contrôle.

```
class Compte
{
    public string Titulaire { get; set; }            // propriété automatique
    public double Solde { get; private set; }        // lisible partout, modifiable dans la classe seulement

    private string _code;                            // attribut privé (convention : tiret bas)
    public string Code
    {
        get { return _code; }
        set { if (value.Length == 4) _code = value; }     // value : la valeur affectée
    }

    public Compte(string titulaire, double solde = 0)     // constructeur
    {
        Titulaire = titulaire;
        Solde = solde;
    }

    public void Deposer(double montant)
    {
        if (montant <= 0) throw new ArgumentException("Montant invalide");
        Solde += montant;
    }

    public override string ToString() => $"{Titulaire} : {Solde:F2} €";
}
```

```
var c = new Compte("Léa", 100);
c.Deposer(50);
c.Titulaire = "Léa Martin";          // appelle le set
Console.WriteLine(c.Solde);          // appelle le get
// c.Solde = 1000000;                // refusé : set privé
Console.WriteLine(c);                // appelle ToString
```

## 2. Héritage et interfaces

```
abstract class Forme
{
    public abstract double Aire();                        // à définir dans les filles
    public virtual string Nom() => "forme";               // virtual : redéfinissable
    public string Description() => $"{Nom()} d'aire {Aire():F2}";
}

class Rectangle : Forme                                   // « : » remplace extends
{
    private readonly double l, h;
    public Rectangle(double l, double h) { this.l = l; this.h = h; }
    public override double Aire() => l * h;               // override obligatoire
    public override string Nom() => "rectangle";
}

interface IExportable                                     // convention : un I devant le nom
{
    string VersCsv();
}

class Produit : IExportable                               // « : » remplace aussi implements
{
    public string Nom { get; set; }
    public double Prix { get; set; }
    public string VersCsv() => $"{Nom};{Prix}";
}
```

| Java | C# |
| `class B extends A implements I` | `class B : A, I` |
| `super(…)` / `super.methode()` | `base(…)` / `base.Methode()` |
| redéfinition libre, `@Override` conseillé | `virtual` dans la mère **et** `override` dans la fille |
| `getX()` / `setX()` | propriété `X { get; set; }` |
| `toString()` | `ToString()` |

## 3. Les exceptions

```
try
{
    int n = int.Parse(Console.ReadLine());
    Console.WriteLine(100 / n);
}
catch (FormatException)
{
    Console.WriteLine("Il faut un nombre entier.");
}
catch (DivideByZeroException e)
{
    Console.WriteLine($"Erreur : {e.Message}");
}
finally
{
    Console.WriteLine("Fin");
}
```

Toutes les exceptions C# sont « non vérifiées » : pas de `throws` dans les signatures. Le bloc `using` ferme automatiquement une ressource, comme le `try`-with-resources de Java.

## 4. LINQ : interroger les collections

**LINQ** permet de filtrer, trier et agréger une collection comme on écrirait une requête SQL. C'est l'équivalent des streams de Java.

```
using System.Linq;

var eleves = new List<Eleve>
{
    new Eleve("Léa", "SLAM", 15), new Eleve("Sam", "SISR", 9),
    new Eleve("Zoé", "SLAM", 18), new Eleve("Tom", "SISR", 12)
};

var admisSlam = eleves
    .Where(e => e.Option == "SLAM" && e.Note >= 10)       // filtre
    .OrderByDescending(e => e.Note)                       // tri
    .Select(e => e.Nom);                                  // projection
Console.WriteLine(string.Join(", ", admisSlam));          // Zoé, Léa

double moyenne = eleves.Average(e => e.Note);
int nbAdmis = eleves.Count(e => e.Note >= 10);
Eleve meilleur = eleves.MaxBy(e => e.Note);
bool tousAdmis = eleves.All(e => e.Note >= 10);
var parOption = eleves.GroupBy(e => e.Option);
foreach (var groupe in parOption)
    Console.WriteLine($"{groupe.Key} : {groupe.Count()} élèves");
```

| LINQ | SQL | Stream Java |
| `Where` | `WHERE` | `filter` |
| `Select` | `SELECT` | `map` |
| `OrderBy` | `ORDER BY` | `sorted` |
| `GroupBy` | `GROUP BY` | `groupingBy` |
| `Count`, `Sum`, `Average`, `Max` | `COUNT`, `SUM`, `AVG`, `MAX` | `count`, `sum`, `average`, `max` |
| `First`, `FirstOrDefault` | `LIMIT 1` | `findFirst` |

## 5. Accéder à une base de données

Avec ADO.NET, le schéma est le même qu'en JDBC : **connexion → commande paramétrée → lecteur**.

```
using MySqlConnector;

string chaine = "Server=localhost;Database=parc;User ID=app;Password=…";
using var cnx = new MySqlConnection(chaine);
cnx.Open();

using var cmd = new MySqlCommand("SELECT nom, prix FROM materiel WHERE prix > @seuil", cnx);
cmd.Parameters.AddWithValue("@seuil", 100);               // paramètre : pas d'injection SQL

using var lecteur = cmd.ExecuteReader();
while (lecteur.Read())
    Console.WriteLine($"{lecteur.GetString("nom")} : {lecteur.GetDouble("prix")}");
```

!attention Toujours des paramètres | Comme en PHP et en Java : ne construis jamais une requête en concaténant une saisie. Les paramètres `@nom` transmettent la saisie comme une donnée.

Dans les projets récents, on utilise souvent **Entity Framework Core**, un ORM : on manipule des objets et des requêtes LINQ, et il génère le SQL.

```
var chers = contexte.Materiels.Where(m => m.Prix > 100).OrderBy(m => m.Nom).ToList();
```

!tuto Une gestion de tickets d'assistance
# Le modèle
```
enum Priorite { Basse, Normale, Urgente }

class Ticket
{
    public int Numero { get; }
    public string Titre { get; }
    public Priorite Priorite { get; }
    public bool Resolu { get; private set; }

    public Ticket(int numero, string titre, Priorite priorite)
    {
        Numero = numero; Titre = titre; Priorite = priorite;
    }
    public void Resoudre() => Resolu = true;
}
```
# La liste et les requêtes LINQ
```
var tickets = new List<Ticket>
{
    new Ticket(1, "Imprimante hors ligne", Priorite.Normale),
    new Ticket(2, "Serveur de fichiers en panne", Priorite.Urgente),
    new Ticket(3, "Mot de passe oublié", Priorite.Basse)
};
tickets[2].Resoudre();

var aTraiter = tickets.Where(t => !t.Resolu).OrderByDescending(t => t.Priorite);
foreach (var t in aTraiter)
    Console.WriteLine($"#{t.Numero} [{t.Priorite}] {t.Titre}");
Console.WriteLine($"{tickets.Count(t => t.Resolu)} ticket(s) résolu(s)");
```
