=== cpp-bases | C++ : compiler, afficher, lire | f
Le **C++** est né en 1985 comme une extension du langage C. C'est un langage **compilé** et **typé** : rapide, précis, exigeant. Il fait tourner les moteurs de jeu (Unreal Engine), les navigateurs web, les systèmes d'exploitation, les bases de données, les logiciels embarqués. Si tu comprends le C++, tu comprends ce que font réellement les autres langages derrière ton dos.

!info Comment suivre ce cours | Chaque bloc avec un bouton **Exécuter** est compilé par un vrai compilateur C++20 (clang) dans ton navigateur. La première compilation prend quelques secondes. Modifie le code, provoque des erreurs, lis les messages du compilateur : c'est lui ton meilleur professeur.

## 1. Le programme minimal

```run
#include <iostream>
using namespace std;

int main() {
    cout << "Bonjour !" << endl;
    return 0;
}
```

| Élément | Rôle |
| `#include <iostream>` | charge la bibliothèque d'entrées-sorties (`cout`, `cin`) |
| `using namespace std;` | évite d'écrire `std::cout`, `std::string`… |
| `int main() { … }` | la fonction par laquelle le programme commence |
| `cout << …` | envoie une valeur vers l'écran (*character output*) |
| `endl` | retour à la ligne (on peut aussi écrire `"\n"`) |
| `return 0;` | le programme s'est bien terminé |
| `;` | termine **chaque instruction** : l'oubli le plus fréquent |

## 2. De la source au programme : la compilation

Un programme C++ ne s'exécute pas directement. Le **compilateur** traduit le fichier source `.cpp` en langage machine :

```
g++ main.cpp -o programme     # compile (g++ ou clang++)
./programme                   # exécute
g++ -Wall -Wextra -std=c++20 main.cpp -o programme   # avec tous les avertissements
```

Conséquence : beaucoup d'erreurs sont détectées **avant** l'exécution. Une *erreur de compilation* (faute de syntaxe, type incorrect) empêche de produire le programme ; une *erreur d'exécution* survient pendant qu'il tourne.

```run err h=iostream main
cout << "Il manque quelque chose" << endl
```

Lis toujours la **première** erreur : elle indique la ligne et ce que le compilateur attendait. Les suivantes en sont souvent des conséquences.

## 3. Variables et types

En C++, chaque variable a un **type** fixé à sa création, qui ne changera jamais.

```run h=iostream,string main
int age = 17;                // entier
double prix = 19.99;         // nombre à virgule
char initiale = 'L';         // UN caractère, entre apostrophes
bool majeur = false;         // true ou false
string prenom = "Léa";       // texte, entre guillemets
cout << prenom << " a " << age << " ans" << endl;
cout << prix << " " << initiale << " " << majeur << endl;   // false s'affiche 0
age = age + 1;
cout << age << endl;
```

| Type | Contenu | Exemple |
| `int` | entier (environ ±2 milliards) | `42` |
| `long long` | très grand entier | `9000000000LL` |
| `double` | nombre à virgule | `3.14` |
| `char` | un caractère | `'A'` |
| `bool` | vrai ou faux | `true` |
| `string` | texte (bibliothèque `<string>`) | `"Bonjour"` |

!attention Une variable non initialisée contient n'importe quoi | `int x;` sans valeur ne vaut pas 0 : elle contient ce qui traînait en mémoire. Donne toujours une valeur de départ : `int x = 0;`.

### `const` et `auto`

```run h=iostream,string main
const double TVA = 0.2;      // constante : toute modification est refusée à la compilation
auto quantite = 3;           // auto : le compilateur déduit int
auto total = quantite * 9.99;   // … et ici double
auto nom = string("Sam");
cout << total * (1 + TVA) << " " << nom << endl;
```

## 4. Les opérateurs et leurs pièges

```run h=iostream main
cout << 7 / 2 << endl;          // 3   : entier / entier = entier !
cout << 7.0 / 2 << endl;        // 3.5 : dès qu'un des deux est double
cout << 7 % 2 << endl;          // 1   : reste de la division
int a = 7, b = 2;
cout << static_cast<double>(a) / b << endl;   // 3.5 : conversion explicite
int i = 5;
i++;            // i = i + 1
i += 10;        // i = i + 10
i *= 2;
cout << i << endl;
cout << (5 > 3) << " " << (5 == 3) << " " << (5 != 3) << endl;
```

!attention Division entière | `7 / 2` vaut `3`, pas `3.5`. Pour une moyenne, écris `somme / 3.0` ou convertis avec `static_cast<double>(somme)`.

## 5. Lire au clavier

`cin >> variable` lit une valeur et la convertit dans le type de la variable. Les valeurs sont séparées par des espaces ou des retours à la ligne.

```run stdin=Léa|17 h=iostream,string main
string prenom;
int age;
cin >> prenom >> age;
cout << "Bonjour " << prenom << ", dans 10 ans tu auras " << age + 10 << " ans." << endl;
```

`cin >>` s'arrête au premier espace. Pour lire une **ligne entière**, on utilise `getline` :

```run stdin=Jean~Dupont h=iostream,string main
string nomComplet;
getline(cin, nomComplet);
cout << "Bonjour " << nomComplet << " (" << nomComplet.size() << " caractères)" << endl;
```

=== cpp-conditions-boucles | C++ : conditions et boucles | f
## 1. `if`, `else if`, `else`

```run stdin=15 h=iostream main
double note;
cin >> note;
if (note >= 16) {
    cout << "Très bien" << endl;
} else if (note >= 10) {
    cout << "Admis" << endl;
} else {
    cout << "Recalé" << endl;
}
```

La condition est entre **parenthèses**, le bloc entre **accolades**. Les accolades sont facultatives pour une seule instruction, mais mets-les toujours : cela évite des bugs célèbres.

## 2. Comparer et combiner

| Opérateur | Sens |
| `==` `!=` | égal, différent |
| `<` `<=` `>` `>=` | comparaisons |
| `&&` | et |
| `||` | ou |
| `!` | non |

```run h=iostream main
int age = 17;
bool carte = true;
cout << (age >= 18 && carte) << endl;     // 0
cout << (age >= 18 || carte) << endl;     // 1
cout << !carte << endl;                   // 0
cout << boolalpha << (age > 10) << endl;  // boolalpha : affiche true / false
```

!attention `=` n'est pas `==` | `if (x = 5)` **affecte** 5 à x puis teste 5, qui est toujours vrai. Le compilateur ne te prévient que si tu actives les avertissements (`-Wall`). En C++, tout nombre différent de 0 est vrai.

## 3. L'opérateur ternaire et `switch`

```run stdin=3 h=iostream,string main
int jour;
cin >> jour;
string type = (jour >= 6) ? "week-end" : "semaine";   // condition ? si vrai : si faux
cout << type << endl;

switch (jour) {
    case 1: cout << "lundi" << endl; break;
    case 2: cout << "mardi" << endl; break;
    case 3: cout << "mercredi" << endl; break;
    case 6:
    case 7: cout << "repos" << endl; break;      // deux cas, même traitement
    default: cout << "autre jour" << endl;
}
```

`switch` compare une valeur **entière** (ou un `char`, un `enum`) à des constantes. Sans `break`, l'exécution **continue dans le cas suivant**.

## 4. `while` et `do … while`

```run h=iostream main
int n = 1;
while (n < 100) {        // teste AVANT chaque tour
    n *= 2;
}
cout << n << endl;

int essais = 0;
do {                     // teste APRÈS : au moins un tour
    essais++;
} while (essais * essais <= 50);
cout << essais << endl;
```

## 5. `for`

`for (départ; condition; évolution)` : le départ s'exécute une fois, la condition avant chaque tour, l'évolution après chaque tour.

```run h=iostream main
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
cout << endl;
for (int i = 10; i > 0; i -= 3) cout << i << " ";
cout << endl;
for (int ligne = 1; ligne <= 3; ligne++) {          // boucles imbriquées
    for (int col = 1; col <= ligne; col++) cout << "*";
    cout << endl;
}
```

## 6. `break` et `continue`

```run h=iostream main
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;    // passe directement au tour suivant
    if (i > 7) break;            // sort de la boucle
    cout << i << " ";
}
cout << endl;
```

!attention Les boucles infinies | Une boucle dont la condition ne devient jamais fausse ne s'arrête pas : vérifie toujours que la variable testée **change** dans la boucle. Dans le labo, le programme est coupé au bout de quelques secondes.

=== cpp-fonctions | C++ : fonctions et références | m
## 1. Déclarer et appeler

Une fonction annonce le **type de ce qu'elle renvoie**, son nom, et le type de chaque paramètre. `void` signifie « ne renvoie rien ».

```run h=iostream,string main
double aire(double largeur, double hauteur) {
    return largeur * hauteur;
}

void saluer(string nom) {
    cout << "Bonjour " << nom << " !" << endl;
}
@@
cout << aire(3, 4.5) << endl;
saluer("Léa");
```

Une fonction doit être **connue avant d'être utilisée**. Soit on la définit au-dessus de `main`, soit on écrit d'abord son **prototype** (la première ligne suivie d'un point-virgule) et sa définition plus bas :

```run h=iostream
int carre(int x);              // prototype : promesse que la fonction existe

int main() {
    cout << carre(7) << endl;
}

int carre(int x) {             // définition
    return x * x;
}
```

## 2. Passage par valeur : la fonction reçoit une copie

```run h=iostream main
void doubler(int n) {
    n = n * 2;                 // modifie la COPIE
}
@@
int x = 5;
doubler(x);
cout << x << endl;             // 5 : x n'a pas changé
```

## 3. Passage par référence : la fonction agit sur l'original

Un `&` après le type crée une **référence** : un autre nom pour la même variable.

```run h=iostream main
void doubler(int& n) {
    n = n * 2;                 // modifie l'ORIGINAL
}

void echanger(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}
@@
int x = 5, y = 9;
doubler(x);
echanger(x, y);
cout << x << " " << y << endl;     // 9 10
```

### `const &` : sans copie et sans modification

Copier un gros objet (un long texte, un tableau) coûte cher. On le passe alors par **référence constante** : pas de copie, et la fonction s'engage à ne pas le modifier.

```run h=iostream,string main
int compterA(const string& texte) {      // la forme à retenir pour les objets
    int n = 0;
    for (char c : texte) {
        if (c == 'a') n++;
    }
    return n;
}
@@
cout << compterA("abracadabra") << endl;
```

| Passage | Écriture | Quand |
| par valeur | `int n` | petits types (`int`, `double`, `char`, `bool`) |
| par référence | `int& n` | la fonction doit **modifier** la variable |
| par référence constante | `const string& s` | gros objets en lecture seule |

## 4. Valeurs par défaut et surcharge

```run h=iostream,string main
double prixTTC(double ht, double taux = 0.2) {        // valeur par défaut
    return ht * (1 + taux);
}

int maxi(int a, int b) { return a > b ? a : b; }                   // même nom,
double maxi(double a, double b) { return a > b ? a : b; }          // paramètres différents :
string maxi(const string& a, const string& b) { return a > b ? a : b; }   // surcharge
@@
cout << prixTTC(100) << " " << prixTTC(100, 0.055) << endl;
cout << maxi(3, 8) << " " << maxi(2.5, 1.5) << " " << maxi(string("abc"), string("abd")) << endl;
```

Le compilateur choisit la bonne version d'après les **types des arguments**. Les paramètres avec valeur par défaut se placent en dernier.

## 5. Récursivité

```run h=iostream main
long long factorielle(int n) {
    if (n <= 1) return 1;                  // cas d'arrêt
    return n * factorielle(n - 1);         // appel récursif
}
@@
cout << factorielle(5) << " " << factorielle(20) << endl;
```

## 6. Portée des variables

Une variable existe de sa déclaration jusqu'à l'accolade fermante de son bloc. Une variable déclarée hors de toute fonction est **globale** : à éviter, sauf pour des constantes.

```run h=iostream main
const int MAX = 3;                  // constante globale : acceptable

int compteur() {
    static int n = 0;               // static : garde sa valeur entre les appels
    n++;
    return n;
}
@@
for (int i = 0; i < MAX; i++) cout << compteur() << " ";
cout << endl;
```

# Renvoyer deux résultats par référence
Une fonction ne renvoie qu'une valeur avec `return` ; les références permettent d'en « sortir » plusieurs.
```run h=iostream,vector main
void minmax(const vector<double>& t, double& mini, double& maxi) {
    mini = maxi = t[0];
    for (double v : t) {
        if (v < mini) mini = v;
        if (v > maxi) maxi = v;
    }
}
@@
double a, b;
minmax({12, 5, 19, 8}, a, b);
cout << a << " " << b << endl;
```
# Composer les fonctions
```run h=iostream,vector main
double moyenne(const vector<double>& t) {
    double s = 0;
    for (double v : t) s += v;
    return s / t.size();
}
int auDessus(const vector<double>& t, double seuil) {
    int n = 0;
    for (double v : t) if (v > seuil) n++;
    return n;
}
@@
vector<double> notes = {12, 5, 19, 8, 10};
cout << auDessus(notes, moyenne(notes)) << " notes au-dessus de la moyenne" << endl;
```

=== cpp-vector-string | C++ : tableaux, vector et string | m
## 1. `vector` : le tableau qui grandit

`vector<T>` (bibliothèque `<vector>`) est le conteneur à utiliser par défaut : une suite d'éléments du même type `T`, dont la taille peut changer.

```run h=iostream,vector main
vector<int> notes = {12, 15, 9};
notes.push_back(18);                 // ajoute à la fin
cout << notes[0] << " " << notes.size() << endl;    // premier élément : indice 0
notes[1] = 16;                       // modifie
cout << notes.front() << " " << notes.back() << endl;   // premier et dernier
notes.pop_back();                    // retire le dernier
cout << notes.size() << " " << notes.empty() << endl;

vector<double> zeros(5, 0.0);        // 5 éléments à 0.0
vector<string> vide;                 // vide
cout << zeros.size() << " " << vide.size() << endl;
```

Les indices vont de **0** à `size() - 1`.

!attention Dépasser les bornes | `notes[10]` sur un vector de 3 éléments ne provoque **pas** d'erreur claire : c'est un *comportement indéfini*, le programme lit n'importe quoi ou plante. `notes.at(10)` vérifie l'indice et arrête proprement le programme.

## 2. Parcourir

```run h=iostream,vector main
vector<int> notes = {12, 15, 9, 18};

for (int n : notes) cout << n << " ";            // for « range » : chaque valeur (copie)
cout << endl;

for (int& n : notes) n += 1;                     // int& : modifie les éléments

for (size_t i = 0; i < notes.size(); i++) {      // avec l'indice
    cout << i << ":" << notes[i] << " ";
}
cout << endl;

int somme = 0;
for (const auto& n : notes) somme += n;          // const auto& : la forme générale
cout << "Moyenne : " << static_cast<double>(somme) / notes.size() << endl;
```

## 3. Insérer, supprimer, trier

```run h=iostream,vector,algorithm main
vector<int> v = {5, 2, 8, 1};
v.insert(v.begin() + 1, 99);          // insère 99 à l'indice 1
v.erase(v.begin());                   // supprime l'élément d'indice 0
sort(v.begin(), v.end());             // trie (bibliothèque <algorithm>)
for (int x : v) cout << x << " ";
cout << endl;
reverse(v.begin(), v.end());
cout << v[0] << " " << *max_element(v.begin(), v.end()) << endl;
v.clear();
cout << v.size() << endl;
```

`v.begin()` et `v.end()` sont des **itérateurs** : ils désignent le début et la fin (juste après le dernier élément). Presque tous les algorithmes de la bibliothèque standard les utilisent.

## 4. Tableaux à deux dimensions

```run h=iostream,vector main
vector<vector<int>> grille(3, vector<int>(4, 0));    // 3 lignes de 4 zéros
grille[1][2] = 7;
for (const auto& ligne : grille) {
    for (int c : ligne) cout << c << " ";
    cout << endl;
}
```

## 5. Les tableaux hérités du C

Tu les croiseras dans du code existant. Leur taille est **fixe** et ils ne connaissent pas leur propre taille.

```run h=iostream,array main
int ancien[3] = {10, 20, 30};            // tableau C : à éviter dans du code neuf
array<int, 3> moderne = {10, 20, 30};    // std::array : taille fixe, mais sûr
cout << ancien[1] << " " << moderne[1] << " " << moderne.size() << endl;
```

## 6. `string`

```run h=iostream,string main
string s = "Bonjour";
s += " C++";                              // concaténation
cout << s << " " << s.size() << endl;
cout << s[0] << " " << s.back() << endl;  // un caractère (char)
cout << s.substr(0, 7) << endl;           // 7 caractères à partir de l'indice 0
cout << s.find("C++") << endl;            // position, ou string::npos si absent
if (s.find("Java") == string::npos) cout << "pas de Java" << endl;
s.replace(0, 7, "Salut");                 // remplace 7 caractères à partir de 0
cout << s << endl;
cout << (s == "Salut C++") << " " << (string("abc") < string("abd")) << endl;
```

### Convertir et parcourir

```run h=iostream,string,cctype main
int n = stoi("42") + 1;                   // string → int   (stod pour double)
string t = "Total : " + to_string(n);     // nombre → string
cout << t << endl;

string mot = "Bonjour";
for (char& c : mot) c = toupper(c);       // <cctype> : toupper, tolower, isdigit, isalpha…
cout << mot << endl;
cout << (int)'A' << " " << (char)('A' + 2) << endl;   // un char est un petit entier
```

!attention `"a" + "b"` ne compile pas | Deux textes entre guillemets sont des tableaux de caractères hérités du C, pas des `string`. Il faut qu'au moins un des deux soit un `string` : `string("a") + "b"`. De même, `"Total : " + 5` ne fait pas ce que tu crois : utilise `to_string(5)`.
