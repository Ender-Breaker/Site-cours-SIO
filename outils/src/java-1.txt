=== java-bases | Java : la classe Main, types et Scanner | f
**Java** (1995) est l'un des langages les plus utilisés au monde : applications d'entreprise, serveurs web, applications **Android**, logiciels bancaires, Minecraft. Sa devise : *écrire une fois, exécuter partout*. Il est **typé**, **orienté objet** de bout en bout, et sa syntaxe ressemble beaucoup à celle du C# que l'on rencontre aussi en BTS SIO : apprendre l'un, c'est presque connaître l'autre.

!info Comment suivre ce cours | Chaque bloc avec un bouton **Exécuter** est compilé par le vrai compilateur `javac` dans ton navigateur. Modifie le code, provoque des erreurs, lis les messages : c'est la meilleure façon d'apprendre.

## 1. Le programme minimal

```run
public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour !");
    }
}
```

| Élément | Rôle |
| `public class Main { … }` | tout le code Java vit dans une **classe** ; le fichier s'appelle `Main.java` |
| `public static void main(String[] args)` | la méthode par laquelle le programme commence |
| `System.out.println(…)` | affiche puis passe à la ligne (`print` : sans retour à la ligne) |
| `;` | termine chaque instruction |
| `{ }` | délimitent les blocs |

## 2. Compiler et exécuter : la JVM

```
javac Main.java     # compile : produit Main.class (du bytecode)
java Main           # la machine virtuelle Java (JVM) exécute le bytecode
```

Le compilateur ne produit pas un programme pour un processeur précis, mais du **bytecode** exécuté par la **JVM**. Le même fichier `.class` tourne sur Windows, Linux, macOS : il suffit d'avoir une JVM. Le **JDK** contient le compilateur et les outils ; le **JRE** seulement de quoi exécuter.

```run err main
System.out.println("Il manque quelque chose")
```

## 3. Variables et types primitifs

Chaque variable a un **type** fixé à sa déclaration.

```run main
int age = 17;                 // entier
double prix = 19.99;          // nombre à virgule
char initiale = 'L';          // UN caractère, entre apostrophes
boolean majeur = false;       // true ou false
String prenom = "Léa";        // texte, entre guillemets (String est une classe : majuscule)
long population = 8_000_000_000L;   // très grand entier (suffixe L)
System.out.println(prenom + " a " + age + " ans");     // + colle les textes
System.out.println(prix + " " + initiale + " " + majeur + " " + population);
age = age + 1;
System.out.println(age);
```

| Type | Contenu | Exemple |
| `int` | entier (environ ±2 milliards) | `42` |
| `long` | très grand entier | `9000000000L` |
| `double` | nombre à virgule | `3.14` |
| `boolean` | vrai ou faux | `true` |
| `char` | un caractère | `'A'` |
| `String` | texte (un objet, pas un type primitif) | `"Bonjour"` |

### `final` et `var`

```run main
final double TVA = 0.2;       // constante : ne peut plus être modifiée
var quantite = 3;             // var : le compilateur déduit int (Java 10+)
var total = quantite * 9.99;  // … et ici double
System.out.println(total * (1 + TVA));
```

## 4. Les opérateurs et leurs pièges

```run main
System.out.println(7 / 2);            // 3   : entier / entier = entier !
System.out.println(7 / 2.0);          // 3.5 : dès qu'un des deux est double
System.out.println(7 % 2);            // 1   : reste de la division
int a = 7, b = 2;
System.out.println((double) a / b);   // 3.5 : conversion explicite (cast)
System.out.println((int) 3.99);       // 3   : le cast vers int TRONQUE
int i = 5;
i++;            // i = i + 1
i += 10;        // i = i + 10
System.out.println(i);
System.out.println("Total : " + 2 + 3);      // Total : 23  (concaténation de gauche à droite)
System.out.println("Total : " + (2 + 3));    // Total : 5
System.out.println(Math.pow(2, 10) + " " + Math.sqrt(49) + " " + Math.round(2.5) + " " + Math.max(3, 8));
```

!attention Division entière et concaténation | `7 / 2` vaut `3`. Et dès qu'un `String` apparaît dans une addition, tout ce qui suit est **collé** comme du texte : mets les calculs entre parenthèses.

## 5. Lire au clavier : `Scanner`

```run stdin=Léa|17 imp=java.util.Scanner main
Scanner sc = new Scanner(System.in);
String prenom = sc.nextLine();        // une ligne de texte
int age = sc.nextInt();               // un entier
System.out.println("Bonjour " + prenom + ", dans 10 ans tu auras " + (age + 10) + " ans.");
```

| Méthode | Lit |
| `nextInt()` | un entier |
| `nextDouble()` | un nombre à virgule |
| `next()` | un mot (jusqu'au prochain espace) |
| `nextLine()` | toute la ligne |
| `hasNext()` | vrai s'il reste quelque chose à lire |

!attention Le piège de `nextInt` suivi de `nextLine` | `nextInt()` laisse le retour à la ligne dans le tampon : le `nextLine()` suivant renvoie alors une chaîne **vide**. Ajoute un `sc.nextLine();` « pour rien » après le `nextInt()`.

## 6. Mettre en forme : `printf` et `String.format`

```run main
double prix = 12.5;
System.out.printf("%.2f €%n", prix);                  // 12.50 €   (%n = retour à la ligne)
System.out.printf("%s a %d ans%n", "Léa", 17);        // %s texte, %d entier
System.out.printf("|%5d|%-5d|%05d|%n", 42, 42, 42);   // largeur, gauche, zéros
String texte = String.format("%.1f %%", 45.678);      // même chose, mais renvoie un String
System.out.println(texte);
```

=== java-conditions-boucles | Java : conditions et boucles | f
## 1. `if`, `else if`, `else`

```run stdin=15 imp=java.util.Scanner main
Scanner sc = new Scanner(System.in);
double note = sc.nextDouble();
if (note >= 16) {
    System.out.println("Très bien");
} else if (note >= 10) {
    System.out.println("Admis");
} else {
    System.out.println("Recalé");
}
```

La condition est entre parenthèses et doit être un **boolean** : contrairement au C ou au JavaScript, `if (x)` avec un entier ne compile pas.

## 2. Comparer et combiner

| Opérateur | Sens |
| `==` `!=` | égal, différent (pour les types primitifs) |
| `<` `<=` `>` `>=` | comparaisons |
| `&&` | et |
| `||` | ou |
| `!` | non |

```run main
int age = 17;
boolean carte = true;
System.out.println(age >= 18 && carte);     // false
System.out.println(age >= 18 || carte);     // true
System.out.println(!carte);                 // false
String a = "java", b = "ja" + String.valueOf("va");
System.out.println(a.equals(b));            // true : compare le CONTENU
```

!attention Comparer des String : `equals`, jamais `==` | `==` entre deux objets teste s'il s'agit du **même objet en mémoire**, pas s'ils ont le même contenu. Pour du texte, écris toujours `a.equals(b)`. C'est le bug numéro 1 des débutants en Java.

## 3. Le ternaire et `switch`

```run stdin=3 imp=java.util.Scanner main
Scanner sc = new Scanner(System.in);
int jour = sc.nextInt();
String type = (jour >= 6) ? "week-end" : "semaine";     // condition ? si vrai : si faux
System.out.println(type);

switch (jour) {                       // forme classique : un break par cas
    case 1: System.out.println("lundi"); break;
    case 2: System.out.println("mardi"); break;
    case 6:
    case 7: System.out.println("repos"); break;
    default: System.out.println("autre jour");
}

String nom = switch (jour) {          // forme moderne (Java 14+) : pas de break, renvoie une valeur
    case 1 -> "lundi";
    case 2 -> "mardi";
    case 3 -> "mercredi";
    case 6, 7 -> "repos";
    default -> "autre jour";
};
System.out.println(nom);
```

`switch` fonctionne avec les entiers, les `char`, les `String` et les `enum`.

## 4. `while` et `do … while`

```run main
int n = 1;

```

=== java-methodes-tableaux | Java : méthodes et tableaux | m
## 1. Écrire une méthode

En Java, une fonction s'appelle une **méthode** et appartient toujours à une classe. Pour l'instant, nos méthodes sont `static` : on les appelle directement, sans créer d'objet.

```run main
static double aire(double largeur, double hauteur) {
    return largeur * hauteur;
}

static void saluer(String nom) {            // void : ne renvoie rien
    System.out.println("Bonjour " + nom + " !");
}

static boolean estPair(int n) {
    return n % 2 == 0;
}
@@
System.out.println(aire(3, 4.5));
saluer("Léa");
System.out.println(estPair(7) + " " + estPair(8));
```

La signature annonce le **type de retour**, le nom, puis le type de chaque paramètre. L'ordre des méthodes dans la classe n'a pas d'importance.

## 2. Surcharge

Plusieurs méthodes peuvent porter le même nom si leurs **paramètres** diffèrent.

```run main
static int maxi(int a, int b) { return a > b ? a : b; }
static double maxi(double a, double b) { return a > b ? a : b; }
static int maxi(int a, int b, int c) { return maxi(maxi(a, b), c); }
@@
System.out.println(maxi(3, 8) + " " + maxi(2.5, 1.5) + " " + maxi(4, 9, 2));
```

## 3. Passage des arguments

Java passe **toujours par valeur**. Pour un type primitif, la méthode reçoit une copie du nombre. Pour un objet ou un tableau, elle reçoit une copie de la **référence** : elle peut donc modifier le contenu de l'objet, mais pas remplacer l'objet de l'appelant.

```run main
static void doubler(int n) { n = n * 2; }              // modifie une copie : sans effet
static void doublerTout(int[] t) {                     // modifie le tableau d'origine
    for (int i = 0; i < t.length; i++) t[i] *= 2;
}
@@
int x = 5;
doubler(x);
System.out.println(x);                 // 5
int[] notes = {1, 2, 3};
doublerTout(notes);
System.out.println(notes[0] + " " + notes[1] + " " + notes[2]);    // 2 4 6
```

## 4. Récursivité

```run main
static long factorielle(int n) {
    if (n <= 1) return 1;                  // cas d'arrêt
    return n * factorielle(n - 1);         // appel récursif
}
@@
System.out.println(factorielle(5) + " " + factorielle(20));
```

## 5. Les tableaux

Un tableau contient un nombre **fixe** d'éléments du même type. Les indices vont de `0` à `length - 1`.

```run imp=java.util.Arrays main
int[] notes = {12, 15, 9};              // tableau initialisé
double[] prix = new double[4];          // 4 cases, toutes à 0.0
String[] noms = new String[2];          // 2 cases, toutes à null
notes[1] = 16;
prix[0] = 9.99;
System.out.println(notes[0] + " " + notes.length);     // length SANS parenthèses
System.out.println(Arrays.toString(notes));            // affichage lisible
System.out.println(Arrays.toString(prix) + " " + noms[0]);

int somme = 0;
for (int n : notes) somme += n;                        // parcours for-each
System.out.println("Moyenne : " + (double) somme / notes.length);
for (int i = notes.length - 1; i >= 0; i--) System.out.print(notes[i] + " ");   // à l'envers
System.out.println();
```

!attention Sortir des bornes | `notes[3]` sur un tableau de 3 éléments lève l'exception `ArrayIndexOutOfBoundsException` et arrête le programme. Le dernier indice valide est toujours `length - 1`.

### La boîte à outils `Arrays`

```run imp=java.util.Arrays main
int[] t = {5, 2, 8, 1};
Arrays.sort(t);                                      // trie sur place
System.out.println(Arrays.toString(t));
int[] copie = Arrays.copyOf(t, t.length);            // vraie copie
copie[0] = 99;
System.out.println(t[0] + " " + copie[0]);
int[] meme = t;                                      // PAS une copie : même tableau
meme[0] = -1;
System.out.println(t[0]);
System.out.println(Arrays.equals(t, copie));
Arrays.fill(copie, 7);
System.out.println(Arrays.toString(copie));
```

## 6. Tableaux à deux dimensions

```run imp=java.util.Arrays main
int[][] grille = new int[3][4];            // 3 lignes, 4 colonnes, remplies de 0
grille[1][2] = 7;
for (int[] ligne : grille) {
    System.out.println(Arrays.toString(ligne));
}
int[][] triangle = {{1}, {1, 1}, {1, 2, 1}};       // lignes de longueurs différentes
System.out.println(triangle[2][1] + " " + triangle.length + " " + triangle[2].length);
```

!info Et quand la taille n'est pas connue ? | Un tableau ne peut pas grandir. Pour une liste dont la taille change, on utilise `ArrayList` : voir le chapitre sur les collections.

# Renvoyer deux résultats dans un tableau
Une méthode ne renvoie qu'une valeur ; cette valeur peut être un tableau.
```run imp=java.util.Arrays main
static double[] minMax(double[] t) {
    double mini = t[0], maxi = t[0];
    for (double v : t) {
        if (v < mini) mini = v;
        if (v > maxi) maxi = v;
    }
    return new double[]{mini, maxi};
}
@@
double[] r = minMax(new double[]{12, 5, 19, 8});
System.out.println(r[0] + " " + r[1]);
```

```run main
static double moyenne(double[] t) {
    double s = 0;
    for (double v : t) s += v;
    return s / t.length;
}
static int auDessus(double[] t, double seuil) {
    int n = 0;
    for (double v : t) if (v > seuil) n++;
    return n;
}
@@
double[] notes = {12, 5, 19, 8, 10};
System.out.println(auDessus(notes, moyenne(notes)) + " notes au-dessus de la moyenne");
```

=== java-chaines | Java : les chaînes de caractères | m
## 1. `String` : un objet non modifiable

Un `String` est **immuable** : aucune méthode ne le modifie, toutes renvoient un **nouveau** `String`.

```run main
String s = "Bonjour Java";
System.out.println(s.length());                 // 12 (avec des parenthèses, contrairement aux tableaux)
System.out.println(s.charAt(0) + " " + s.charAt(s.length() - 1));
System.out.println(s.toUpperCase() + " " + s.toLowerCase());
System.out.println(s.substring(0, 7));          // de l'indice 0 inclus à 7 exclu : Bonjour
System.out.println(s.substring(8));             // de 8 à la fin : Java
System.out.println(s.indexOf("Java") + " " + s.indexOf("Python"));   // 8  -1
System.out.println(s.contains("jour") + " " + s.startsWith("Bon") + " " + s.endsWith("va"));
System.out.println(s.replace("Java", "le monde"));
System.out.println(s);                          // inchangé !
s = s.toUpperCase();                            // il faut réaffecter
System.out.println(s);
```

## 2. Comparer

```run main
String a = "java";
String b = new String("java");
System.out.println(a == b);                     // false : deux objets différents
System.out.println(a.equals(b));                // true  : même contenu
System.out.println("Java".equalsIgnoreCase("JAVA"));
System.out.println("abc".compareTo("abd"));     // négatif : "abc" est avant "abd"
System.out.println("".isEmpty() + " " + "   ".isBlank());
```

!attention `equals`, toujours | `==` compare les références. Il « marche » parfois par hasard (Java réutilise certains littéraux), ce qui rend le bug sournois. Pour éviter une erreur quand la variable peut être `null`, place la constante à gauche : `"oui".equals(reponse)`.

## 4. Convertir

```run main
int n = Integer.parseInt("42") + 1;             // String → int
double d = Double.parseDouble("3.5") * 2;       // String → double
String s = String.valueOf(n);                   // nombre → String

System.out.println(Integer.toBinaryString(10) + " " + Integer.toHexString(255) + " " + Integer.parseInt("1010", 2));
```

`Integer.parseInt("abc")` lève une `NumberFormatException` : on apprendra à l'attraper dans le chapitre sur les exceptions.

## 5. Les caractères

Un `char` est un petit entier : le code du caractère. On peut calculer avec.

```run main
char c = 'a';
System.out.println((int) c + " " + (char) (c + 1) + " " + (char) 65);
System.out.println(Character.isDigit('7') + " " + Character.isLetter('7') + " " + Character.toUpperCase('b'));
String mot = "Bonjour";
int voyelles = 0;
for (char x : mot.toCharArray()) {
    if ("aeiouy".indexOf(x) >= 0) voyelles++;
}
System.out.println(voyelles);
```

## 6. `StringBuilder` : construire un texte efficacement

Comme un `String` n'est pas modifiable, `s = s + morceau` dans une boucle recrée tout le texte à chaque tour. `StringBuilder` est une chaîne **modifiable**, faite pour cela.

```run main
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 5; i++) {
    sb.append(i).append(" ");           // append renvoie le StringBuilder : on enchaîne
}
System.out.println(sb.toString().trim());
sb.insert(0, "Nombres : ");
sb.setLength(sb.length() - 1);          // retire le dernier caractère
System.out.println(sb);
System.out.println(new StringBuilder("Java").reverse());
```

# Masquer une information sensible
`replaceAll` accepte une **expression régulière** : ici, quatre groupes de chiffres séparés par des points.
```run main
String ligne = "connexion refusée depuis 192.168.1.42 puis 10.0.0.7";

System.out.println("192.168.1.42".matches("\\d+\\.\\d+\\.\\d+\\.\\d+"));
```
