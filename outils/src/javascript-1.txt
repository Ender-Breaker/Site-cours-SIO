**JavaScript** est le langage du web : c'est le seul que tous les navigateurs exécutent. Il anime les pages (menus, formulaires, jeux), et avec Node.js il tourne aussi côté serveur. Pour l'option SLAM, c'est un passage obligé.

## 1. Afficher et commenter

```run
console.log("Bonjour !");
console.log("Total :", 42, true);      // plusieurs valeurs, séparées par un espace
// un commentaire sur une ligne
/* un commentaire
   sur plusieurs lignes */
```

## 2. Variables : `const` et `let`

```run
const prenom = "Léa";      // const : ne sera jamais réaffectée
let score = 0;             // let : peut changer
score = score + 10;
score += 5;                // raccourci
score++;                   // + 1
console.log(prenom, score);
let inconnue;              // déclarée sans valeur
console.log(inconnue);     // undefined
```

!attention Jamais `var` | `var` est l'ancienne façon de déclarer : sa portée est la fonction entière et non le bloc, ce qui cause des bugs. Écris `const` par défaut, `let` quand la valeur doit changer.

## 3. Les types

| Type | Exemples |
| `number` | `42`, `3.14` (un seul type pour entiers et décimaux) |
| `string` | `"texte"`, `'texte'`, `` `texte ${variable}` `` |
| `boolean` | `true`, `false` |
| `undefined` | variable sans valeur |
| `null` | « rien », mis volontairement |
| `object` | objets `{…}`, tableaux `[…]` |
| `function` | les fonctions sont des valeurs |

```run
console.log(typeof 42, typeof "42", typeof true, typeof undefined, typeof {}, typeof [], typeof console.log);
console.log(7 / 2, Math.floor(7 / 2), 7 % 2, 2 ** 10);    // 3.5  3  1  1024
console.log(0.1 + 0.2);                                    // 0.30000000000000004 : les décimaux sont approchés
console.log((0.1 + 0.2).toFixed(2), Math.round(2.5), Math.max(3, 8));
```

## 4. Les chaînes et les gabarits

```run
const nom = "Léa", age = 17;
console.log("Bonjour " + nom + ", tu as " + age + " ans");      // concaténation
console.log(`Bonjour ${nom}, dans 10 ans tu auras ${age + 10} ans`);   // gabarit : accents graves
console.log(nom.length, nom.toUpperCase(), nom[0], nom.includes("é"));
```

## 5. Convertir, et les pièges de `+`

```run
console.log("5" + 3);            // "53" : + avec une chaîne = concaténation
console.log("5" - 3);            // 2    : - convertit en nombre
console.log(Number("42") + 1, parseInt("42px"), Number("abc"));   // 43  42  NaN
console.log(String(42).length, (42).toString(2));
console.log(5 == "5", 5 === "5");    // true  false
```

!attention Toujours `===` | `==` convertit les types avant de comparer (`0 == ""` est vrai !). `===` compare la valeur **et** le type : utilise toujours `===` et `!==`.

## 6. Lire une entrée

Dans le labo, `lire()` renvoie la ligne suivante des entrées, sous forme de **texte**. Dans une page web, on lit plutôt la valeur d'un champ de formulaire (chapitre DOM).

=== js-conditions-boucles | JavaScript : conditions et boucles | f
## 1. `if`, `else if`, `else`

```run stdin=15
const note = Number(lire());
if (note >= 16) {
  console.log("Très bien");
} else if (note >= 10) {
  console.log("Admis");
} else {
  console.log("Recalé");
}
```

## 2. Comparer et combiner

| Opérateur | Sens |
| `===` `!==` | égal, différent (strict) |
| `<` `<=` `>` `>=` | comparaisons |
| `&&` | et |
| `||` | ou |
| `!` | non |

```run
const age = 17, carte = true;
console.log(age >= 18 && carte, age >= 18 || carte, !carte);
const pseudo = "";
console.log(pseudo || "Invité");          // || renvoie la première valeur « vraie »
console.log(null ?? "défaut", 0 ?? 5);    // ?? : seulement si null ou undefined
console.log(age >= 18 ? "majeur" : "mineur");   // ternaire
```

!attention Les valeurs « fausses » | Dans une condition, `false`, `0`, `""`, `null`, `undefined` et `NaN` sont considérés comme faux. Tout le reste est vrai, y compris `"0"`, `[]` et `{}`.

## 3. `switch`

```run stdin=3

switch (jour) {
  case 1: console.log("lundi"); break;
  case 2: console.log("mardi"); break;
  case 6:
  case 7: console.log("repos"); break;
```

## 4. Les boucles

```run
let n = 1;
while (n < 100) n *= 2;                  // tant que
console.log(n);

for (let i = 1; i <= 5; i++) console.log("tour", i);     // nombre de tours connu

const fruits = ["pomme", "kiwi", "poire"];
for (const f of fruits) console.log(f);                  // for…of : chaque VALEUR
for (const c of "abc") console.log(c);                   // marche aussi sur une chaîne

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;             // tour suivant
  if (i > 7) break;                      // sortie
  console.log(i);
}
```

!attention `for…of`, pas `for…in` | `for…in` parcourt les **clés** (les indices, sous forme de texte) et réserve des surprises sur les tableaux. Pour un tableau, c'est toujours `for…of`.

=== js-fonctions | JavaScript : les fonctions | m
## 1. Déclarer et appeler

```run
function aire(largeur, hauteur) {
  return largeur * hauteur;
}
function saluer(nom = "inconnu") {       // valeur par défaut
  console.log(`Salut ${nom}`);
}
console.log(aire(3, 4));
saluer("Léa");
saluer();
console.log(aire(3));                    // NaN : hauteur vaut undefined
```

Une fonction sans `return` renvoie `undefined`. Un argument manquant vaut `undefined`, un argument en trop est ignoré.

## 2. Les fonctions fléchées

```run
const carre = (x) => x * x;              // return implicite
const somme = (a, b) => {
  const s = a + b;
  return s;                              // avec des accolades, return explicite
};
const direBonjour = () => console.log("Bonjour");
console.log(carre(7), somme(3, 4));
direBonjour();
```

## 3. Les fonctions sont des valeurs

On peut passer une fonction en argument : c'est un **callback**. Tout JavaScript repose là-dessus (événements, tableaux, requêtes réseau).

```run
function appliquer(f, valeur) {
  return f(valeur);
}
console.log(appliquer(x => x * 2, 21));
console.log(appliquer(Math.sqrt, 49));

function repeter(n, action) {
  for (let i = 1; i <= n; i++) action(i);
}
repeter(3, i => console.log(`tour ${i}`));
```

## 4. Portée et closures

Une variable `let` ou `const` n'existe que dans son bloc `{ }`. Une fonction garde l'accès aux variables de l'endroit où elle a été créée : c'est une **closure**.

```run
function creerCompteur() {
  let n = 0;                       // privée : inaccessible de l'extérieur
  return () => {
    n++;
    return n;
  };
}
const a = creerCompteur(), b = creerCompteur();
console.log(a(), a(), a(), b());   // 1 2 3 1 : chaque compteur a son propre n
```

## 5. Paramètres du reste et décomposition

```run
function total(...nombres) {             // ...nombres : tous les arguments dans un tableau
  let s = 0;
  for (const n of nombres) s += n;
  return s;
}
console.log(total(1, 2, 3), total());

function minmax(t) { return [Math.min(...t), Math.max(...t)]; }   // ...t : étale le tableau
const [mini, maxi] = minmax([12, 5, 19]);                         // décomposition
console.log(mini, maxi);
```

## 6. Récursivité

```run
function factorielle(n) {
  if (n <= 1) return 1;                  // cas d'arrêt
  return n * factorielle(n - 1);
}
console.log(factorielle(5), factorielle(10));
```

=== js-tableaux-objets | JavaScript : tableaux et objets | m
## 1. Les tableaux

```run
const fruits = ["pomme", "kiwi"];
fruits.push("poire");                   // ajoute à la fin
fruits.unshift("ananas");               // ajoute au début
console.log(fruits, fruits.length, fruits[0]);
console.log(fruits.pop(), fruits.shift());      // retire le dernier, le premier
console.log(fruits.includes("kiwi"), fruits.indexOf("kiwi"), fruits.join(" | "));
console.log(fruits.slice(0, 1));        // copie d'une portion
console.log([3, 1, 2].reverse(), [5, 10, 9].sort((a, b) => a - b));
console.log(fruits[99]);                // undefined : pas d'erreur
```

!attention Trier des nombres | Sans argument, `sort()` trie comme du **texte** : `[10, 9, 100].sort()` donne `[10, 100, 9]`. Pour des nombres : `sort((a, b) => a - b)`.

## 2. `map`, `filter`, `reduce` et compagnie

Ces méthodes reçoivent une fonction et renvoient un **nouveau** résultat, sans modifier le tableau.

```run
const prix = [12, 5, 30, 8];
console.log(prix.map(p => p * 2));                    // transforme chaque élément
console.log(prix.filter(p => p >= 10));               // garde selon un test
console.log(prix.reduce((total, p) => total + p, 0)); // combine en une valeur
console.log(prix.find(p => p > 10), prix.findIndex(p => p > 10));
console.log(prix.some(p => p > 20), prix.every(p => p > 0));
prix.forEach((p, i) => console.log(i, p));            // simple parcours
console.log(prix.filter(p => p >= 10).map(p => p * 1.2).reduce((s, p) => s + p, 0));   // enchaînement
```

## 3. Les objets

```run
const joueur = { nom: "Léa", pv: 10, inventaire: ["épée"] };

delete joueur.pv;                                // supprime

for (const [cle, valeur] of Object.entries(joueur)) console.log(cle, "→", valeur);

```

## 4. Décomposition et copie

```run
const eleve = { nom: "Sam", note: 15, option: "SLAM" };
```

## 5. Tableaux d'objets : le cas le plus courant

## 6. JSON

**JSON** est le format texte d'échange de données du web. Il ressemble à un objet JavaScript, avec des guillemets doubles obligatoires.

```run
const texte = '{"nom":"Léa","notes":[12,15],"majeur":false}';
const obj = JSON.parse(texte);                   // texte → objet
console.log(obj.nom, obj.notes[1]);
obj.notes.push(18);
console.log(JSON.stringify(obj));                // objet → texte
console.log(JSON.stringify(obj, null, 2));       // mis en forme
```

=== js-classes-modules | JavaScript : classes, modules et gestion des erreurs | m
## 1. Les classes

```run
class Compte {
  #solde = 0;                            // # : attribut privé
  constructor(titulaire, solde = 0) {
    this.titulaire = titulaire;
    this.#solde = solde;
  }
  deposer(montant) {
    if (montant > 0) this.#solde += montant;
    return this;                         // permet d'enchaîner
  }
  retirer(montant) {
    if (montant > this.#solde) return false;
    this.#solde -= montant;
    return true;
  }
  get solde() { return this.#solde; }    // accesseur : s'utilise comme une propriété
  static creerVide(nom) { return new Compte(nom); }     // méthode de classe
}
const c = new Compte("Léa", 100);
c.deposer(50).deposer(10);
console.log(c.retirer(500), c.retirer(30), c.solde);
console.log(Compte.creerVide("Sam").solde);
```

## 3. Le piège de `this`

```run

}
```

=== js-async-api | JavaScript : asynchrone, fetch et API REST | d
Charger des données depuis un serveur prend du temps. JavaScript ne **bloque** pas la page en attendant : il lance l'opération, continue, et reprend quand la réponse arrive. C'est la programmation **asynchrone**.

!info Où tester ? | Ces exemples font des requêtes réseau : essaie-les dans la console de ton navigateur (F12), sur n'importe quelle page.

## 1. Le principe

```
console.log("1 : avant");
setTimeout(() => console.log("3 : une seconde plus tard"), 1000);   // n'attend pas
console.log("2 : après");
```

L'ordre d'affichage est 1, 2, 3 : `setTimeout` programme la fonction et rend la main tout de suite.

## 2. Les promesses

Une **promesse** (`Promise`) représente un résultat qui arrivera plus tard. Elle est *en attente*, puis *tenue* (avec une valeur) ou *rompue* (avec une erreur).

```
fetch("https://api.exemple.fr/produits")           // renvoie une promesse
  .then(reponse => reponse.json())                  // quand la réponse arrive
  .then(produits => console.log(produits.length))   // quand le JSON est lu
  .catch(erreur => console.log("Échec :", erreur.message));
```

## 3. `async` / `await` : la forme à utiliser

`await` met la fonction en pause jusqu'à ce que la promesse soit tenue, **sans bloquer la page**. Le code se lit de haut en bas, comme du code ordinaire.

```
async function chargerProduits() {
  try {
    const reponse = await fetch("https://api.exemple.fr/produits");
    if (!reponse.ok) throw new Error("HTTP " + reponse.status);   // 404, 500…
    const produits = await reponse.json();
    return produits;
  } catch (e) {
    console.log("Impossible de charger :", e.message);
    return [];
  }
}

const produits = await chargerProduits();     // await : seulement dans une fonction async ou un module
```

!attention `fetch` ne rejette pas sur une erreur 404 | `fetch` n'échoue que si le réseau est coupé. Une réponse 404 ou 500 est une réponse « réussie » : il faut tester `reponse.ok` (ou `reponse.status`) soi-même.

## 4. Les API REST

Une **API REST** expose des données par des URL, manipulées avec les **méthodes HTTP**. Les échanges se font en JSON.

| Méthode | Action | Exemple |
| `GET` | lire | `GET /produits`, `GET /produits/12` |
| `POST` | créer | `POST /produits` |
| `PUT` / `PATCH` | modifier | `PUT /produits/12` |
| `DELETE` | supprimer | `DELETE /produits/12` |

| Code | Signification |
| `200` `201` `204` | succès, créé, succès sans contenu |
| `400` | requête incorrecte |
| `401` `403` | non authentifié, interdit |
| `404` | introuvable |
| `500` | erreur du serveur |

```
const reponse = await fetch("https://api.exemple.fr/produits", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer " + jeton },
  body: JSON.stringify({ nom: "Souris", prix: 19.9 }),
});
const cree = await reponse.json();
console.log(reponse.status, cree.id);
```

## 5. Plusieurs requêtes en parallèle

```
const [clients, produits] = await Promise.all([
  fetch("/api/clients").then(r => r.json()),
  fetch("/api/produits").then(r => r.json()),
]);
```

`Promise.all` lance tout en même temps et attend que **toutes** les promesses soient tenues.

=== js-jeu-canvas | JavaScript : créer un jeu dans le navigateur | d
Un jeu, c'est une boucle : **lire les entrées, mettre à jour, dessiner**, soixante fois par seconde.

!info Où tester ? | Les jeux se lancent dans le [bac à sable du labo](labo-js.html#libre). Copie les exemples et modifie-les.

## 1. La boucle de jeu du labo

```
let x = 50;

function setup() { x = 50; }             // une fois au démarrage (facultatif)

function update(dt) {                    // la logique, 60 fois par seconde
  if (touche("droite")) x += 200 * dt;   // 200 pixels par seconde
}

function draw() {                        // l'affichage
  effacer("black");
  rect(x, 140, 40, 40, "gold");
}
```

| Fonction | Rôle |
| `effacer(c)` | remplit l'écran (480 × 320) |
| `rect(x, y, l, h, c)`, `cercle(x, y, r, c)`, `ligne(x1, y1, x2, y2, c)` | formes |
| `texte(t, x, y, taille, c)` | texte |
| `touche("gauche")` / `toucheAppuyee("espace")` | touche maintenue / appuyée à cette image |
| `sourisX()`, `sourisY()`, `clic()` | souris |
| `hasard(a, b)`, `LARGEUR`, `HAUTEUR` | entier au hasard, 480, 320 |

L'origine est en haut à gauche ; `y` augmente vers le bas.

## 2. Le vrai canvas du navigateur

Dans une page web, on dessine dans une balise `<canvas>` et on demande au navigateur de rappeler la fonction à chaque image :

```
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");
const touches = {};
addEventListener("keydown", e => touches[e.key] = true);
addEventListener("keyup", e => touches[e.key] = false);

let x = 50, avant = performance.now();
function boucle(maintenant) {
  const dt = (maintenant - avant) / 1000;          // secondes écoulées
  avant = maintenant;
  if (touches["ArrowRight"]) x += 200 * dt;         // update
  ctx.fillStyle = "black";                          // draw
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "gold";
  ctx.fillRect(x, 140, 40, 40);
  requestAnimationFrame(boucle);                    // image suivante
}
requestAnimationFrame(boucle);
```

## 3. Gravité, collisions, listes d'objets
