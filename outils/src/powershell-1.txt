=== ps-bases | PowerShell : cmdlets, objets et pipeline | f
**PowerShell** est le shell et le langage de script de Windows (il existe aussi pour Linux et macOS). Il sert à administrer les postes, Windows Server, Active Directory, Microsoft 365. Sa grande différence avec Bash : les commandes n'échangent pas du **texte**, mais des **objets**.

## 1. Les cmdlets : Verbe-Nom

Toutes les commandes suivent la même forme, ce qui les rend devinables.

```
Get-Process                      # liste les processus
Get-Service                      # liste les services
Get-ChildItem C:\Users           # contenu d'un dossier (alias : dir, ls, gci)
Get-Content notes.txt            # contenu d'un fichier (alias : cat, type)
Set-Location C:\Scripts          # change de dossier (alias : cd)
New-Item -ItemType Directory -Name Projet
Remove-Item ancien.txt
Copy-Item a.txt b.txt
```

| Verbe | Rôle |
| `Get` | lire |
| `Set` | modifier |
| `New` | créer |
| `Remove` | supprimer |
| `Start` / `Stop` / `Restart` | démarrer / arrêter / redémarrer |

## 2. Trouver de l'aide

```
Get-Command *service*            # quelles commandes parlent de services ?
Get-Help Get-Service -Examples   # des exemples d'utilisation
Get-Service | Get-Member         # quelles propriétés et méthodes ont ces objets ?
```

Ces trois commandes suffisent à tout découvrir sans quitter le terminal.

## 3. Le pipeline d'objets

Le tube `|` transmet des **objets** complets, avec leurs propriétés. Pas besoin de découper du texte avec `cut` ou `awk`.

```
Get-Service | Where-Object Status -eq "Running"                  # filtre
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, CPU
Get-ChildItem C:\Logs -Filter *.log | Measure-Object Length -Sum
Get-Process | Where-Object { $_.WorkingSet -gt 200MB } | Select-Object Name, Id
Get-Service | Group-Object Status
```

| Cmdlet | Rôle | Équivalent Linux |
| `Where-Object` | filtrer | `grep` |
| `Select-Object` | choisir des propriétés ou les N premiers | `cut`, `head` |
| `Sort-Object` | trier | `sort` |
| `Measure-Object` | compter, additionner | `wc` |
| `Group-Object` | regrouper | `uniq -c` |
| `ForEach-Object` | agir sur chaque objet | une boucle |

Dans un bloc `{ }`, `$_` désigne **l'objet en cours**.

## 4. Les opérateurs de comparaison

| Opérateur | Sens |
| `-eq` `-ne` | égal, différent |
| `-gt` `-ge` `-lt` `-le` | supérieur, supérieur ou égal, inférieur, inférieur ou égal |
| `-like` | correspond à un motif avec `*` : `-like "*.log"` |
| `-match` | correspond à une expression régulière |
| `-and` `-or` `-not` | et, ou, non |

PowerShell ne tient pas compte de la casse par défaut : `"ABC" -eq "abc"` est vrai.

## 5. Exporter et mettre en forme

```
Get-Service | Export-Csv services.csv -NoTypeInformation -Encoding UTF8
Import-Csv utilisateurs.csv                      # chaque ligne devient un objet
Get-Process | ConvertTo-Json
Get-Service | Out-File services.txt
Get-Process | Format-Table Name, Id, CPU -AutoSize
Get-Process | Out-GridView                       # une fenêtre triable et filtrable
```

## 6. Variables et types

```
$nom = "Léa"                     # toutes les variables commencent par $
$age = 17
$liste = @("pc01", "pc02", "pc03")               # tableau
$compte = @{ Nom = "Léa"; Service = "SIO" }      # table de hachage (dictionnaire)
"Bonjour $nom, tu as $age ans"                   # guillemets doubles : variables remplacées
'Bonjour $nom'                                   # guillemets simples : texte littéral
"Il y a $($liste.Count) postes"                  # $( ) pour une expression
$liste[0]; $compte.Nom; $compte["Service"]
```

=== ps-administration | PowerShell : scripts et administration | m
## 1. Écrire un script

Un script est un fichier `.ps1`. Par sécurité, Windows bloque leur exécution par défaut.

```
Get-ExecutionPolicy                              # Restricted sur un poste neuf
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser   # autorise tes scripts locaux
.\rapport.ps1                                    # lance le script (le .\ est obligatoire)
```

```
# rapport.ps1
param(
    [string]$Dossier = "C:\Logs",                # paramètre avec valeur par défaut
    [int]$Jours = 7
)
Write-Host "Analyse de $Dossier sur $Jours jours"
```

```
.\rapport.ps1 -Dossier D:\Journaux -Jours 30
```

## 2. Conditions et boucles

```
if (Test-Path "C:\Sauvegardes") {
    Write-Host "Le dossier existe"
} elseif ($Jours -gt 30) {
    Write-Host "Période longue"
} else {
    New-Item -ItemType Directory -Path "C:\Sauvegardes" | Out-Null
}

foreach ($poste in @("pc01", "pc02", "pc03")) {
    if (Test-Connection $poste -Count 1 -Quiet) { "$poste répond" } else { "$poste ne répond PAS" }
}

for ($i = 1; $i -le 3; $i++) { "Tour $i" }
$n = 0
while ($n -lt 3) { $n++ }

Get-ChildItem *.log | ForEach-Object { "$($_.Name) : $($_.Length) octets" }
```

## 3. Fonctions et gestion des erreurs

```
function Get-EspaceLibre {
    param([string]$Lettre = "C")
    $disque = Get-PSDrive $Lettre
    return [math]::Round($disque.Free / 1GB, 1)
}
"Libre sur C : $(Get-EspaceLibre) Go"

try {
    Get-Content "C:\absent.txt" -ErrorAction Stop     # Stop : transforme l'erreur en exception
} catch {
    Write-Warning "Lecture impossible : $($_.Exception.Message)"
} finally {
    "Fin du traitement"
}
```

## 4. Services, processus, journaux

```
Get-Service Spooler
Restart-Service Spooler                          # relance le service d'impression

Get-EventLog -LogName System -EntryType Error -Newest 10

```

## 5. Active Directory

Sur un contrôleur de domaine (module `ActiveDirectory`) :

```
Get-ADUser -Filter * -SearchBase "OU=SIO,DC=lycee,DC=local" | Select-Object Name, SamAccountName
Get-ADUser lea.martin -Properties LastLogonDate, MemberOf

New-ADUser -Name "Léa Martin" -SamAccountName "lea.martin" `
    -UserPrincipalName "lea.martin@lycee.local" -Path "OU=SIO,DC=lycee,DC=local" `
    -AccountPassword (Read-Host "Mot de passe" -AsSecureString) `
    -ChangePasswordAtLogon $true -Enabled $true

Add-ADGroupMember -Identity "G_SIO1" -Members "lea.martin"
Disable-ADAccount lea.martin
Unlock-ADAccount lea.martin
Search-ADAccount -AccountInactive -TimeSpan 90.00:00:00 -UsersOnly     # comptes inactifs depuis 90 jours
```

L'accent grave `` ` `` en fin de ligne poursuit la commande sur la ligne suivante.

## 6. Administrer à distance

```
Enter-PSSession -ComputerName srv-fichiers       # un terminal sur la machine distante
Invoke-Command -ComputerName pc01, pc02, pc03 -ScriptBlock { Get-Service Spooler }
```

`Invoke-Command` exécute le même bloc sur plusieurs machines **en parallèle** et rassemble les résultats.

## 7. Bonnes pratiques

- Tester d'abord avec `-WhatIf` : la commande **affiche** ce qu'elle ferait, sans rien modifier (`Remove-Item *.tmp -WhatIf`).
- Jamais de mot de passe en clair dans un script : `Read-Host -AsSecureString` ou `Get-Credential`.
- Des paramètres plutôt que des valeurs écrites en dur.
- Journaliser ce que fait le script (`Start-Transcript`, ou `Add-Content` dans un fichier).
- Versionner les scripts avec Git.

!tuto Créer des comptes à partir d'un fichier CSV
# Le fichier
```
Prenom;Nom;Classe
Léa;Martin;SIO1
Sam;Durand;SIO1
```
# Le lire et construire l'identifiant
```
$eleves = Import-Csv eleves.csv -Delimiter ";"
foreach ($e in $eleves) {
    $login = ("{0}.{1}" -f $e.Prenom, $e.Nom).ToLower()
    "$login (classe $($e.Classe))"
}
```
# Créer les comptes, sans doublon, avec un journal
Lance d'abord le script avec `-WhatIf` ajouté à `New-ADUser` pour vérifier.
```
$mdp = Read-Host "Mot de passe initial" -AsSecureString     # jamais écrit dans le script
foreach ($e in $eleves) {
    $login = ("{0}.{1}" -f $e.Prenom, $e.Nom).ToLower()
    if (Get-ADUser -Filter "SamAccountName -eq '$login'") {
        Add-Content journal.txt "$login existe déjà"
        continue
    }
    New-ADUser -Name "$($e.Prenom) $($e.Nom)" -SamAccountName $login `
        -Path "OU=$($e.Classe),DC=lycee,DC=local" `
        -AccountPassword $mdp `
        -ChangePasswordAtLogon $true -Enabled $true
    Add-Content journal.txt "$login créé"
}
```
