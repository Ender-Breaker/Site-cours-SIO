=== java-lambdas-streams | Java : lambdas et streams | d
Depuis Java 8, on peut passer du **comportement** en argument (une lambda) et traiter les collections de façon **déclarative** (les streams) : on décrit *quoi* obtenir plutôt que *comment* boucler.

## 1. Une lambda : une fonction écrite sur place

```run imp=java.util.function.* main
Function<Integer, Integer> carre = x -> x * x;               // un paramètre, un résultat
BiFunction<Integer, Integer, Integer> somme = (a, b) -> a + b;
Predicate<String> estVide = s -> s.isEmpty();                // renvoie un boolean
Supplier<String> salut = () -> "Bonjour";                    // aucun paramètre
Consumer<String> afficher = s -> System.out.println("> " + s);    // ne renvoie rien

System.out.println(carre.apply(7) + " " + somme.apply(3, 4) + " " + estVide.test("") + " " + salut.get());
afficher.accept("une lambda est un objet");

Function<Integer, Integer> plusLong = x -> {                 // corps sur plusieurs lignes
    int double_ = x * 2;
    return double_ + 1;
};
System.out.println(plusLong.apply(5));
```

| Interface fonctionnelle | Forme | Méthode |
| `Function<T, R>` | T → R | `apply` |
| `Predicate<T>` | T → boolean | `test` |
| `Consumer<T>` | T → rien | `accept` |
| `Supplier<T>` | rien → T | `get` |
| `Comparator<T>` | (T, T) → int | `compare` |
| `Runnable` | rien → rien | `run` |

Une lambda est une façon courte d'écrire un objet qui implémente une **interface à une seule méthode abstraite**.

## 2. Les références de méthodes

Quand la lambda ne fait qu'appeler une méthode existante, on peut la nommer directement avec `::`.

```run imp=java.util.*,java.util.function.* main
Function<String, Integer> longueur = String::length;         // s -> s.length()
Function<String, String> maj = String::toUpperCase;          // s -> s.toUpperCase()
Function<String, Integer> convertir = Integer::parseInt;     // s -> Integer.parseInt(s)
System.out.println(longueur.apply("Java") + " " + maj.apply("java") + " " + (convertir.apply("41") + 1));
List<String> mots = new ArrayList<>(List.of("poire", "kiwi", "banane"));
mots.forEach(System.out::println);                           // x -> System.out.println(x)
```

## 3. Les streams : une chaîne de traitements

Un **stream** est un flux d'éléments qui traverse une suite d'opérations. On part d'une collection (`.stream()`), on enchaîne des opérations **intermédiaires**, et on termine par une opération **terminale** qui produit le résultat.

```run imp=java.util.*,java.util.stream.* main
List<Integer> notes = List.of(12, 5, 19, 8, 10, 15);

List<Integer> admis = notes.stream()
    .filter(n -> n >= 10)                // garde ceux qui passent le test
    .sorted()                            // trie
    .collect(Collectors.toList());       // rassemble dans une liste
System.out.println(admis);

List<String> textes = notes.stream()
    .map(n -> n + "/20")                 // transforme chaque élément
    .collect(Collectors.toList());
System.out.println(textes);

System.out.println(notes.stream().filter(n -> n >= 10).count());            // combien
System.out.println(notes.stream().mapToInt(Integer::intValue).sum());       // somme
System.out.println(notes.stream().mapToInt(Integer::intValue).average().getAsDouble());
System.out.println(notes.stream().mapToInt(Integer::intValue).max().getAsInt());
System.out.println(notes.stream().anyMatch(n -> n < 6) + " " + notes.stream().allMatch(n -> n > 0));
```

| Intermédiaires (renvoient un stream) | Terminales (produisent un résultat) |
| `filter(test)` | `collect(Collectors.toList())`, `toList()` |
| `map(fonction)` | `count()`, `sum()`, `average()`, `max()`, `min()` |
| `sorted()`, `sorted(comparateur)` | `forEach(action)` |
| `distinct()`, `limit(n)`, `skip(n)` | `anyMatch`, `allMatch`, `noneMatch` |
| `mapToInt(…)` | `reduce(départ, opération)`, `findFirst()` |

Le stream **ne modifie pas** la collection d'origine, et rien n'est calculé tant qu'il n'y a pas d'opération terminale.

## 4. Des streams sur des objets

```run imp=java.util.*,java.util.stream.* cls main
class Eleve {
    final String nom, option;
    final double note;
    Eleve(String nom, String option, double note) { this.nom = nom; this.option = option; this.note = note; }
    String getNom() { return nom; }
    String getOption() { return option; }
    double getNote() { return note; }
}
@@
List<Eleve> classe = List.of(new Eleve("Léa", "SLAM", 15), new Eleve("Sam", "SISR", 9),
                             new Eleve("Zoé", "SLAM", 18), new Eleve("Tom", "SISR", 12));

String admisSlam = classe.stream()
    .filter(e -> e.getOption().equals("SLAM"))
    .filter(e -> e.getNote() >= 10)
    .sorted(Comparator.comparing(Eleve::getNote).reversed())
    .map(Eleve::getNom)
    .collect(Collectors.joining(", "));
System.out.println(admisSlam);

System.out.println(classe.stream().mapToDouble(Eleve::getNote).average().orElse(0));
Map<String, Long> parOption = classe.stream()
    .collect(Collectors.groupingBy(Eleve::getOption, TreeMap::new, Collectors.counting()));
System.out.println(parOption);
```

Compare avec la version « boucles » : trois `if`, un tri, une concaténation. Le stream se lit comme une phrase.

## 5. `reduce` et `IntStream`

```run imp=java.util.*,java.util.stream.* main
List<Integer> v = List.of(1, 2, 3, 4);
System.out.println(v.stream().reduce(0, Integer::sum));           // 10 : combine tous les éléments
System.out.println(v.stream().reduce(1, (a, b) -> a * b));        // 24
System.out.println(IntStream.rangeClosed(1, 5).sum());            // 1 + 2 + 3 + 4 + 5
IntStream.range(0, 3).forEach(i -> System.out.print(i + " "));    // remplace for (int i = 0; i < 3; i++)
System.out.println();
System.out.println(Stream.of("b", "a", "b", "c").distinct().sorted().collect(Collectors.toList()));
```

## 6. `Optional` : une valeur, ou rien

Certaines opérations peuvent ne rien trouver (`findFirst`, `max` sur une liste vide). Plutôt que de renvoyer `null`, elles renvoient un `Optional`, qui oblige à prévoir le cas « rien ».

```run imp=java.util.* main
List<String> mots = List.of("poire", "kiwi", "banane");
Optional<String> long6 = mots.stream().filter(m -> m.length() >= 6).findFirst();
Optional<String> long9 = mots.stream().filter(m -> m.length() >= 9).findFirst();
System.out.println(long6.isPresent() + " " + long6.get());
System.out.println(long9.isPresent() + " " + long9.orElse("aucun"));
long6.ifPresent(m -> System.out.println("trouvé : " + m));
System.out.println(long9.map(String::toUpperCase).orElse("?"));
```

!attention Lisibilité avant tout | Un stream de dix opérations avec des lambdas sur plusieurs lignes est plus difficile à lire et à déboguer qu'une boucle. Utilise-les pour filtrer, transformer, agréger ; garde une boucle classique quand la logique est complexe.

=== java-enum-records | Java : enum, records, paquetages et bonnes pratiques | m
## 1. `enum` : un nombre fini de valeurs

Un `enum` définit un type dont les seules valeurs possibles sont listées. Fini les `int` ou `String` « magiques ».

```run cls main
enum Statut { EN_ATTENTE, EN_COURS, RESOLU, FERME }
@@
Statut s = Statut.EN_COURS;
System.out.println(s + " " + s.ordinal() + " " + s.name().length());
if (s == Statut.EN_COURS) System.out.println("ticket en cours");      // == est sûr pour un enum
for (Statut x : Statut.values()) System.out.print(x + " ");           // toutes les valeurs
System.out.println();
Statut lu = Statut.valueOf("RESOLU");                                 // depuis un texte
String message = switch (lu) {
    case EN_ATTENTE -> "pas encore pris en charge";
    case EN_COURS -> "un technicien travaille dessus";
    case RESOLU, FERME -> "terminé";
};
System.out.println(message);
```

### Un enum est une classe

Il peut avoir des attributs, un constructeur et des méthodes.

```run cls main
enum Priorite {
    BASSE("sous 5 jours", 1), NORMALE("sous 48 h", 2), URGENTE("sous 4 h", 3);

    private final String delai;
    private final int niveau;
    Priorite(String delai, int niveau) { this.delai = delai; this.niveau = niveau; }
    String getDelai() { return delai; }
    boolean plusUrgentQue(Priorite autre) { return niveau > autre.niveau; }
}
@@
Priorite p = Priorite.URGENTE;
System.out.println(p + " : " + p.getDelai());
System.out.println(p.plusUrgentQue(Priorite.NORMALE));
```

## 2. `record` : une classe de données en une ligne

Un `record` (Java 16+) génère automatiquement le constructeur, les accesseurs, `toString`, `equals` et `hashCode`. Ses champs sont **immuables**.

```run imp=java.util.* cls main
record Point(int x, int y) {
    double distance(Point autre) {                  // on peut ajouter des méthodes
        return Math.sqrt(Math.pow(x - autre.x, 2) + Math.pow(y - autre.y, 2));
    }
}
record Produit(String nom, double prix) {
    Produit {                                       // constructeur compact : validation
        if (prix < 0) throw new IllegalArgumentException("prix négatif");
    }
}
@@
Point a = new Point(0, 0), b = new Point(3, 4);
System.out.println(b + " " + b.x() + " " + a.distance(b));          // accesseur : x(), pas getX()
System.out.println(b.equals(new Point(3, 4)));                      // true : comparaison par contenu
List<Produit> panier = List.of(new Produit("Souris", 19.9), new Produit("Clavier", 49));
System.out.println(panier);
```

Écrire la même classe `Point` à la main demande une trentaine de lignes. Les records sont parfaits pour les objets qui ne font que **transporter des données** (résultat d'une requête, ligne d'un fichier, réponse d'une API).

## 3. L'immuabilité

Un objet **immuable** ne change plus après sa création (`String`, les records, `List.of`). Avantages : pas de modification surprise à distance, partage sans danger. Pour « modifier », on crée un nouvel objet.

```run cls main
record Compte(String titulaire, double solde) {
    Compte deposer(double m) { return new Compte(titulaire, solde + m); }    // renvoie un NOUVEAU compte
}
@@
Compte c1 = new Compte("Léa", 100);
Compte c2 = c1.deposer(50);
System.out.println(c1 + " " + c2);
```

## 4. `static`, `final` et les constantes

```run main
static final double TVA = 0.2;                 // constante de classe : MAJUSCULES
static final int MAX_ESSAIS = 3;
static int compteur = 0;                       // variable de classe (à utiliser avec prudence)

static double ttc(double ht) { compteur++; return ht * (1 + TVA); }
@@
System.out.println(ttc(100) + " " + ttc(50) + " " + compteur + " " + MAX_ESSAIS);
final int[] t = {1, 2, 3};
t[0] = 99;                                     // final protège la VARIABLE, pas le contenu
System.out.println(t[0]);
```

## 5. Les paquetages et `import`

Un **paquetage** (*package*) est un dossier de classes. Il évite les conflits de noms et organise le projet.

```
// fichier src/fr/monlycee/banque/Compte.java
package fr.monlycee.banque;                 // 1re ligne : le paquetage (= le chemin du dossier)

import java.util.ArrayList;                 // une classe précise
import java.util.*;                         // toutes les classes du paquetage java.util

public class Compte { … }                   // public : utilisable depuis un autre paquetage
```

| Paquetage | Contenu |
| `java.lang` | `String`, `Math`, `Integer`, `System`… importé automatiquement |
| `java.util` | collections, `Scanner`, `Random`, `Optional` |
| `java.util.stream` | les streams |
| `java.io`, `java.nio.file` | fichiers |
| `java.time` | dates et heures (`LocalDate`, `Duration`) |
| `java.sql` | accès aux bases de données (JDBC) |

Règle : **une classe publique par fichier**, et le fichier porte le nom de la classe.

## 6. Les conventions de nommage

| Élément | Convention | Exemple |
| Classe, interface, enum, record | PascalCase | `CompteBancaire` |
| Méthode, variable, attribut | camelCase | `calculerTotal`, `prixTtc` |
| Constante | MAJUSCULES_AVEC_TIRETS_BAS | `MAX_ESSAIS` |
| Paquetage | minuscules | `fr.monlycee.banque` |
| Accesseurs | `getX`, `setX`, `isX` pour un boolean | `getSolde`, `isVide` |

Ces conventions sont respectées par tous les développeurs Java : les suivre rend ton code lisible par n'importe qui.

## 1. Lire et écrire des fichiers

```
import java.nio.file.*;
import java.io.IOException;
import java.util.List;

    public static void main(String[] args) {
        Path fichier = Path.of("notes.txt");
        try {
            Files.writeString(fichier, "Léa;15\nSam;9\n");                    // écrit (écrase)
            Files.writeString(fichier, "Zoé;18\n", StandardOpenOption.APPEND); // ajoute à la fin

            List<String> lignes = Files.readAllLines(fichier);                // lit tout
            for (String ligne : lignes) {
                String[] champs = ligne.split(";");
                System.out.println(champs[0] + " a " + Double.parseDouble(champs[1]));
            }
            System.out.println(Files.exists(fichier) + " " + Files.size(fichier));
        } catch (IOException e) {                    // exception vérifiée : obligatoire
            System.out.println("Erreur de fichier : " + e.getMessage());
        }
    }
}
```

## 2. Accéder à une base de données : JDBC

**JDBC** est l'API standard pour dialoguer avec une base SQL (MySQL, MariaDB, PostgreSQL, SQLite). Le schéma est toujours le même : **connexion → requête préparée → résultat**.

```
import java.sql.*;

public class Main {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/parc";
        String sql = "SELECT nom, prix FROM materiel WHERE prix > ? ORDER BY prix";

        try (Connection cnx = DriverManager.getConnection(url, "utilisateur", "motdepasse");
             PreparedStatement requete = cnx.prepareStatement(sql)) {

            requete.setDouble(1, 100);                       // remplace le 1er ?
            try (ResultSet res = requete.executeQuery()) {
                while (res.next()) {                         // une ligne à la fois
                    System.out.println(res.getString("nom") + " : " + res.getDouble("prix"));
                }
            }
        } catch (SQLException e) {
            System.out.println("Erreur SQL : " + e.getMessage());
        }
    }
}
```

Pour modifier les données : `executeUpdate()`, qui renvoie le nombre de lignes touchées.

```
String sql = "INSERT INTO materiel (nom, prix) VALUES (?, ?)";
try (PreparedStatement requete = cnx.prepareStatement(sql)) {
    requete.setString(1, "Écran 27 pouces");
    requete.setDouble(2, 189.90);
    int lignes = requete.executeUpdate();
}
```

!attention Injection SQL : toujours une requête préparée | Ne construis **jamais** une requête en collant une saisie de l'utilisateur : `"… WHERE nom = '" + saisie + "'"`. Si quelqu'un tape `' OR '1'='1`, la condition devient toujours vraie et il lit toute la table ; il peut aussi détruire des données. Avec `PreparedStatement` et les `?`, la saisie est transmise comme une **donnée**, jamais comme du code SQL. C'est une exigence du bloc 3 (cybersécurité).

En pratique on range ce code dans une classe **DAO** (*Data Access Object*) : `MaterielDao.trouverTous()`, `MaterielDao.ajouter(m)`. Le reste de l'application ne voit jamais de SQL.

## 4. Les tests unitaires avec JUnit

Un **test unitaire** vérifie automatiquement qu'une méthode renvoie le bon résultat. On l'écrit une fois, on le relance à chaque modification : si un changement casse quelque chose, on le sait tout de suite.

```
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CompteTest {

    @Test
    void deposerAugmenteLeSolde() {
        Compte c = new Compte("Léa", 100);
        c.deposer(50);
        assertEquals(150, c.getSolde());
    }

    @Test
    void retirerPlusQueLeSoldeEstRefuse() {
        Compte c = new Compte("Léa", 100);
        assertFalse(c.retirer(500));
        assertEquals(100, c.getSolde());             // le solde n'a pas bougé
    }

    @Test
    void soldeInitialNegatifLeveUneException() {
        assertThrows(IllegalArgumentException.class, () -> new Compte("Léa", -1));
    }
}
```

Un bon test suit trois temps : **préparer** les données, **agir**, **vérifier**. Les objectifs vérifiés automatiquement dans les labos de ce site sont exactement des tests de ce genre.

=== java-jeu | Java : créer un jeu dans le navigateur | d
Java est le langage de Minecraft et de milliers de jeux Android (libGDX, jMonkeyEngine). Le principe est le même que dans tous les moteurs : tu écris une classe, et le moteur appelle ses méthodes à chaque image.

!info Où tester ? | Les jeux ont besoin d'un écran : ils se lancent dans le [bac à sable du labo](labo-java.html#libre). Copie les exemples de ce chapitre et modifie-les.

## 1. La boucle de jeu

Ta classe **hérite** de `Jeu` et **redéfinit** trois méthodes. C'est l'héritage et le polymorphisme en action : le moteur ne connaît que `Jeu`, et appelle pourtant **tes** méthodes.

```
public class Main extends Jeu {
    double x = 200;                          // l'état du jeu : des attributs

    public void setup() {                    // une fois, au démarrage
        x = 50;
    }

    public void update(double dt) {          // 60 fois par seconde : la logique
        if (touche("droite")) x += 200 * dt; // 200 pixels par seconde
    }

    public void draw() {                     // 60 fois par seconde : l'affichage
        effacer("black");
        rect(x, 140, 40, 40, "gold");
    }

    public static void main(String[] args) {
        lancer(new Main());                  // démarre le moteur
    }
}
```

| Méthode | Rôle |
| `effacer(c)` | remplit l'écran (480 × 320) |
| `rect(x, y, l, h, c)` | rectangle plein (coin haut gauche) |
| `cercle(x, y, r, c)` | disque (centre) |
| `ligne(x1, y1, x2, y2, c)` | segment |
| `texte(t, x, y, taille, c)` | texte |
| `touche("gauche")` | vrai tant que la touche est enfoncée |
| `toucheAppuyee("espace")` | vrai une seule image, à l'appui |
| `sourisX()`, `sourisY()`, `clic()` | souris |
| `hasard(a, b)` | entier au hasard entre a et b |
| `LARGEUR`, `HAUTEUR` | 480 et 320 |

L'origine est en **haut à gauche** et `y` augmente vers le **bas**.

## 2. Des entités : une classe par type d'objet

```
import java.util.ArrayList;
import java.util.List;

class Balle {
    double x, y, vx, vy;
    Balle(double x, double y, double vx, double vy) { this.x = x; this.y = y; this.vx = vx; this.vy = vy; }

    void avancer() {
        x += vx; y += vy;
        if (x < 10 || x > Jeu.LARGEUR - 10) vx = -vx;
        if (y < 10 || y > Jeu.HAUTEUR - 10) vy = -vy;
    }
}

public class Main extends Jeu {
    List<Balle> balles = new ArrayList<>();

    public void setup() {
        for (int i = 0; i < 5; i++) balles.add(new Balle(hasard(20, 460), hasard(20, 300), 3, 2));
    }
    public void update(double dt) {
        for (Balle b : balles) b.avancer();
    }
    public void draw() {
        effacer("#16182b");
        for (Balle b : balles) cercle(b.x, b.y, 10, "gold");
    }
    public static void main(String[] args) { lancer(new Main()); }
}
```

## 6. Les états du jeu avec un `enum`

enum Etat { MENU, JEU, FIN }

public class Main extends Jeu {
    Etat etat = Etat.MENU;
    int score = 0;

    public void update(double dt) {
        switch (etat) {
            case MENU -> { if (toucheAppuyee("espace")) { etat = Etat.JEU; score = 0; } }
            case JEU  -> { score++; if (score > 300) etat = Etat.FIN; }
            case FIN  -> { if (toucheAppuyee("espace")) etat = Etat.MENU; }
        }
    }

    public void draw() {
        effacer("black");
        switch (etat) {
            case MENU -> texte("ESPACE pour jouer", 130, 150, 24, "white");
            case JEU  -> texte("Score : " + score, 16, 16, 24, "white");
            case FIN  -> texte("Perdu ! Score : " + score, 130, 150, 24, "tomato");
        }
    }
    public static void main(String[] args) { lancer(new Main()); }
}
