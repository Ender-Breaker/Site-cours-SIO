=== lua-bases | Lua : variables, types et affichage | f
**Lua** (« lune » en portugais) est un langage très léger, créé au Brésil en 1993 et conçu pour être **intégré** dans d'autres programmes. On le retrouve dans les jeux (Roblox utilise une variante, Luau ; le moteur LÖVE ; les extensions de World of Warcraft), dans l'éditeur Neovim, dans des routeurs et dans le serveur web nginx (OpenResty). Tout le langage tient en une vingtaine de mots-clés : on peut vraiment le connaître en entier, et c'est le but de ce cours.

!info Comment suivre ce cours | Chaque bloc de code avec un bouton **Exécuter** est un vrai programme Lua 5.4 : lance-le, modifie-le, casse-le, relance-le. C'est en changeant le code qu'on apprend. Les **défis** t'envoient dans le labo, où ton programme est vérifié automatiquement.

## 1. Afficher et commenter

`print` affiche ses valeurs puis passe à la ligne. Avec plusieurs valeurs, elles sont séparées par une tabulation.

```run
print("Bonjour !")
print("Total :", 42)
-- un commentaire sur une ligne : Lua l'ignore
--[[ un commentaire
     sur plusieurs lignes ]]
io.write("Sans retour ")
io.write("à la ligne\n")
```

Pas de point-virgule obligatoire, pas d'accolades : les blocs se terminent par le mot `end`. Lua distingue les majuscules des minuscules : `Score` et `score` sont deux noms différents.

## 2. Variables : toujours `local`

```run
local score = 0          -- variable locale : à préférer partout
score = score + 10
local a, b = 1, 2        -- affectation multiple
a, b = b, a              -- échange en une seule ligne
print(score, a, b)
print(inconnue)          -- jamais affectée : vaut nil
```

!attention Le piège numéro 1 de Lua | Sans le mot `local`, une variable est **globale** : elle est visible dans tout le programme et peut écraser une autre variable du même nom. Une faute de frappe dans un nom ne provoque pas d'erreur : elle crée silencieusement une nouvelle variable qui vaut `nil`. Prends l'habitude d'écrire `local` à chaque création.

Depuis Lua 5.4, on peut aussi déclarer une constante : `local TVA <const> = 0.2`. La modifier ensuite est une erreur de compilation.

## 3. Les huit types

| Type | Exemples | À savoir |
| `nil` | `nil` | l'absence de valeur |
| `boolean` | `true`, `false` | seuls `false` et `nil` sont « faux » |
| `number` | `42`, `3.14`, `1e3`, `0xFF` | deux sous-types : entier et flottant |
| `string` | `"texte"`, `'texte'`, `[[texte long]]` | non modifiable |
| `table` | `{1, 2, 3}`, `{nom = "Léa"}` | la seule structure de données |
| `function` | `print`, `function() end` | une valeur comme une autre |
| `thread` | une coroutine | voir le chapitre Coroutines |
| `userdata` | donnée du programme hôte | rare en Lua pur |

```run
print(type(42), type(3.14), type("42"), type(nil), type(print), type({}))
print(math.type(42), math.type(42.0))   -- integer   float
print(10 == 10.0)                        -- true : même valeur
print(0 == false, "" == false)           -- false false
```

!attention 0 et "" sont vrais | Contrairement à Python, JavaScript ou PHP, en Lua le nombre `0` et la chaîne vide `""` sont considérés comme **vrais** dans une condition. Seuls `false` et `nil` sont faux.

## 4. Opérateurs arithmétiques

```run
print(7 / 2)       -- 3.5    la division donne toujours un flottant
print(7 // 2)      -- 3      division entière (arrondie vers le bas)
print(7 % 2)       -- 1      reste de la division (modulo)
print(2 ^ 10)      -- 1024.0 puissance (toujours flottante)
print(-7 // 2, -7 % 3)   -- -4   2  : arrondi vers moins l'infini
print(10 / 2)      -- 5.0 et non 5
print(1 + 2 * 3, (1 + 2) * 3)
```

Pas de `++` ni de `+=` en Lua : on écrit `i = i + 1`.

## 5. Texte : coller, mesurer, convertir

```run
local prenom = "Léa"
print("Bonjour " .. prenom .. " !")      -- .. colle deux chaînes
print(#"Lua")                             -- # donne la longueur : 3
print("10" + 5)                           -- 15 : la chaîne est convertie en nombre
print(10 .. 20)                           -- "1020" : les nombres sont convertis en texte
print(tonumber("42") + 1, tonumber("abc")) -- 43   nil
print(tostring(42) .. "!")
print(string.format("%.2f euros", 3.14159))
```

`tonumber` renvoie `nil` si le texte n'est pas un nombre : c'est la façon de vérifier une saisie. `string.format` met en forme : `%d` entier, `%.2f` deux décimales, `%s` texte, `%5d` sur 5 caractères.

## 6. Lire au clavier

```run stdin=Léa|17
local nom = io.read()          -- lit une ligne de texte
local age = io.read("n")       -- lit un nombre
print("Bonjour " .. nom .. ", dans 10 ans tu auras " .. (age + 10) .. " ans.")
```

=== lua-conditions-boucles | Lua : conditions et boucles | f
## 1. La condition `if`

```run stdin=15
local note = io.read("n")
if note >= 16 then
  print("Très bien")
elseif note >= 10 then
  print("Admis")
else
  print("Recalé")
end
```

Trois règles : la condition est suivie de `then`, le bloc se termine par `end`, et `elseif` s'écrit **en un seul mot**. Les conditions sont testées dans l'ordre : dès qu'une est vraie, les suivantes sont ignorées.

## 2. Comparer et combiner

| Opérateur | Sens |
| `==` | égal |
| `~=` | différent (et non `!=`) |
| `<` `<=` `>` `>=` | comparaisons |
| `and` | et |
| `or` | ou |
| `not` | non |

```run
local age, carte = 17, true
print(age >= 18 and carte)       -- false
print(age >= 18 or carte)        -- true
print(not carte)                 -- false
print(1 == 1.0, "1" == 1)        -- true  false : pas de conversion avec ==
print("abc" < "abd")             -- true : ordre alphabétique
```

### `and` et `or` renvoient une valeur

`and` et `or` ne renvoient pas forcément `true` ou `false` : ils renvoient **l'un de leurs deux opérandes**. `a or b` vaut `a` s'il est vrai, sinon `b`. `a and b` vaut `a` s'il est faux, sinon `b`.

```run
local pseudo = nil
print(pseudo or "Invité")              -- valeur par défaut
local age = 20
print(age >= 18 and "majeur" or "mineur")   -- le « ternaire » de Lua
print(nil and 1, false or nil, 0 and "zéro est vrai")
```

!attention Limite du faux ternaire | `c and a or b` ne marche que si `a` n'est ni `false` ni `nil`. Sinon écris un vrai `if`.

## 3. `while` et `repeat`

`while` teste **avant** chaque tour ; `repeat … until` teste **après** (le bloc s'exécute au moins une fois) et s'arrête quand la condition devient **vraie**.

```run
local n = 1
while n < 100 do
  n = n * 2
end
print(n)

local essais = 0
repeat
  essais = essais + 1
until essais * essais > 50
print(essais)
```

## 4. `for` numérique

`for i = début, fin, pas` : la fin est **incluse**, le pas vaut 1 par défaut.

```run
for i = 1, 5 do io.write(i, " ") end
print()
for i = 10, 1, -3 do io.write(i, " ") end     -- pas négatif
print()
for i = 0, 1, 0.25 do io.write(i, " ") end
print()
```

La variable `i` est locale à la boucle et n'existe plus après le `end`. Il existe aussi un `for … in` pour parcourir les tables : voir le chapitre sur les tables.

## 5. `break`, et pas de `continue`

`break` sort de la boucle. Lua n'a pas de `continue` : on inverse la condition, ou on utilise `goto` avec une étiquette.

```run
for i = 1, 10 do
  if i % 2 == 0 then goto suite end     -- saute les nombres pairs
  if i > 7 then break end               -- arrête tout
  io.write(i, " ")
  ::suite::
end
print()
```

=== lua-fonctions | Lua : les fonctions | m
## 1. Définir et appeler

```run err
local function aire(largeur, hauteur)
  return largeur * hauteur
end

print(aire(3, 4))
print(aire(3))        -- erreur : hauteur vaut nil
```

Un paramètre non fourni vaut `nil` (d'où l'erreur ci-dessus quand on multiplie), un argument en trop est ignoré. Une fonction sans `return` renvoie `nil`.

### Valeurs par défaut

Lua n'a pas de syntaxe dédiée : on utilise `or`.

```run
local function saluer(nom, politesse)
  politesse = politesse or "Bonjour"
  print(politesse .. " " .. (nom or "inconnu") .. " !")
end
saluer("Léa")
saluer("Sam", "Salut")
saluer()
```

## 2. Plusieurs valeurs de retour

Une fonction Lua peut renvoyer **plusieurs valeurs**. C'est très utilisé : `string.find` renvoie un début et une fin, `pcall` un statut et un résultat.

```run
local function divise(a, b)
  return a // b, a % b
end

local q, r = divise(17, 5)
print(q, r)
local seul = divise(17, 5)        -- les valeurs en trop sont perdues
print(seul)
print(divise(17, 5), "fin")       -- tronqué à 1 valeur : pas en dernière position
print("début", divise(17, 5))     -- toutes les valeurs : dernière position
print((divise(17, 5)))            -- des parenthèses forcent une seule valeur
```

## 3. Nombre variable d'arguments : `...`

```run
local function somme(...)
  local total = 0
  for _, v in ipairs({...}) do     -- {...} range les arguments dans une table
    total = total + v
  end
  return total
end

print(somme(1, 2, 3), somme(10, 20, 30, 40), somme())
print(select("#", "a", "b", "c"))   -- nombre d'arguments : 3
print(select(2, "a", "b", "c"))     -- à partir du 2e : b   c
```

## 4. Les fonctions sont des valeurs

Une fonction se range dans une variable, se passe en argument, se renvoie. `function f() end` n'est qu'un raccourci de `f = function() end`.

```run
local double = function(x) return x * 2 end

local function appliquer(f, valeur)
  return f(valeur)
end

print(appliquer(double, 21))
print(appliquer(function(x) return x * x end, 9))   -- fonction anonyme
print(appliquer(string.upper, "lua"))
```

## 5. Récursivité

Une fonction récursive s'appelle elle-même. Il lui faut un **cas d'arrêt**.

```run
local function factorielle(n)
  if n <= 1 then return 1 end           -- cas d'arrêt
  return n * factorielle(n - 1)
end
print(factorielle(5), factorielle(20))
```

!attention `local function` ou `local f = function` ? | Pour une fonction récursive, écris `local function f()`. Avec `local f = function() … f() … end`, le nom `f` n'existe pas encore à l'intérieur de la fonction au moment où elle est créée.

# Une fonction qui renvoie deux résultats
```run
local function minmax(t)
  local mini, maxi = t[1], t[1]
  for _, v in ipairs(t) do
    if v < mini then mini = v end
    if v > maxi then maxi = v end
  end
  return mini, maxi
end
print(minmax({12, 5, 19, 8}))
```
# Réutiliser une fonction dans une autre
```run
local function somme(t)
  local s = 0
  for _, v in ipairs(t) do s = s + v end
  return s
end
local function moyenne(t)
  return somme(t) / #t
end
print(moyenne({12, 5, 19, 8}))
```
# Passer une fonction en argument
`compter` reçoit un test sous forme de fonction : la même fonction sert pour tous les critères. Ajoute ton propre test.
```run
local function compter(t, test)
  local n = 0
  for _, v in ipairs(t) do
    if test(v) then n = n + 1 end
  end
  return n
end
local notes = {12, 5, 19, 8, 10}
print(compter(notes, function(v) return v >= 10 end))
print(compter(notes, function(v) return v % 2 == 0 end))
```

=== lua-tables | Lua : les tables | m
La **table** est l'unique structure de données de Lua. Elle sert à la fois de liste, de dictionnaire, d'objet, de module. Bien maîtriser les tables, c'est maîtriser Lua.

## 1. La table comme liste

```run
local fruits = {"pomme", "kiwi", "poire"}
print(fruits[1])              -- pomme : les indices commencent à 1
print(#fruits)                -- 3 : nombre d'éléments
fruits[#fruits + 1] = "figue" -- ajoute à la fin
table.insert(fruits, "noix")  -- pareil
table.insert(fruits, 1, "ananas")   -- insère au début (décale le reste)
print(table.remove(fruits))   -- retire et renvoie le dernier : noix
print(table.remove(fruits, 1))-- retire le premier : ananas
print(table.concat(fruits, ", "))
print(fruits[99])             -- nil : pas d'erreur
```

!attention Les indices commencent à 1 | C'est la différence la plus déroutante quand on vient d'un autre langage. `t[0]` vaut `nil`, et les boucles vont de `1` à `#t`.

## 2. Parcourir : `ipairs` et `pairs`

```run
local notes = {12, 15, 9}
for i, v in ipairs(notes) do        -- indice et valeur, dans l'ordre
  print(i, v)
end
for i = #notes, 1, -1 do            -- à l'envers, avec un for numérique
  io.write(notes[i], " ")
end
print()
```

`ipairs` parcourt 1, 2, 3… et **s'arrête au premier `nil`**. `pairs` parcourt **toutes** les clés, dans un ordre non garanti.

## 3. La table comme dictionnaire

```run
local joueur = { nom = "Léa", pv = 10 }
print(joueur.nom, joueur["pv"])     -- deux écritures équivalentes
joueur.niveau = 3                   -- ajoute une clé
joueur.pv = nil                     -- supprime une clé
for cle, valeur in pairs(joueur) do
  print(cle, valeur)
end
local stock = {}
stock["clé USB"] = 12               -- les crochets acceptent n'importe quelle clé
stock[42] = "réponse"
print(stock["clé USB"], stock[42], stock.absent)
```

`t.nom` est un raccourci de `t["nom"]` : il ne marche que si la clé est un nom simple (lettres, chiffres, `_`).

## 4. Trier

```run
local t = {5, 2, 8, 1}
table.sort(t)
print(table.concat(t, " "))
table.sort(t, function(a, b) return a > b end)   -- ordre décroissant
print(table.concat(t, " "))

local eleves = { {nom = "Léa", note = 15}, {nom = "Sam", note = 9}, {nom = "Zoé", note = 18} }
table.sort(eleves, function(a, b) return a.note > b.note end)
for rang, e in ipairs(eleves) do print(rang, e.nom, e.note) end
```

La fonction de comparaison reçoit deux éléments et renvoie `true` si le premier doit passer **avant** le second.

## 5. Les tables sont des références

```run
local a = {1, 2, 3}
local b = a            -- b désigne LA MÊME table, pas une copie
b[1] = 99
print(a[1])            -- 99
print(a == b, {1} == {1})   -- true  false : == compare l'identité

local copie = {}
for i, v in ipairs(a) do copie[i] = v end   -- copie élément par élément
copie[1] = 0
print(a[1], copie[1])
```

Conséquence : une fonction qui reçoit une table peut la **modifier**, et l'appelant voit le changement.

## 6. Tables imbriquées

```run
local grille = {}
for l = 1, 3 do
  grille[l] = {}
  for c = 1, 3 do grille[l][c] = (l - 1) * 3 + c end
end
print(grille[2][3])
for _, ligne in ipairs(grille) do print(table.concat(ligne, " ")) end
```

!attention `#` et les trous | `#t` n'est fiable que pour une liste **sans trou**. Si tu écris `t[2] = nil` au milieu d'une liste, `#t` peut donner un résultat inattendu : retire les éléments avec `table.remove`. Pour compter les clés d'un dictionnaire, il faut une boucle `pairs`.

!tuto Un inventaire de magasin
# Compter avec un dictionnaire
La clé est le nom de l'article, la valeur sa quantité. `(stock[nom] or 0)` vaut 0 la première fois.
```run
local stock = {}
local function ajouter(nom, qte)
  stock[nom] = (stock[nom] or 0) + qte
end
ajouter("souris", 3)
ajouter("clavier", 2)
ajouter("souris", 5)
print(stock.souris, stock.clavier)
```
# Afficher dans l'ordre alphabétique
`pairs` n'a pas d'ordre garanti : on récupère les clés dans une liste, on la trie, puis on affiche.
```run
local stock = { souris = 8, clavier = 2, ecran = 4 }
local noms = {}
for nom in pairs(stock) do noms[#noms + 1] = nom end
table.sort(noms)
for _, nom in ipairs(noms) do
  print(nom .. " : " .. stock[nom])
end
```
# Trouver l'article le plus en stock
```run
local stock = { souris = 8, clavier = 2, ecran = 4 }
local meilleur, maxi = nil, -1
for nom, qte in pairs(stock) do
  if qte > maxi then meilleur, maxi = nom, qte end
end
print(meilleur, maxi)
```
